野生精灵检测器

在本地小窗查看野生精灵的声音、体重比例、性格与佩戴奖章。

查看工具项目 ↗ 版本与发布说明 ↗

源码预览版：目前公开源码与文档，尚未提供可直接安装的完整程序包。

能查看什么

声音
查看声音属性在范围内的位置，以及粗嗓门、婉转声等标识。
体重比例
查看该精灵体重范围内的位置和大小端标识。百分比不是稀有概率。
性格与奖章
查看已下发的性格效果和佩戴奖章，缺失信息保留为未知。

使用前了解

  1. 先看项目说明运行前需按文档准备所需资源，公开源码压缩包不包含完整游戏资源。
  2. 准备 Windows 环境源码运行需要 Python 3.12 和官方 Npcap。具体安装、资源准备和构建步骤见项目文档。
  3. 进入野生 PVE 遭遇开启读取后重新进入游戏世界，小窗在确认野生遭遇后显示信息；PVP 和未知模式不显示。
当前验证范围

本地启动、离线合成回放和界面已验证；当前游戏版本的真实采集兼容性、属性下发时机仍待实测。
