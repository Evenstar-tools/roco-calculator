# 国际客户端精灵种族值版本核查

核查日期：2026-10-28。客户端：本机 `C:/RoCoKingdom`，游戏主程序 FileVersion / ProductVersion **1.61.0.91**。客户端全程只读。

## 结论

**这版包内种族值不等同国服 S4。592 条历史共有精灵的六维，全部吻合项目保存的 S3 季中基线。**

S3 季中基线由 `data/snapshots/seasons/s3-2026-07-15.json` 与 `scripts/bwiki/apply-s3-midseason-balance.mjs` 两组种族值补丁复原。其中 5 项来自 8 月 13 日官方季中调整记录，7 项来自 8 月 17 日 BWIKI 同步；归入 S3 季中口径，不单独推断这 7 项各自的生效日。

| 比较基线 | 基线记录数 | 客户端六维一致 | 六维不同 | 客户端缺少 ID |
| --- | ---: | ---: | ---: | ---: |
| 项目 S3 原快照 | 592 | 580 | 12 | 0 |
| 项目 S3 季中基线 | 592 | **592** | **0** | 0 |
| 项目 S4 现行基线 | 622 | **528** | **90** | **4** |

S4 使用当前 `data/snapshots/current.json`。该文件虽然 `meta.id` 仍为 `s4-2026-09-10`，实际已包含 2026-10-14 测风蝉、摇铃魔偶各五项种族值调整；本报告使用调整后数值，不混入 S5 前瞻 overlay 或用户手调种族值。

4 个 S4 ID 在本机当前 `PETBASE_CONF` 中不存在：烈焰狂战士 `5063`、满月砣（上弦的样子）`5064`、满月砣（下弦的样子）`5065`、果实立方人 `3796`。这表示本次包内表缺少这些 ID，不代表永久不会开放。

## 来源与验证

1. 重新读取本机全部 35 个 Pak 索引，查明 `PETBASE_CONF` 的 schema、主表、ROW 表及四种语言文件均来自 `pakchunk4-WindowsNoEditor.pak`，没有被其他本机 Pak 的同路径文件覆盖。新提取内容与前次提取逐字节一致。
2. 从客户端本身 `PETBASE_CONF.non` 读取 schema，按 `id` 对齐国服 `game_id`，同时复用已核验的中文名／形态对应；没有靠同名模糊匹配。
3. 比较六个字段：`hp_max_race`、`phy_attack_race`、`spe_attack_race`、`phy_defence_race`、`spe_defence_race`、`speed_race`。独立按字段实际序列化位置读出小端 uint32；全部行完整消费，四语言非文本值一致。
4. 包内共 1,136 个唯一 ID，其中 1,026 条六维齐全，110 条六维字段均未序列化，保持空值。与 S4 对应的 618 条全部六维齐全。
5. `SUM_race` 有 **825 条已写数值与六维之和不同**；另有 6 条六维完整但没有该字段。因此本报告总和一律六项相加，不使用 `SUM_race` 推断或修正种族值。
6. CSV 全列读回与 JSON 对齐；S4 共 90 条、377 个数值单元格不同。全部 622 个项目 ID 和 1,136 个客户端 ID 唯一，形态记录独立保留。

原始验证证据：[client-version-evidence.json](client-version-evidence.json)、[current-pak-evidence.json](current-pak-evidence.json)、[stats-schema-evidence.json](stats-schema-evidence.json)。过程脚本在 `_work/global-client-20261028/stats-audit/`：`verify-current-petbase.mjs`、`export-petbase-stats.py`、`compare-stats.py`；S3 基线构造脚本和来源见同目录。

本结论限于**当前本机安装包的精灵六维种族值**。未确认服务器或运行时热更新覆盖，也未以本次六维匹配认定整包技能、特性、规则和实际可用精灵池等同 S3。额外条目及占位值不进入计算器。本轮只新增本地研究结果，未修改客户端、产品数据、语言表、计算规则或线上。
