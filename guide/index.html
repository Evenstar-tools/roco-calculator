洛克计算器使用说明

为《洛克王国：世界》对战选择精灵、配置技能，查看伤害与剩余 HP。先完成一次计算，再用队伍和查询工具比较配置。

开始伤害计算 → 下载 Windows 版

三步完成一次伤害计算

查看常见问题 ↓
  1. 01

    选择攻守双方

    在主计算器选择攻击方与防御方精灵。搜索支持名称模糊匹配，选择后会带出技能、特性与种族值。

  2. 02

    调整技能与条件

    精简版适合快速配置；具体版可进一步调整性格、个体、威力、连击和战斗条件。按需要选择单技能或四技能。

  3. 03

    读取并比较结果

    查看伤害、HP 占比与剩余生命。改变配置会立即重算；需要核对细节时，展开高级选项查看算式与条件。

结果对应当前输入条件。遇到种族值待确认、未支持效果或条件待确认提示时，先核对提示，不把理论结果当作确定的实战结论。

按问题选择工具

「队伍」在主计算器顶部；下列查询、计算和排行入口在「工具箱」。

保存和比较常用阵容 队伍

管理多支六人队伍，配置成员与四技能，再快捷载入攻守双方。队伍分析可查看属性弱点、技能打击面和对位。

入口：主计算器 → 队伍

找技能与可学精灵 技能检索

按技能名称或效果搜索，结合属性、种类和赛季筛选；查看可学家族，以及资料中收录的赛季技能与学习更新。

入口：工具箱 → 技能检索

查弱点和进攻覆盖 属性查询

选择一种或两种属性，查看防守抗性和进攻打击面。这里仅比较属性关系，不计技能威力、特性、天气等实际伤害条件。

入口：工具箱 → 属性查询

比较先手与承伤能力 速度线／耐久排行

速度线排行可查实际速度档位与种族速度；耐久排行可按模板、承受属性和指标比较。查看配置口径后，再代入具体对战复算。

入口：工具箱 → 速度线排行／耐久排行

推演技能槽位顺序 传动计算器

选择精灵、特性与四个初始技能，逐回合查看传动后的顺序和变化记录，也可载入主计算器已有技能。传动推演不等同于完整战斗模拟。

入口：工具箱 → 传动计算器

查看击倒所需层数 电鹿斩杀线

设置攻守双方、特性层数与目标 HP，比较技能的当前伤害、单招最低层数和可选先发补刀。页面会标明尚未计入的保命效果及待确认条件。

打开电鹿斩杀线 →

常见问题

精简版和具体版怎么选？

快速比较精灵与技能时用精简版。需要逐项调整性格、个体及更多条件时切到具体版；读取结果前确认双方参数和技能条件是否符合本次对战。

为什么同一个技能与实战伤害不同？

先核对双方精灵、性格、个体、技能威力、特性和战斗条件，并查看高级选项中的算式。属性查询和排行采用各自注明的口径，不能直接代替完整伤害计算；资料待确认或未支持的效果也会影响结论。

配置会保存到哪里？

精灵配置保存在本机，切换精灵时会按精灵恢复。它不是账号云同步；更换设备或清除网站存储后，不应期待原配置自动出现。队伍面板提供导入与导出阵容，分享内容的范围以面板提示为准。

手机和电脑都能用吗？

可直接使用网页版；Windows 用户也可从项目 GitHub 下载最新安装包。相关入口见本页顶部，下载文件以 Release 页面实际提供的版本为准。

发现资料或计算结果有问题，怎么反馈？

请记录精灵、技能、双方配置、已开启的条件及预期结果，通过 GitHub 问题反馈 提交。需要核对计算口径时，可阅读 计算规则说明。
