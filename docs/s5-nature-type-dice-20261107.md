# S5 系别骰子单关系接入

2026-11-07。本次接通单个非中性属性关系下的四个系别骰面。沿用现有觉醒和野怪攻防模型，没有恢复游戏 order42 的完整消费者，也没有用拟合系数替换野怪双防。

## 实际行为

| 骰面 ID | 适用持有方 | 单关系基础系数 |
|---|---|---|
| 7 克制 | 攻击方 | 2 → 2.5 |
| 14 强力克制 | 攻击方 | 2 → 3.5 |
| 8 抵抗 | 防守方 | 0.5 → 0.4 |
| 15 强力抵抗 | 防守方 | 0.5 → 0.25 |

自动威力只替换一次关系系数，再沿用现有极化/钝化修正。手填显示威力已经含骰子系别，不重复替换；手填最终威力继续跳过自动换算。免疫保持零，中性关系与不适用的持有方不加效果。

可处理“一个非中性因子 + 一个中性因子”的双属性精灵。两个非中性因子（包括克制与抵抗抵消）、双方同时存在相关类型骰子、同侧多骰面仍需已知最终威力；没有把40%的系数当成所有招统一减伤60%。

目录仍标 `supportStatus=trial`、`formulaVerified=false`。新增 `typeCoefficientPolicy` 记录角色、单关系范围及未恢复消费者/未完成独立实录验证的状态。结果的 `recordedDiceEffects` 与 `appliedDiceEffects` 分别表示选中和本击实际应用。旧目录精确系数描述可继续读取。

## 配置依据与限制

四条记录的 `BUFFBASE_CONF.buffbase_order=42`，对应 `BFT_CHANGE_SDT_RATIO`：

- 2042018：`[50,0,0,0]`，原文“克制系数增加为250%”。
- 2042019：`[150,0,0,0]`，原文“克制系数增加为350%”。
- 2042020：`[0,0,0,20]`，原文“抵抗系数降低为40%”。
- 2042021：`[0,0,0,50]`，原文“抵抗系数降低为25%”。

生成器核对精确基础效果 ID、order 和四个数组项，任何不符都撤去可自动应用的系数描述。没有将四个参数位推广成通用线性算式。

同型 BUFF20420010 和技能200070“神羽”的文案把参数1关联到克制出伤；BUFF29990001 把参数4关联到抵抗承伤。该道具参数4为负1而骰子为正20/50，符号语义仍有冲突，故方向采用配置关联、数值采用四个骰面各自的明确文案。消费者顺序、叠层及双关系组合尚无直接证据。

42级伊雷龙加物防的人工条件样本：地刺显示180造成333，火焰切割显示40造成133，与单关系0.4后接现有极化1.8相容。该样本缺骰面ID协议链，且已用于模型分析，不属于新增独立验证。旧41级335/157矛盾样本保留；25%抵抗和两档克制尚无对应真实对局验证。

## 强度阶位研究结果

`PETBASE_CONF.stength_stage` 原说明：种族资质，只有1阶填3，有2阶填2、3，有3阶填1、2、3。字段与显示形态阶级分开，但配置约定关联进化链。

本轮定向读取全部最新 Lua 后，实际消费者是模型编辑器的 `SetAdjustPetParam → SetPetVisualParam → PetStrengthStage.SetText`。未恢复该字段进入野怪双防的代码。历史怪物成长/突破及双防附加字段分别存在，不能由字段存在推出绑定关系。

2.76 / 1.955 / 1.383 仍为指定本体物防结构的拟合候选，魔防不能直接套用。本次未修改 `wild-defense.mjs`、`awakening.mjs` 或物种目录中的阶段与种族值。

## 验证

受影响的 S5 单元回归与定向静态检查通过。浏览器以当前 public 源码独立打开工具页，验证选择抵抗、刷新保留、40显示威力只计一次、切换强力抵抗时保留手填值、恢复自动后显示25且有效威力45。

复跑：

```text
node node_modules/vitest/vitest.mjs run --config config/vite.config.mjs tests/domain/s5-nature --maxWorkers=2
```

浏览器回归位于 `tests/e2e/s5-nature.spec.js` 的 `type dice calculate single resistance` 用例。用户随后明确要求“骰子接通就发布，通行证精灵强度阶位同步”。本轮将上述单关系接入纳入国服网页发布；强度阶位已逐只对照原表，4 只为 2、6 只为 1。线上结果另行回查，不构建桌面安装包。
