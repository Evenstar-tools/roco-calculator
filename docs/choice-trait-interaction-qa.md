# 加尔与黑化加尔选择技能专项验收

日期：2026-09-14。Web/桌面 2.0.2，小程序 1.1.16；只做本地修复和提交，未推送、上线或上传审核。

## 发现与修复

1. 友谊满溢：实际控件使用稳定 ID 保存分支，但成长推进只读旧字段，导致第一段漏记。改为与选择分支相同的读取顺序，兼容旧配置和默认值。加尔成长一次 +20；黑化加尔成长分支重复后 +40，第二段能读到第一段成长。
2. 单技能：原来只在四技能模式执行特性追加段。现在单技能也读取自身方向的条件，使用同一个执行计划；未开启特性时仍只结算一段。
3. 小程序纯状态预览：原来预览未传入已开启的选择特性，与实际施加值不同。技能参数和结果动作两处预览均带入特性；取消特性后恢复单分支预览。
