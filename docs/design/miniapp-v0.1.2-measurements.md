## 手机结构

1. 顶部标题区 52px；微信胶囊右侧预留 96px。
2. 双方精灵区两列，每列最小宽 0，中央换位按钮 44px；精灵图标槽 52px，`aspectFit`。
3. 六维区固定七列：行名 38px + 六个等宽图标槽；图标可见边界 24–28px。
4. 单/四切换总宽 144px、高 44px；选中态为深色填充，未选中为透明，不允许两个都填充。
5. 技能行高 68px；左图标槽 28px，中部文字 `min-width: 0`，右结果宽 72px。
6. 结果栏固定底部并计入安全区：内容高 128px + `env(safe-area-inset-bottom)`；展开箭头 44px。
7. 底部抽屉左右边距 8px、顶部圆角 18px；标题区 64px、分类区 52px、搜索 44px；列表占剩余高度。

## iPad 结构

1. 主工作区列比 2fr / 1fr，列间距 14px，最大内容宽 1180px。
2. 左侧双方配置保持两列；每列六维图标、参数和技能列表共享基线。
3. 右侧结果区 `position: sticky`，顶部不越过微信标题栏；结果和战斗状态垂直排列。
4. 技能选择采用右侧 360px 面板；窄 iPad 退化为底部抽屉，不覆盖安全区。

## 状态规范

- 按下：背景亮度降低 4%，内容缩放到 0.985，120ms 恢复。
- 选中：边线/文字使用语义色，浅色填充；勾选徽标保持 16px，不挤压图标。
- 展开：触发器保留选中底色和方向箭头变化。
- 禁用：不透明度 0.45，同时禁用点击，不仅改变文字颜色。
- 血条：`<=20%` 绿、`>20% && <=50%` 黄、`>50%` 红；百分比文字同色。
- 搜索：0、1、多结果时标题/分类/输入框 y 坐标一致；列表从同一锚点开始。

## 比较门槛

- 手机重复边线与参考相差不超过 2px，iPad 不超过 3px。
- 无横向滚动、文字被裁剪、图标缩放失真、浮层超框或键盘导致头部跳动。
- 参考和实现必须在相同视口、相同数据、相同展开状态下并排检查。
