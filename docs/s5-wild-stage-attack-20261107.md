# S5 野怪攻击阶段修正（2026-11-07）

## 问题和结果

43 级伊雷龙的升龙咆哮，对魔防 137 的罗隐造成 660，伊雷龙魔攻／全属性 +30%。旧模型先改用伊兰亚龙的魔攻种族 190，再乘 2，普通魔攻性格算 672；加魔攻 737、减魔攻 607，均与实测冲突。

新攻击模型使用选中本形态种族与其包体强度阶段。伊雷龙自身魔攻种族 152、强度阶段 2，计算出普通魔攻 389，带 +30% 后得到 660；加魔攻得 721、减魔攻得 599。在该模型及已确认条件下，660 对应魔攻不增不减。该观测不区分其余属性的性格增减项。

## 公式

R 表示正数四舍五入：

```text
B = R(10 + 本形态攻击种族 × (等级 + 50) / 100)
A = R((R(B × 性格倍率) + 11) × 强度阶段系数)
强度阶段 1 / 2 / 3：系数 2.8 / 2.4 / 2.0
性格倍率：增加 1.1、不变 1.0、降低 0.9
```

末次取整发生在骰子增益之前，骰子仍沿用现有计算，不重复取整或叠加。物攻和魔攻使用同一生成流程。强度阶段来自包体 `stength_stage`，不等于界面显示的进化阶段。

本次修改野怪双攻生成，并将已记录的抵抗钝化修正 0.59 调整为 0.6。HP、双防、我方面板、技能威力、骰子叠加及显式威力的处理保持各自原规则。第三强度阶段系数仍为 2，不改深蓝鲸等已有双攻结果。缺少攻击阶段时只阻断需要双攻的计算，HP-only 判断仍独立可用，不默认为第三阶段。
