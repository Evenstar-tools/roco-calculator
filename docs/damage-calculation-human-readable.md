# 伤害计算过程展示规范

## 目标

让玩家快速核对当前技能伤害，不显示内部字段、英语函数、编号步骤或长段说明。

## 展示方式

- 位于高级选项内，默认折叠。
- 只展示当前高亮技能，条件或层数变化后立即更新。
- 所有数值直接来自计算引擎，界面不重复计算。
- 使用一张扁平算式卡，只保留四行。

```text
技能威力  （基础25 + 固定20）× 威力加成1.5 = 67.5
显示威力  67.5 × 本系1.25 × 克制0.5 = 42.1875 → 四舍五入42
每段伤害  物攻213 × 威力42.1875 × 等级系数0.902439 → 四舍五入8114 ÷ 物防175 → 向下取整46
总伤害    每段46 × 2段 + 星陨20 = 112
```

## 展示规则

- 默认隐藏所有未生效的 `×1` 乘区。
- 固定加成、百分比加成、天气、能力等级、减伤和最终倍率仅在实际生效时显示。
- 取整只写“四舍五入”和“向下取整”，不显示 `round()`、`floor()`。
- 连击必须展示为“每段伤害 × 段数”，确保先完成单段取整。
- 四技能模式只展示当前高亮技能。
- 无法精确计算时显示缺少条件，不伪造算式。

## 验收标准

- 四行算式的最终结果与右侧结果栏完全一致。
- 不出现五步编号卡、重复中文段落、最终总结段或内部规则编号。
- 动态威力、天气、印记、减伤、最终倍率和追加伤害只在生效时进入对应算式。
- 桌面和移动端均可自然换行，不产生横向滚动。
