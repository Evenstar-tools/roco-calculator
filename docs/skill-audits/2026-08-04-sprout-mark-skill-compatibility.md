# 萌芽印记技能适配审计

## 审计口径

- 数据范围：`data/snapshots/current.json` 中的 553 个技能。
- 萌芽只追加“本次技能实际生效的自身正面固定数值”。
- 每层追加：双攻 `+1 层`、双防 `+1 层`、速度 `+10`、固定威力 `+10`、连击 `+1`。折射水系效果额外为能耗 `-1`。
- 百分比威力通常不适配；明确例外为放晴、点亮每层额外 `+10%` 光系威力，以及暴风眼每层额外 `+100%` 连击。减伤、回血、吸血、先手、能量、印记、异常、对敌减益和随机效果不属于本轮适配。
- 下方“不适配”只列出有相关描述、容易被误认为萌芽增益的技能；纯伤害、纯对敌效果和无数值增益技能不重复列出。

## 已检查但不适配

### 状态技能

- 百分比或非固定增益：贪婪。
- 按需求明确排除：漫反射保持每个唯一系别固定 `+35` 威力，不读取萌芽层数。
- 全技能能耗、蓄力或下回合效果：洗礼、盐水浴、赤子之心、龙守望、踏雷。当前引擎没有通用的“整组技能能耗永久偏移”状态，不写入一个看似生效、实际不参与后续计算的数值。
- 队伍、延迟或随机效果：假寐、虫茧、虫群智慧、振翅、叠加态、薄纱环。
- 技能栏位与历史累计：减压阀。它需要独立记录本技能和两侧技能的历史成长，本轮不猜测。
- 只回复生命或施加萌化：甜心续航。

部分适配：缓一缓、氧输送、气沉丹田、马步只追加其能力或速度增益，回血、回能和其他分支不追加。

### 攻击技能

- 队伍或随机效果：飞断、虫群过境、做好事、吃独食。
- 按需求明确排除：超级糖果、友谊满溢不读取萌芽加成。友谊满溢仍按实际使用次数累计永久威力，应对分支仍按技能原规则翻倍。

### 防御技能

- 百分比威力：淬火。点亮是明确例外，应对成功后每层萌芽额外增加 `10%` 光系威力。
- 先手、能耗、冷却或使用次数：有效预防、水环、能量守恒、硬化、壁垒、雪替身、电磁偏转。
- 回复、吸血或保命：血气、无畏之心、酶浓度调整、蜡质膜、等价交换、虚假破产。

## 本轮新增与修正

- 修正三连破：每次连击获得双攻 `+3层`，默认3连击时合计 `+9层`；实际连击变化时按实时连击数结算。
- 新增伺机而动：基础 `+70` 固定威力，每层萌芽再 `+10`。
- 新增焚毁：手动填写驱散印记层数，每层提供双攻 `+2 层`，萌芽再追加固定层数。
- 保留幼态延续的同类兼容规则；该技能不在当前 553 技能快照中，不计入上述数量。
- 超级糖果和友谊满溢按需求移出萌芽适配；撒娇仍追加固定威力，且不把一次使用错记为多次成长。
- 放晴、点亮每层萌芽增加 `10%` 光系威力；暴风眼每层萌芽增加 `100%` 连击。
- 漫反射移出萌芽适配，保持原本每个唯一系别固定 `+35` 威力。
- 修正空操作字段：百分比威力技能不再生成 `null` 的固定威力操作。
