# 技能累计增益与计算条件验收

日期：2026-09-14。Web/桌面 2.0.2，小程序 1.1.16，版本号保持不变；本轮仅本地提交，未推送或发布。

## 已确认范围

- 沿用原技能行，覆盖已适配的攻击、防御、纯状态技能；不新增明细折叠面板。
- 点击次数与连击数分开。防御未应对成功只显示实际减伤，成功后才记录能力或威力增益。
- 纯状态技能的次数控件与来源同步；不因无直接伤害丢失累计摘要，也不再显示为未知伤害规则。
- 纯状态技能未触发或取消后，次数设置保留，原效果区明确标为“触发后预览”，不冒充已生效增益。
- 只解释现有结算，不重复应用加成，不扩大未适配规则。当前攻击等级仍沿用既有双攻字段口径。
- 来源从血条下移入计算条件：12px 内容、正常字重的浅色标签、500 字重来源、可换行。无来源不占行。
- Web 独立点击入口补接来源记录；技能施加不会误标成手动。公式原项保留来源标注，不重复堆使用明细。
