# S5 性格计算：显示威力与奇遇防御

初稿2026-11-06，国服网页 v2.3.16；2026-11-07补充有限实录点和当前回放。依据用户交接《奇遇野怪数值公式交接.md》当日更新，保留 Claude 已完成的界面布局。

## 输入含义

- 自动：按本系、属性关系、双方骰子和我方特性计算显示威力，保留小数。自动伤害仍使用真实调整后的攻防；显示能力倍率沿用计算器本体规则。
- 手填 `displayedPower`：表示已包含本系、基础克制／抵抗、威力加成和攻防变化的本次技能栏威力。双方用原始攻防，不重复上述效果；奇遇极化／钝化与最终增减伤仍独立结算。
- 调整特性或骰子后，自动值即时更新；手填值保持锁定，清空即可恢复自动。仅凭一个显示威力无法反推出双方各自的能力变化。
- 游戏技能栏可能省略小数；已知 55 × 1.1 时填写 60.5。实际掉血填“实测／我方掉血”，不填入威力。
- 旧 `effectivePower` 仍表示最终威力，界面显式标识并可恢复自动。导入时不允许同时给出两种威力字段。

## 防御公式

未命中下列有限实录点时，沿用`D = c × ((10 + S × (L + 50) / 100) × 性格倍率 + 11)`，全程不取整。S 取同家族第三强度阶段防御；c 优先取原始物种编号对应的实测校准，没有校准时取所选野怪形态的强度阶段。

| 强度阶段 | 物防 c | 魔防 c |
|---|---:|---:|
| 1 | 1.806 | 1.806 |
| 2 | 1.65725 | 1.6005 |
| 3 | 1.38531 | 1.335 |

阶段3物防按原始伤害取整区间细化为 `(1.385292034739, 1.385332385742]`，避免把文档小数摘要误当精确边界。映射来自 PETBASE_CONF，保留缺失和不同进化分支，不能确定的双防不代入旧初始形态公式。

### 小翼龙物防校准 · 2026-11-06

按阶段2共用伊雷龙物防系数1.65725会把42级冷静小翼龙算成678／535／98；用户实测为684／540／99。捕获生命140、物防77与初始形态、42级、冷静（魔攻↑速度↓）一致，等级不应减一。

在罗隐60级、物攻312、10星、物攻骰子1.1条件下，显示威力418／330／60.5要求物防系数 `(1.6406907819531265, 1.6430539157811885]`。另一场42级物防↑、敌方全能骰子1.3、地刺207要求 `(1.642778499942017, 1.6507146279610605]`；两场交集内取 **1.643**，可同时复现四个伤害数。

校准只绑定包体源物种 **3209（小翼龙）** 的物防，魔防、生命、攻击及进化形态3210不变。预览与实测记录共用此入口；自动骰子和手填显示威力均保持原有小数运算。42级有中性与增加物防两组实测；41／43级及减物防沿现有等级、性格结构外推，不标为独立实测或服务器原公式。阶段2按物种共用倍率的旧结论已被这组数据否定。

## 验证与现存差异

可爱猿103／113／735、伊雷龙182／364、133／333、199／399，及深蓝鲸30条中性承伤均有回归。小翼龙新增684／540／99与旧207两场均吻合；保留锤头鹳超导480对481、燃薪虫藤绞454对456，以及旧伊雷龙火切134对157的矛盾记录。

非中性出伤保留极化上限1.8，双克制先合成3；8星以上承伤采用交接中的克制0.72／抵抗0.6实测折扣，并在页面标识。抵抗原0.59在2026-11-07随[本形态阶段双攻修正](s5-wild-stage-attack-20261107.md)更新，0.6仍是条件实测拟合。钝化未解为通用精确公式。各阶段防御系数仍为实测拟合，并非恢复出的服务器源码。

旧“实测记录”页仍限定中性简单单击，使用同一新防御模型；显示威力、特性与骰子的完整交互在主配招界面。
