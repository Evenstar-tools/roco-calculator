# 面板威力显示与威力区加算实施计划

> 对应设计：`docs/superpowers/specs/2026-08-17-panel-power-display-and-additive-power-zone-design.md`

## 1. 锁定行为

- 为显示设置的读取、写入、非法值回退增加失败测试。
- 为显示弹窗、单技能和四技能两种显示模式增加失败测试。
- 为雪原狩猎、扇风与特性/印记组合增加失败测试。

验证：目标测试在实现前按预期失败，且失败原因对应缺失功能。

## 2. 修正威力区

- 新增“布尔条件百分比加成”技能规则。
- 将雪原狩猎、扇风迁移到该规则。
- 将技能规则输出的百分比加成合并到现有威力百分比区。

验证：技能、特性、印记组合按加法合并，伤害和公式过程一致。

## 3. 接入显示设置

- 增加本地显示模式存储。
- 显示设置弹窗增加二选一控件。
- 单技能和四技能编辑器接入显示模式；面板威力只读。

验证：切换只改变显示，不改变配置和计算结果。

## 4. 回归与验收

- 运行计算、技能规则、显示设置和编辑器目标测试。
- 同步小程序共享核心并检查漂移。
- 运行数据校验、完整测试、验收、端到端和生产构建。
- 检查最终差异与空白错误。

验证：全部门禁通过；若失败则修复后重新执行相关门禁。
