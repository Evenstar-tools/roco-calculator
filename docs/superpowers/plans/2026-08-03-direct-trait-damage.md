# 刺肤直接特性伤害实施计划

> 关联设计：`docs/superpowers/specs/2026-08-03-direct-trait-damage-design.md`

## 任务 1：建立失败测试

- 新增直接特性规则测试：只识别刺肤并覆盖当前快照全部携带形态。
- 新增计算测试：固定 50 威力、无属性克制、本系/天气隔离、能力等级与减伤、逐段取整后乘连击。
- 新增 UI 测试：详细版和精简版双端栏位、单一高亮、结果栏独立行。
- 先运行专项测试确认红灯。

## 任务 2：实现状态和计算模型

- 新增 `src/domain/trait-damage.js` 规则目录并加入共享核心清单。
- 在方向状态中增加 `selectedDamageSource`、`traitDamageHitCount`，同步 reducer 与分享校验。
- 在 `calculateDirection` 中计算独立 `traitResult`，并根据伤害来源选择主结果。
- 在视图模型中暴露特性伤害行和选中状态。
- 同步共享核心并运行领域与状态测试。

## 任务 3：接入详细版、精简版和结果栏

- 在双端四技能编辑器技能 1 上方加入刺肤栏位。
- 接入连击修改与选中回调，保持攻防方向一致。
- 结果栏增加“特性造成伤害”行并复用伤害色阶。
- 增加响应式样式，窄窗口不产生遮挡或横向溢出。
- 运行 UI 与集成测试。

## 任务 4：专项回归

- 运行加尔/加灵/加益、黑化加尔双段与应对测试。
- 运行精简版性格预设 18 组矩阵、用户覆盖和记忆恢复测试。
- 运行普通单技能、四技能、反向计算和分享状态回归。
