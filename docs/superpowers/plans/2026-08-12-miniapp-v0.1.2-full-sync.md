# Mini-program v0.1.2 Full Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将桌面版触发、状态写回和结果能力完整同步到微信小程序，并按批准的手机/iPad视觉规范交付可编译的 v0.1.2。

**Architecture:** 把桌面 `App.jsx` 中的触发编排收敛为共享纯函数，小程序与桌面共用状态转换；小程序组件只编辑上下文和派发意图。手机采用主页面加稳定底部抽屉，iPad 采用双栏工作区，全部交互状态使用同一组设计令牌和真实 PNG 资产。

**Tech Stack:** React、Taro 4、Vitest、共享 ES modules、微信开发者工具、PNG/WebP 资源。

## Global Constraints

- 版本号固定为 `0.1.2`。
- 不引入云开发、支付、账号或新运行时依赖。
- 保留当前未提交改动，不改无关桌面功能。
- 先测试复现，再实现；每个功能切片完成后运行对应测试。
- 最终必须完成生产构建、真实微信运行、手机/iPad视觉与交互验收。
