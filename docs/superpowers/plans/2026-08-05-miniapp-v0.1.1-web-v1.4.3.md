# 微信小程序 v0.1.1 对齐网页版 v1.4.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将微信小程序升级为 `v0.1.1`，完整暴露网页版 `v1.4.3` 的确定性计算输入与结果说明，并完成生产构建、微信开发者工具导入和真机预览验收。

**Architecture:** 网页 `src/domain` 与已纳入 manifest 的 `src/state` 模块继续作为规则唯一来源，小程序只新增 Taro 输入组件、状态映射、持久化/分享适配和展示格式化。生产配置通过忽略提交的 `miniapp/local.config.json` 或进程环境变量注入；真实 AppID、云环境、文件 ID 和 SHA 不进入 Git。

**Tech Stack:** JavaScript ESM、React 18、Taro 4.2.1、Vitest 3.2.7、Testing Library、微信云开发、微信开发者工具。

## Global Constraints

- 小程序发布版本固定为 `0.1.1`，对齐的网页核心版本固定为 `1.4.3`。
- 根目录网页 `package.json` 的产品版本保持 `1.4.3`；不合入并行的 `v1.4.4` 发布加固改动。
- 不复制或分叉伤害公式；共享源改动只通过 `scripts/miniapp/shared-source-manifest.mjs` 和同步脚本进入 `miniapp/src/shared/`。
- 保持现有竖屏视觉语言，不重写页面结构，不新增登录、手机号、支付、广告、定位、通讯录、相册、摄像头或麦克风能力。
- 真实 AppID、云环境 ID、manifest 文件 ID、运行数据 SHA 仅存在于本地私有配置或环境变量；AppSecret 不得出现在仓库、前端产物、日志和验收材料中。
- 本轮外部边界止于开发者工具编译和扫码真机预览；不上传体验版、不提交审核、不正式发布。
- 每个任务只暂存其 `Files` 列出的文件；执行前后都用 `git status --short` 隔离并行工作区改动。

```js
export function getSkillInputs(skill) {
  const inputs = [
    ...(skill?.inputs ?? getSkillEffectInputs(skill)),
    ...getSkillStatusEffectInputs(skill),
  ];
  const seen = new Set();
  return inputs.filter((input) => {
    const id = input.id ?? input.contextKey ?? input.key;
    if (!id || seen.has(id)) return false;
    seen.add(id);
    return true;
  });
}

export function getVisibleSkillInputs(skill, context = {}) {
  return getSkillInputs(skill).filter((input) => {
    const condition = input.visibleWhen ?? input.when;
    if (!condition) return true;
    const key = condition.id ?? condition.contextKey ?? condition.key;
    return (context[key] ?? condition.defaultValue) === condition.equals;
  });
}
```

```js
export function createTraitView(snapshot, side, role, ownerSide) {
  const spirit = (snapshot?.spirits ?? []).find(
    (entry) => entry.id === side?.spiritId,
  );
  const trait = spirit ? getTraitView(snapshot, spirit, role) : null;
  if (!trait) return null;
  return {
    ...trait,
    controls: trait.inputs.map((input) => ({
      ...input,
      canonicalKey: canonicalTraitControlKey(input),
    })),
    ownerSide,
  };
}

export function createDirectionTraitViews(snapshot, state, direction) {
  const attackerSide = direction === "reverse" ? "defender" : "attacker";
  const defenderSide = direction === "reverse" ? "attacker" : "defender";
  return {
    attacker: createTraitView(snapshot, state.sides[attackerSide], "attacker", attackerSide),
    defender: createTraitView(snapshot, state.sides[defenderSide], "defender", defenderSide),
  };
}
```

```js
function formatResolutionStep(step) {
  const before = Number(step.before);
  const after = Number(step.after);
  const source = String(step.source);
  if (
    source.includes("speed-defense-difference") &&
    Number.isFinite(Number(step.input?.attacker)) &&
    Number.isFinite(Number(step.input?.defender))
  ) {
    const metric = String(step.label).startsWith("物防") ? "物防" : "速度";
    return `${metric} ${Number(step.input.attacker)} − ${Number(step.input.defender)} = ${before} → 威力 ${after}`;
  }
  if (source.includes("mana-burst")) {
    return `${Number(step.input)} 能量 → 威力 ${after}`;
  }
  if (source.includes("multiplier")) {
    const multiplier = before === 0 ? 0 : after / before;
    return `${before} × ${Number(multiplier.toFixed(2))} = ${after}`;
  }
  const difference = after - before;
  return `${before} ${difference >= 0 ? "+" : "−"} ${Math.abs(difference)} = ${after}`;
}

export function describePowerResolution(result) {
  const steps = result?.formulaSteps ?? [];
  const baseIndex = steps.findIndex(({ label }) => label === "基础威力");
  const candidates = baseIndex >= 0 ? steps.slice(0, baseIndex) : steps;
  const changed = candidates.find(({ before, after, source }) =>
    String(source).startsWith("reviewed-rule:") &&
    Number.isFinite(Number(before)) &&
    Number.isFinite(Number(after)) &&
    Number(before) !== Number(after),
  );
  return changed ? formatResolutionStep(changed) : null;
}

export function decoratePowerResult(result) {
  return {
    ...result,
    displayedPower:
      result?.resolvedPower ?? result?.skillPower ?? result?.effectivePower ?? null,
    powerSummary: describePowerResolution(result),
  };
}
```
