# S3 季中数据与小程序同步设计

## 目标

将桌面端已经验证的 2026-08-13 S3 季中平衡调整同步到统一核心和微信小程序，并补齐 BWIKI 当前目录中缺少的宝藏小狐、宝藏沙狐，使网页端与小程序共享同一份 594 精灵离线快照。

## 数据边界

- 平衡规则以 `D:/codex/rock-calculator-public` 已通过测试的季中补丁为基线，只同步数据、领域规则和对应测试。
- 两只新增精灵以 BWIKI 精灵筛选页及详情页的固定修订为来源，补齐种族值、特性、学习技能、进化链和图片来源。
- 不同步桌面工作区中的首次引导、推广设置、窗口外观等无关改动。
- 运行时继续使用仓库内离线快照，不在小程序启动时联网抓取数据。

## 数据流

1. 在旧 S3 快照上应用两只精灵的目录补丁，验证所有技能引用均已存在。
2. 应用 2026-08-13 季中平衡补丁，生成 `s3-2026-08-13-midseason` 快照。
3. 同步图片清单，生成网页运行时快照和小程序 bundled runtime。
4. 通过共享核心同步脚本将领域规则复制到小程序，禁止手工维护两份实现。

## 验收

- 快照包含 594 个精灵、594 个学习集、228 个特性，且包含宝藏小狐、宝藏沙狐和博物。
- 两只精灵的全部学习技能均能解析到现有技能库，图片 URL 可用。
- 五项种族值、三项技能、两项特性和季中规则计算与桌面端一致。
- 数据验证、根项目全量测试、小程序全量测试、生产构建与微信开发者工具运行均通过。
- Git 提交和微信代码上传仅在上述门禁通过后执行。
