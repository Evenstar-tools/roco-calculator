# 小程序手机端上线基础 UI 设计

## 目标

将 320–430 px 竖屏手机端重构为可正常操作、信息层级稳定、视觉接近确认稿的对战计算界面；保持现有计算、记忆、收藏配置、分享和 iPad 布局不变。

- 当前问题证据：`C:\Users\ADMINI~1\AppData\Local\Temp\codex-clipboard-37a4b45e-b449-4559-a307-7134b73a6595.png`。
- 视觉原则：白底、细分隔线、攻击红/防守蓝、结果红/绿；不使用渐变、玻璃卡片或多层阴影。

## 手机端结构

1. 顶栏：单行标题与两个安静的辅助操作；不显示版本微文案。
2. 对战区：双方精灵各占半屏，真图为主要视觉；攻击/防守、名称、属性集中成一组，中央只保留攻守切换。
3. 快速配置：只显示当前计算方向对应的一方；“性格”和“个体”各一行，真实六维图标按统一基线排列；详细设置不占主界面空间。
4. 模式切换：固定宽度的“单 / 四”分段控件，选中状态为深色底，触控高度至少 44 px。
5. 技能列表：每行由属性图标、技能名称、单行元数据、伤害与 HP 比例组成；元数据不竖排、不挤压技能名。
6. 条件栏：单行入口，清晰显示条件类别与数量。
7. 结果：改为内容流中的大结果卡，不再固定遮挡技能和条件；显示伤害、比例和详情入口。

## 交互

- 点击左右精灵卡片：切换当前计算方向并打开对应精灵搜索。
- 点击中央切换：交换攻守双方。
- 点击性格/个体图标：立即更新，选中态只用边框和轻底色表达。
- 点击“单 / 四”：即时切换技能模式。
- 点击技能行：选择该行并更新底部结果。
- 点击条件或详情：打开现有底部面板，关闭后恢复焦点。

## 响应式与上线门槛

- 320、375、390、430 px 无横向溢出、重叠、文字竖排或不可点击区域。
- 375/390/430 与确认稿保持同一信息顺序和主要比例；320 允许紧凑缩放，但不改变顺序。
- 关键触控区域高度至少 44 px。
- 手机端样式只在 `max-width: 767px` 生效；iPad 断点保持原行为。
- 浏览器控制台无错误；206 项小程序测试和发布门禁通过；微信主包不超过 2 MiB。
