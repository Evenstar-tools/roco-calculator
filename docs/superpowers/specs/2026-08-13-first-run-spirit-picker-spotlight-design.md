# 初次引导精灵选择聚光框设计

## 目标

修正初次使用引导第 1、2 步的高亮范围，让用户在选择攻击方和防御方时，先明确看到输入栏，展开后再完整看到可选精灵列表，不再由一个固定大框覆盖精灵卡或空白区域。

## 交互规则

- 未点击输入栏时，高亮框只包围当前一侧的精灵搜索输入栏。
- 点击或聚焦输入栏、下拉列表展开后，高亮框平滑扩大，范围覆盖输入栏和当前可见的精灵列表。
- 选择精灵、按 `Esc` 或失焦关闭列表后，高亮框恢复为只包围输入栏。
- 攻击方与防御方使用同一套行为；第 1 步只响应攻击方，第 2 步只响应防御方。
- 引导说明卡随高亮范围重新定位，不能遮住输入栏、下拉选项或滚动条。
- 页面滚动、窗口缩放、列表继续加载时，高亮框实时贴合目标，不闪烁、不跳到旧位置。

## 实现边界

- 不修改精灵搜索、收藏排序、增量加载、选中和配置恢复逻辑。
- 不修改六步引导的步骤、文案、跳过与完成状态。
- 不新增运行时依赖。
- 仅调整引导目标标记、目标范围计算及相关样式和测试。

## 组件设计

### 精灵选择器

引导目标从整个精灵选择卡收敛到搜索区域。搜索区域保留稳定的引导标记；下拉列表继续属于同一选择器，但不依赖父元素高度参与测量。

### 引导层

引导层根据选择器状态计算目标矩形：

- 收起状态：使用搜索区域矩形。
- 展开状态：取搜索区域与可见下拉列表矩形的并集。

引导层监听目标属性、子节点和尺寸变化。下拉列表创建、继续加载或关闭时立即重新测量，避免必须滚动或缩放窗口后才更新。

### 视觉

- 沿用现有紫色聚光框和遮罩，不增加新的颜色体系。
- 收起状态保持紧凑边距。
- 展开状态覆盖完整可见列表，圆角与选择器一致。
- 范围变化使用短时过渡，禁止明显拉伸闪烁。

## 验收标准

- 第 1 步初始高亮仅包围攻击方输入栏。
- 攻击方下拉展开后，高亮覆盖输入栏和列表；关闭后恢复。
- 第 2 步对防御方表现一致。
- 高亮框不覆盖另一侧选择器，也不包含已选精灵展示卡。
- 引导说明卡在桌面和窄窗口都不遮挡精灵选项。
- 下拉增量加载时高亮高度同步更新。
- 既有精灵选择和首次引导流程测试继续通过。

## 测试范围

- 组件测试：收起矩形、展开并集矩形、关闭恢复、DOM 变化自动重测。
- 端到端测试：攻击方和防御方分别验证展开前后范围、说明卡不遮挡、选择后正确进入下一步。
- 响应式测试：桌面与常见窄窗口验证无溢出、错位和闪烁。
