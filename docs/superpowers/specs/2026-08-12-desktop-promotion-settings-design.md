# 桌面版推广入口设计

## 目标

在不打断伤害计算主流程的前提下，把用户提供的 193 只热门精灵配置作为离线内置配置库，并补充清晰的数据来源与反馈入口。

## 已确认交互

- 系统菜单新增 `常用精灵配置`，显示内置数量 `193`。
- 点击后进入独立预览弹窗，不静默覆盖本机配置。
- 预览继续复用现有配置库校验：新增配置、覆盖本机配置、新增收藏、兼容问题与精灵技能清单均由当前数据实时计算。
- 确认导入后，通过现有原子导入流程写入收藏和个人精灵配置；只覆盖文件中同 ID 精灵，不修改队伍和当前计算页。
- 内置 JSON 随桌面包离线提供，不增加网络依赖，也不增加运行时依赖。
- 系统菜单新增 `数据来源`，弹窗展示：洛克王国：世界 BWIKI、公开资料与实机校验、问题反馈 QQ `1215583051`，支持复制 QQ。

## 视觉与文案

- `常用精灵配置` 使用紫色主操作强调，数量以轻量徽标显示。
- 弹窗沿用现有配置库卡片、指标和按钮，不新造一套模板。
- 提示明确写明：`只覆盖同名精灵配置，队伍与当前页面不会改变。`
- 数据来源链接使用现有 BWIKI 地址：`https://wiki.biligame.com/rocom/`。

## 验收

- 冷启动不加载 90 KB 配置文件；只有点击入口时才请求本地资源。
- 断网桌面环境能打开预览并导入。
- 内置文件 193 条全部经过当前快照校验；数量或兼容问题以真实预览结果为准。
- 导入后收藏与完整配置状态立即刷新，重启仍保留。
- 键盘、窄窗口和深色模式可用。
