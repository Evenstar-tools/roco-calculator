# 精简版性格预设设计

## 目标

精简版继续让用户只选择性格的正面属性，但生成的完整性格不再使用固定攻防方映射，而是根据当前物攻、魔攻个体加点选择更合理的负面属性。

该逻辑只属于快捷预设。具体版手动选择、配置记忆、配置库导入、分享配置和队伍载入中的具体性格均保持用户原值。

## 交互规则

1. 用户在精简版点击生命、物攻、魔攻、速度、物防或魔防增益按钮。
2. 系统读取当前一侧的物攻和魔攻个体值。
3. 只有个体值等于 `60` 才视为已选择。
4. 根据正面属性和两项攻击个体的选择状态，生成一个确定的完整性格。
5. 后续调整个体不会自动重算性格，避免覆盖用户选择。
6. 用户再次点击正面属性按钮时，才按最新个体重新生成预设。

## 性格映射

| 正面属性 | 仅物攻个体为 60 | 仅魔攻个体为 60 | 两者都有或都没有 |
| --- | --- | --- | --- |
| 生命 | 平和（+生命、-魔攻） | 沉默（+生命、-物攻） | 踏实（+生命、-速度） |
| 物攻 | 固执（+物攻、-魔攻） | 勇敢（+物攻、-速度） | 勇敢（+物攻、-速度） |
| 魔攻 | 冷静（+魔攻、-速度） | 聪明（+魔攻、-物攻） | 冷静（+魔攻、-速度） |
| 速度 | 开朗（+速度、-魔攻） | 胆小（+速度、-物攻） | 莽撞（+速度、-魔防） |
| 物防 | 天真（+物防、-魔攻） | 稳重（+物防、-物攻） | 悠闲（+物防、-速度） |
| 魔防 | 害羞（+魔防、-魔攻） | 警惕（+魔防、-物攻） | 慎重（+魔防、-速度） |

点击“普通”仍直接设置为无修正性格，不读取个体。

## 代码边界

- 在性格领域模块中提供纯函数：输入正面属性和当前个体，返回标准性格 ID。
- `QuickNaturePicker` 接收当前个体，并只在用户点击增益按钮时调用该函数。
- 不在 reducer 中增加自动联动，不增加“预设/手动”状态字段，不升级本地存储结构。
- 攻击方与防御方共用同一映射。双方差异完全由各自当前个体配置产生。

## 记忆与兼容性

- 快捷预设生成后仍通过现有 `side/set-nature` 写入状态，因此继续进入当前精灵配置记忆。
- 具体版手动改动继续以具体性格 ID 保存，切换模式、重启、导入或分享后不重新推导。
- 旧配置和旧记忆不迁移、不重写。
- 队伍成员和详细模式的性格选择器不使用本次预设函数。

## 测试与验收

- 领域测试覆盖六种正面属性与三种攻击个体状态，共十八个映射。
- 覆盖非 `60` 数值不视为勾选的边界。
- UI 测试验证双方均读取自己的个体配置。
- UI 测试验证修改个体后不会自动覆盖已选性格。
- UI 测试验证再次点击正面属性会按最新个体重算。
- UI 测试验证具体版手动性格在切换模式和记忆恢复后保持不变。
- 既有分享、配置库、队伍和伤害计算测试必须全部通过。
