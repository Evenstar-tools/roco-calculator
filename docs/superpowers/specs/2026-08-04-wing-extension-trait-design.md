# 凡鹰“展翅”与疾风涡轮设计

## 目标

为凡雀、紫翎鹰、凡鹰家族的“展翅”特性补齐三项确定性规则：自身普通系技能按翼系结算；防御方可开关后手承伤增加；疾风涡轮可与一个已携带技能组合结算。

## 规则

### 展翅属性转换

- 仅当当前出招精灵拥有“展翅”时，将它自己的普通系技能按翼系结算。
- 转换覆盖属性克制、本系加成、结果标签和技能列表属性展示。
- 不修改技能原始数据，不影响对方或其他精灵。
- 原生翼系及其他系技能保持不变。

### 防御方负面特性

- 防御方拥有“展翅”时展示“后于对手行动”勾选框。
- 勾选后最终承伤乘 `1.25`；未勾选不生效。
- 该状态属于当前战斗输入，不自动继承到其他精灵。

### 疾风涡轮组合结算

- 四技能模式选中疾风涡轮时，展示“前置翼技”选择框，候选为同侧另外三个技能槽。
- 未选择前置技能时，按方案 B 只计算疾风涡轮自身伤害。
- 选择攻击技能时，前置技能和疾风涡轮分别执行完整伤害计算、分别取整，再相加为总伤害。
- 前置普通系技能若由“展翅”转换为翼系，应按转换后的翼系参与计算。
- 选择变化或防御技能时，只计算疾风涡轮自身伤害，不显示双段伤害说明。
- 双攻击技能时结果显示：`前置技能 A + 疾风涡轮 B = 合计 C`，公式过程分别标记两段。
- 组合选择保存在疾风涡轮所在技能槽上下文中；换掉该槽技能后不沿用。

## 界面

- 技能属性标签直接显示实际结算属性；普通转翼时显示“翼”，悬停说明仍保留原技能描述。
- 疾风涡轮的组合选择放在技能描述下方，不扩展新的全局高级选项。
- 结果栏沿用加尔家族的分段说明样式，并使用技能名替代“第一段/第二段”。

## 验收

- 凡鹰的普通物理技能按翼系克制和本系加成计算；对方同名普通技能不受影响。
- 展翅防御开关仅勾选时使总伤害增加 25%。
- 疾风涡轮单独、组合攻击技能、组合变化技能三种状态结果正确。
- 双段伤害等于两段各自取整后的和。
- 攻防方向切换、四技能列表、结果栏、分享与精灵记忆不丢失现有功能。
