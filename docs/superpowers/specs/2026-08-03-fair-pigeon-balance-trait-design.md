# 公平鸽「衡量」特性设计

## 目标

让公平鸽能够按特性描述复制对方的正面能力等级，并在详细版中看见、调整原本隐藏的攻击方防御等级与防御方攻击等级。

## 交互与规则

- 公平鸽的「衡量」显示一个“触发衡量”勾选框，攻防位置均可使用。
- 从未勾选切换为勾选时，公平鸽复制对方当前大于 `0` 的攻击与防御能力等级；负面和零等级不复制。
- 勾选保持期间，对方点击增益状态或防御技能后，本次实际增加的正面攻击、正面防御能力等级同步增加给公平鸽。
- 公平鸽自身点击增益技能时，不把增益反向给对手。
- 取消勾选只停止后续复制，不清除公平鸽已经获得的等级。
- 层数仍限制为 `-50..50`，复用现有能力等级结算，不新增倍率乘区。

## 状态映射

沿用现有方向状态，不新增重复字段：

- 攻击方攻击等级：`forward.overrides.attackLevelStage`
- 攻击方防御等级：`reverse.overrides.defenseLevelStage`
- 防御方攻击等级：`reverse.overrides.attackLevelStage`
- 防御方防御等级：`forward.overrides.defenseLevelStage`

## UI

- 任一方是公平鸽时，详细版双方都展示攻击与防御两行能力等级。
- 没有公平鸽时维持现状，每方只显示当前攻防方向相关的一行，不增加页面高度。
- 新增行使用现有加减按钮、长按连续调整、百分比显示和红蓝侧色。
- 精简版不增加常驻等级控件；技能区仍显示「衡量」触发入口。

## 边界

- 本轮只复制攻击与防御能力等级，不复制速度、固定威力、技能威力、连击、生命、印记或天气。
- 只复制正面增量；减益不会反向变成公平鸽的减益。
- 两边都是公平鸽时，同一次技能增益只从施放方复制到另一方一次，不递归回传。
- 触发态属于当前战斗状态，不进入个人配置库的稳定特性字段。

## 验收

- 公平鸽在攻击方或防御方时均出现“触发衡量”。
- 勾选时能复制另一边已存在的正面攻击、防御等级。
- 保持勾选后，另一边点击增益技能，公平鸽同步得到对应正面增量。
- 负面等级、减益技能和公平鸽自身增益不触发复制。
- 任一方有公平鸽时能编辑两项隐藏等级；移除公平鸽后恢复单行 UI，已存状态仍参与计算。
- 单元、UI 集成、Web 全量、小程序共享核心和生产构建全部通过。
