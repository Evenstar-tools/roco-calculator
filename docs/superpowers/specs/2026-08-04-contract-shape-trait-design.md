# 契约的形状特性设计

## 目标

为陨星虫、落星虫、星尘虫的“契约的形状”提供稳定的咕噜球选择，并把能确定影响伤害的入场效果接入双方计算。选择属于精灵长期配置，攻防换位后仍可恢复。

## 依据

效果以 BWiki 陨星虫页面的“特殊效果”表为准：普通、高级、国王、美妙、调温、光合、网兜、绝缘、淘沙、变幻、暗星、捕光、棱镜共十三种。

## 交互

- 特性栏显示“咕噜球”下拉框；未选择时不应用效果。
- 选择“棱镜球”后追加“棱镜效果”下拉框，让用户明确本次随机到哪一种球，计算按该效果数值减半。
- 两个字段均为方向级稳定配置，进入个人配置记忆、收藏配置库导入导出；不保存本回合临时状态。
- 攻击方和防御方各自独立选择，效果按照当前所在角色映射。

## 计算映射

| 咕噜球 | 计算效果 |
| --- | --- |
| 普通球 | 自身双攻、双防、速度 +10% |
| 高级球 | 自身双攻、双防、速度 +20% |
| 国王球 | 自身双攻、双防、速度 +30% |
| 美妙球 | 对手双攻 -30%；自身技能威力 +20 |
| 调温球 | 记录对手灼烧 4 层、冻结 2 层，不虚构额外伤害 |
| 光合球 | 连击技能连击数 +1；能耗 -1 仅作说明 |
| 网兜球 | 自身速度 +50；对手中毒 2 层 |
| 绝缘球 | 对手速度 -40、物防 -40%、连击技能连击数 -2 |
| 淘沙球 | 自身双防 +30%；对手星陨 1 层 |
| 变幻球 | 记录吸血 +30%、对手能量 -2，不改写当前 HP/能量 |
| 暗星球 | 自身物攻 +40%；对手魔防 -40% |
| 捕光球 | 无效果 |
| 棱镜球 | 用户选择上述一种效果，所有数值减半；层数/连击等离散量向零取整 |

百分比能力变化复用现有每层 10% 的能力等级计算，不再额外乘一次，避免重复计算。

## 结果说明

结果栏通过 `traitSettlements` 显示已选球及实际生效效果。调温、变幻、能耗等不直接进入本次伤害的内容明确标注“仅记录”。棱镜球同时显示原球名称和半值处理。

## 验收

- 三个家族形态均出现相同控件。
- 普通/高级/国王、美妙、光合、网兜、绝缘、淘沙、暗星可改变对应伤害、速度、连击、印记或中毒上下文。
- 非伤害效果不凭空增加伤害。
- 棱镜效果只有选择棱镜球时显示，且按半值计算。
- 双方换位、个人记忆和配置库往返不丢字段。
- 既有特性与伤害测试无回归。
