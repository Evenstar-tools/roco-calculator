# 洛克计算器首次使用引导设计

## 目标

让第一次安装洛克计算器的用户从精简版开始，按 `1/6` 至 `6/6` 完成一次真实操作路径。

## 最终视觉方案

采用已确认的组合稿：前五步使用局部聚光提示，第六步使用右侧紧凑导入卡。视觉参考为：

`C:/Users/Administrator/.codex/generated_images/019f8e48-0471-7152-8f47-165c8903d6c1/exec-edde9e57-9201-4fbb-b4d1-81a33bc4e634.png`

引导沿用现有白灰底、紫色交互色、红蓝攻防色、8px 圆角和轻阴影，不新增插画、欢迎页或品牌大横幅。

## 六步流程

1. `先选攻击方`
   - 聚光攻击方精灵选择区。
   - 辅助文案：`选择本回合出手的精灵`。
2. `再选防御方`
   - 聚光防御方精灵选择区。
   - 辅助文案：`选择本回合承伤的精灵`。
3. `选性格和个体`
   - 聚光精简版双方快捷配置区。
   - 双方只需选择正面性格；六项个体默认全部为 60，可按需取消。
4. `单技能 / 四技能`
   - 聚光技能配置区；单技能用于看一招细节，四技能用于直接比较双方伤害。
5. `需要细调时`
   - 聚光顶部具体版入口，主操作 `前往具体版` 会真实切换界面后进入下一步。
6. `导入热门配置`
   - 显示内置 PVP 配置库数量和简短说明。
   - 明确写出：`以后修改性格、个体和技能，都会继续记住`。
   - 主操作：`导入并完成`；次操作：`上一步`；弱操作：`跳过`。

## 触发与记忆

- 每台机器第一次成功加载应用时自动出现一次。
- 点击任一步的“跳过”即视为已完成，后续启动不再自动出现。
- 完成第六步导入或直接跳过后都写入本机完成标记。
- 系统菜单保留 `新手引导` 入口，可随时重播；重播不改变首次触发标记。
- 引导完成状态只保存在本机，不进入分享链接、配置库或队伍数据。

## 导入边界

- 第六步复用现有内置配置库解析、预览和原子导入，不另写第二套导入逻辑。
- 导入失败时保留在第六步并显示原因，不写入半套数据。
- 导入成功后刷新收藏和精灵记忆，不切换当前双方精灵，不修改队伍。
- 内置配置可离线使用；配置导入后，用户后续修改仍由现有自动记忆机制保存。

## 响应式与无障碍

- 桌面提示卡靠近目标放置并限制在视口内。
- 窄窗口改为底部提示卡，避免遮挡目标和页面操作。
- 聚光层不阻断目标控件，用户可在引导中直接选择精灵或技能。
- 提供清晰的步骤计数、按钮名称和实时提示；键盘可操作全部按钮。

## 验收标准

- 清空完成标记后启动，显示第 1 步。
- 跳过后重启不再自动显示。
- 菜单点击 `新手引导` 可重新显示第 1 步。
- 前进、后退和缺失目标场景均不报错、不跳动、不溢出。
- 第 5 步能切换具体版，第 6 步能导入内置热门配置，成功后关闭并显示导入结果。
- 导入前后的队伍存储和当前页面配置保持不变。
- Windows 离线安装后仍能完成六步流程和内置配置导入。
