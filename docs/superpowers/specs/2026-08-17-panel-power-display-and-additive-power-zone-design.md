# 面板威力显示与威力区加算设计

## 目标

1. 在“显示设置”中允许用户切换技能栏显示“技能威力”或“面板威力”。
2. “面板威力”对应游戏界面最终显示值，包含本系、属性克制、天气、能力等级等显示威力乘区。
3. 修正同一技能威力百分比乘区：技能条件、特性、印记与状态提供的百分比加成先相加，再整体乘入基础威力。

## 交互

- 显示设置增加二选一分段控件：`技能威力` / `面板威力`。
- 默认保持“技能威力”，不改变现有用户习惯。
- 四技能模式切到“面板威力”后，威力列只读，避免把最终面板值误写回基础威力。
- 单技能模式切换后，仅改变右侧醒目数值的展示口径；手动基础威力与“游戏内威力”计算覆盖功能保持原样。
- 设置仅保存在本机，不进入分享链接、队伍、配置库或计算状态。

## 计算规则

同一威力百分比区采用：

```text
有效技能威力 = （基础威力 + 固定威力）×（1 + 技能条件加成 + 特性加成 + 印记加成 + 状态加成）
```

本次明确修正：

- 雪原狩猎：技能条件 `+50%` 与冰雪魂魄 `+100%` 加算。
- 扇风：技能条件 `+50%` 与顺风 `+50%` 加算。
- 蓄势、风起继续进入同一威力百分比区。
- 愿力冲击、回旋踢等替换或独立倍率规则不借本次改动改变语义。

## 兼容与回退

- 不修改分享参数、队伍、配置库和本地计算状态结构。
- 新设置使用独立存储键，旧用户默认回退到“技能威力”。
- 保留改动前 Git 分支 `backup/panel-power-before-20260817-0155`，可整组回退。
- 计算结果继续保留现有字段，避免破坏 Web、桌面和小程序共享核心。

## 验收

- 切换显示设置不会改变伤害结果。
- 四技能面板威力只读，技能威力仍可按原方式编辑。
- 雪原狩猎与冰雪魂魄、扇风与顺风、蓄势与风起的组合结果符合加算规则。
- 公式过程只显示一个合并后的威力加成区。
- 相关单元、UI、共享核心、构建与端到端测试通过。
