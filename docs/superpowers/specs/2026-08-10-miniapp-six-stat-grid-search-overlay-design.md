# 小程序六维快捷配置与搜索浮层设计

日期：2026-08-10
版本：小程序 v0.1.1，网页核心 v1.4.3
状态：用户已确认最终合并设计稿

## 目标

在不修改计算核心、记忆系统、收藏配置与分享协议的前提下，按确认稿修正手机主页面的六维快捷配置和精灵搜索浮层：性格与个体严格同列，已选正面性格可再次点击恢复普通，搜索输入及结果列表不超出任何目标手机视口。

## 界面与交互

- 快捷配置固定为一个标签列和六个等宽能力列，顺序为：生命、物攻、魔攻、速度、物防、魔防。
- “普通”属于“性格”标签列，不作为第七个能力列。
- 性格行与个体行共用同一网格；同一能力的两个图标垂直居中对齐。
- 个体行直接显示当前值 `0` 或 `60`，选择状态沿用绿色边框和浅绿色底。
- 点击未选中的正面性格应用现有紧凑性格预设；再次点击当前正面性格立即写入 `neutral`，界面回到“普通”，不保留任何增减益。
- 搜索输入与结果列表使用同一组左右 `14px` 安全边距，以 `left: 14px; right: 14px; width: auto; box-sizing: border-box` 约束；遮罩点击继续关闭并清空搜索。

## 验收

- 组件测试证明六维列顺序一致、每行只有一个标签列和六个能力列。
- 交互测试证明已选正面性格再次点击后 store 中性格为 `neutral`。
- CSS 测试证明不存在 `repeat(7, ...)`，输入与结果列表均使用左右安全边距和自动宽度。
- 320、375、390、430 宽手机视口无横向溢出、裁剪或错列。
- 小程序全量测试、生产构建、包体门禁和真实微信开发者工具编译通过；`design-qa.md` 最终为 `passed`。
