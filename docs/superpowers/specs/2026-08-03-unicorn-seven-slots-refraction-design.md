# 彩虹独角兽七技能槽与折射设计

## 目标

只为特性为“夺目”的彩虹独角兽开放七个携带技能槽，并让“折射”按本次携带技能的唯一系别，一次性应用当前版本的系别效果。既有四技能精灵、旧分享、旧配置和旧队伍继续按四槽工作。

## 已确认规则

- 小独角兽、白金独角兽仍为四槽；彩虹独角兽因“夺目”额外获得三个槽位，共七槽。
- 七个槽位都参与技能伤害计算、结果栏切换、配置记忆、分享、配置库导入导出和队伍成员保存。
- “折射”只统计当前携带的其他技能；折射本身不贡献光系。若想获得光系效果，必须再携带一个光系技能。
- 同一系别每次释放只结算一次；重复点击“折射”会再结算一轮。
- 点击输入框只编辑技能，不算释放；点击技能行的非输入区域才应用状态。
- 技能行下面显示“本次可得”摘要，最多两行，悬停仍可查看完整技能描述。

## 结构设计

1. `skill-slot-capacity` 只负责从精灵/特性得出槽位数，并提供按容量补齐、裁剪的方法。
2. `refraction` 只负责去重系别、生成效果增量和短摘要，不直接修改 React 状态。
3. 现有技能状态应用入口消费折射结果，沿用能力等级、方向修正、生命和印记的既有更新通路，避免重复计算。
4. 状态、分享、配置库和队伍允许四槽或七槽；读取旧四槽数据不扩写、不报错。选择彩虹独角兽时才补齐到七槽。
5. 结果列表按真实技能槽数量渲染；未选择的槽位仍显示空态，但不制造伤害结果。

## UI 约束

- 七槽维持现有列表密度，不新增卡片或说明面板。
- 技能描述最多两行；折射摘要同样最多两行，完整内容通过悬停标题读取。
- 行内字段在窄窗口允许重排，但技能名、威力、连击和伤害占比不能互相遮挡。
- 当前选中行继续使用攻防方既有高亮色，不新增第三套高饱和颜色。

## 证据来源

- BWiki 彩虹独角兽：“夺目”额外获得三个未携带随机技能。
- BWiki 折射：当前 18 系效果表。
- 3DM 2025-12-30 调整记录：电、机械、光、武、普通五项 S2 削弱数值。

## 验收

- 彩虹独角兽显示并保存七槽，其他精灵仍为四槽。
- 七槽每个攻击技能都可在结果栏独立计算和选中。
- 同系多个技能每次折射只触发一次；另一光技能存在时才触发光效果。
- 连续点击两次折射，所有可叠加效果累计两次。
- 旧四槽分享、配置库和队伍数据正常读取。
- 1920、1280 和窄窗口下无遮挡，说明不超过两行。
- 本轮不打包。
