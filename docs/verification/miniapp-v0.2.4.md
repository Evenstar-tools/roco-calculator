# 微信小程序 v0.2.4 验收记录

## 本次整理

- 将长期累计的小程序业务代码、共享计算核心、数据文件、头像资源和自动化测试收敛到独立分支。
- 合并桌面端 `v1.5.7` 后续补丁，保留小程序既有交互、触发工作台、分享恢复和属性分析开关。
- 静态威力与面板威力使用统一数据结构，可在单技能和四技能结果详情中切换、保存、分享并恢复自动值。
- 手动面板威力直接作为最终面板威力结算；手动静态威力继续接受后续明确声明的乘区。
- 静态威力/面板威力只切换查看口径时不写入覆盖；手动静态威力不重复叠加固定威力，手动面板威力不重复应用面板乘区。
- `天旋地转`、`电弧`、`引雷`、`电流刺激`的迸发默认开启且可手动取消；`雷暴`默认开启迸发，并按已生效迸发种类每种增加 `10` 威力。
- 恢复自动、换技能和换精灵会清除临时威力覆盖；单技能、四技能、正反方向、配置记忆和分享恢复均保留威力模式语义。
- 将当前计算的攻击、防御能力等级从主页收进“战斗条件”，原有加减、方向切换和重置逻辑保持不变。
- 小程序版本更新为 `0.2.4`，更新日期为 `2026-08-18`。
