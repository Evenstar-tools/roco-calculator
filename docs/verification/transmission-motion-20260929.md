# 传动动效与特殊行动适配

## 本轮范围

用户要求调研游戏里的传动表现、补动效，尤其保护现有计算，并适配轮班及相关特性。沿用既有四槽布局、配色和回合操作；未更改伤害公式、普通传动算法、固定槽规则或数据快照。未推送、未发布。

## 游戏表现取证

- 来源：[两分钟让你理解传动的基本逻辑【洛克王国：世界】](https://www.bilibili.com/video/BV1c19KBsELC/)，辞锦只应天上有，2026-04-03。
- 29.58–36.30 秒字幕描述钢铁洪流从 3→4→1；64.34–85.76 秒描述 2211 先全体移动一层，再由原 1、2 号位技能同时移动第二层。
- 已核对平台返回的带时间戳字幕及视频快照，画面为游戏配招与战斗。视频流连接重置，未连续观看原游戏动效，不能确认路径曲线、时长或特效。因此本轮是按逐层、同层同时移动设计的计算器动效，不是逐帧复刻。
- 材料位于本地忽略目录 `output/transmission-research/BV1c19KBsELC/`。动画 420ms/层为本项目交互参数，不是游戏测量值。

## 实现与安全边界

- 点击操作时仅结算一次，立即保存权威终态、记录、冷却和风速仪累计。独立展示层只播放 `steps`，完成回调仅清除展示层，绝不再次计算或回写槽位。
- 技能身份使用本次操作输入的实例索引，支持重复技能；回合轨迹已有 `slots/keys/remaining`，行动轨迹沿用同结构。
- 轮班加威分支不移动；额外传动、有求必应另一分支、一意孤行同分支追加按引擎轨迹依次播放。修正原先通过技能 ID 查找轮班、误移动另一张重复技能的问题。
- 特性列表补有求必应、一意孤行；冷却及追加来源统一使用有效特性。原生加尔/黑化加尔次回合冷却、待机恢复与回退保持一致。
- 补杠杆置换的轻量行动入口；可指定每一张轮班。固定邻居冲突仍明确阻断，不凭动效猜规则。
- 向心力、翼轴、贪心算法的层数仍只在回合开始领取；固定技能保持原位；风速仪只按结算累计；正位宝剑、宝剑王牌的槽位限制保持不变。
- 播放时禁止再次推进或结算，可跳过、撤回、重置、换精灵、切布局或关闭；取消动画时不会有迟到结果覆盖新状态。尊重系统减少动态效果，无动画 API 时直接显示终态。
- 盲拧的随机先后、技能替换/跨精灵移动及固定槽交换冲突仍未确认，保留原阻断。机械变式仍只推演顺序，不新增未验证的能耗累计。这些不能标作本轮已完成新规则支持。
