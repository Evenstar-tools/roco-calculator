# 微信小程序 v0.1.2 验收记录

验收日期：2026-08-13
分支：`main`
小程序版本：`0.1.2`
桌面版版本：`1.5.2`

## 交付结论

v0.1.2 已完成桌面版计算核心、技能/特性触发状态写回和小程序交互层同步；手机竖屏与 iPad 双栏均已通过生产构建、自动化尺寸检查和微信开发者工具原生运行检查。最终生产包未包含云开发、支付或账号能力。

## 已同步功能

- 桌面版与小程序共用 31 个领域和状态模块，并由核心漂移检查阻止两端代码分叉。
- 新增共享技能使用后状态转换：能力等级、固定威力、速度、连击、回血、印记、减防、持续成长、选择技序列和平衡状态均可写回。
- 战斗作用域特性、全局雨天、无差别过滤、直接特性伤害源和次数均真正进入计算状态。
- 特殊精灵支持七技能槽；技能筛选支持中文、类型、分类、拼音和首字母。
- 设置页保留配置记忆、193 只常用精灵一键导入、重置本页、数据来源与反馈信息。
- 手机保留稳定底部结果栏与抽屉；iPad 使用双栏工作区；血条按 20% / 50% 显示绿、黄、红三段状态。
- 结果抽屉内新增“状态 / 防御 / 增减”触发工作台；只展示当前攻守方向、当前技能和当前特性相关项目。
- 技能触发与特性参数可直接在结果抽屉中修改；点击技能结果仍切换伤害明细，不改变所在页面。
- 无参数触发项支持原位“触发 → 取消”，取消后安全恢复触发前状态；实测伤害 73 → 117 → 73，抽屉全程保持打开。
