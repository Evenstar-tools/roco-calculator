# 折射减耗与冻结适配验收

日期：2026-09-14。版本仍为 2.0.2；本轮未提交、推送、替换 Release 或上传小程序。

## 行为

- 携带水系技能，成功应用折射后，历史减耗参与所有攻击、防御、状态技能的能耗，最低为 0；同系携带多次不重复触发。兼容已保存的水系减耗记录，萌芽按每次实际记录结算，不倒推历史。
- 按能耗判定的特性读取减免后的能耗。动态技能先结算自身能耗再减免；实际能耗型技能自动联动，手动填写优先，避免重复减耗。计算过程区分折射减耗与手动能耗。
- 携带冰系技能，每次成功应用折射给对方增加 2 层冻结，进入已有冻结状态字段，上限 99。关闭异常结算时保留层数但不计入计算；开启后沿用已有冻结条件与斩杀阈值，不把冻结算成额外扣血。冰系免疫仍生效。
- 摘要显示全技能减耗及敌方冻结层数；关闭异常结算时明确提示。水系不再标注仅记录，冰系预览标注异常结算。
- Web 与桌面共用实现，小程序共享核心已同步；小程序实际能耗输入同步显示计算值。
