# 小程序排行榜入口一致性修复

日期：2026-09-11。仅本地修复和验证，未发布，版本保持 1.1.14。

## 问题与修复

用户截图中的两个排行榜入口只渲染裸文字，没有沿用现有设置菜单的左右两列结构，导致标题居中、缺少跳转提示，和相邻菜单项不一致。

- 速度线排行、耐久排行统一使用现有左侧标题与简短说明、右侧箭头结构，保留相同菜单行高度、文字字号和边距。
- 补齐分隔线、按压反馈和明确可访问名称；“查询工具”改为次级分组标题。
- 榜单与重置入口复用已有右箭头 PNG，尺寸统一，暗色主题沿用现有图标处理，不新增外部素材。
- 增加入口结构与行为回归测试：两入口必须具有菜单标题、说明和图标，点击后设置关闭并打开正确榜单。修复前测试失败，修复后通过，防止再次仅检查按钮是否存在。

## 验收

- 小程序全量 439 项测试通过，生产构建及发布产物门禁通过；主包 1,401,498 字节。
- H5 320、390、820px 明暗主题：两个入口标题相对“重置本页”左边缘偏移 0，行内横向溢出 0，箭头与文字区域间隔 16px。
- 原生微信开发者工具手机模拟器：入口标题与既有菜单左边缘对齐误差不超过 2px，箭头存在；分别进入速度线排行、耐久排行，再关闭返回，全部通过。
- 原生截图 `output/playwright/menu-layout-native.png`；用户截图与原生修复对照 `output/playwright/menu-layout-comparison.png`。H5 明暗与宽度截图同目录 `menu-layout-<宽度>-<主题>.png`。
- 截图验收排除入场动画中间帧，按稳定显示状态检查颜色和透明度。820px 平板检查为 H5，不冒充原生 iPad 实机验收。
