# Web UX13 三项小优化验收

日期：2026-09-20。版本保留 2.2.2。本轮仅 Web / 桌面共享前端代码，本地提交，不推送或发布；没有构建桌面安装包或小程序。

## 改动

1. 主计算器普通精灵候选列表在 760px 及以下展开到视口可用宽度，攻方左锚定、防方右锚定；宽屏原布局不变。
2. 生命输入采用 HP / % 两段选择，高亮当前单位并提供 aria-pressed；保留满血、换算及 HP 模式最大生命参照。320px 收紧间距，隐藏输入框内置数字箭头，不缩字号，避免三位数截断；键盘上下键仍可调数值。
3. 撤回默认坐标随手机与桌面视口更新，右侧留 18px，宽屏底部留 18px，1080px 及以下底部留 82px 避开结果栏。仅真正拖动后保存坐标；缩小时临时约束，恢复宽度后返回用户拖动位置。

## 验证

- `npm test`：104 文件，1791 项通过。
- 相关组件：使用 `--config config/vite.config.mjs`，floating-undo-button、result-rail、skill-editors 共 122 项通过。新增默认定位及手动位置恢复测试，补选中态断言。
- `npm run lint`、`git diff --check` 通过。
- 最终 `npm run e2e`：11 项通过，包含生产构建与体积门禁；JS gzip 347.18 KiB / 348 KiB，CSS gzip 55.42 KiB / 56 KiB。现有基线警告仍在，未扩大预算。
- 生产预览 4197：320 / 390px 双方列表，亮暗主题，ArrowDown / Escape；无横向溢出和视口越界。1280px 普通候选列表未变为整屏。
- 320px 亮暗主题：HP / %、0 / 90 / 满血回到 100，再切 HP 回到 425；截图读回确认数值完整可见。1280px 核对结果栏单位选中态。
- 撤回默认位置依次验证 320×720、390×844、1280×900、1920×1080、1000×700、1280×900；缩放不写入拖动缓存。实际鼠标拖动不触发撤回，缩小再恢复后手动坐标和缓存不变。

- 实现对比：`compare-list.png`、`compare-hp.png`、`compare-undo.png`；完整验收页：`artifacts/web-ux13/acceptance.html`。
- 沿用 design-craft 对图验收。列表边界与参考一致；生命单位保持 30px 按钮及 12px 字号。实际撤回统一相对浏览器视口右缘定位，参考图则更靠内容内缘；桌面滚动条存在时两者可能相差一个滚动条宽度，这是本轮统一默认锚点的明确取舍。
