修复实测发现的旧交互问题：原速度轴在 pointerdown 时立即捕获指针，普通点击未传到节点；现在超过拖动阈值后才捕获。触屏沿用原生横向滑动，并允许页面纵向滚动，不模拟计算逻辑。

统一样例：音速犬，普通性格，生命/物防/魔防各 60，速度 192，目标棋绮后（黑子）192。保存配置摘要为速度 192、综合耐久 35,306、物理耐久 74,664、魔法耐久 66,978。

有意保留的实现差异：

- “速度一览”沿用现有入口名，旁边补齐比较前提；不改原有完整速度表工作流。
- 手机目标长名称允许辅助文本换行，桌面去掉重复的目标行。
- 原生折叠控件保留键盘操作；历史非法配置优先展开修正，不强制默认收起。
- 4K 复用现有抽屉宽度，本轮只核对布局和无溢出，不引入新的全局缩放策略。

## 用户验收

1. 打开 `http://127.0.0.1:4191/`，进入「队伍 → 成员 → 能力分析」。
2. 无需展开就能看速度轴；点一个目标、拖动横轴，再检查“当前 / 目标”及快慢提示。
3. 展开「手动微调」，改性格/个体后收起；确认草稿提示、当前保存摘要和应用按钮的区别。
4. 比较三种推荐，进入速度一览后返回；切换亮暗主题并缩至手机宽度，确认赛季标题完整。
