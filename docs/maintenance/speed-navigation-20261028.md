# 国服与国际服速度线全屏及纵轴导航 · 2026-10-28

用户要求“国服和国际服同步……全屏展示……纵向轴拖拽……出方案然后落地”。沿用现有工具箱和排行榜样式直接实施，仅本地 Web 共享界面；未提交、推送、部署或打包，不改小程序。两服继续使用各自快照，速度计算、配置口径与排序规则不变。

## 方案与实现

- 桌面标题栏增加全屏／还原，扩展到浏览器内容区，不重建榜单。保留搜索、培养口径、详情和当前速度档位；关闭按钮仍直接关闭，Escape 依次关闭详情、还原窗口、关闭榜单。
- 实速排行与按种族速查共用左侧纵轴，高速在上、低速在下。拖动或点击定位实际档位，滚轮／触摸滚动时同步当前位置；方向键逐档，PageUp／PageDown 跨档，Home／End 到首尾。
- 纵轴按实际存在的档位分段，不把档位索引冒充连续速度比例。使用真实行位置定位；数值参照插入行也能导航。同种族值、不同等级的行保留独立 key。
- 手机沿用原有满屏布局，隐藏重复的展开按钮；缩减非必要间距，不缩小列表正文。轴宽按窄屏适配，中英日和明暗主题复用既有词典与颜色。
- 零结果不显示轴，单档不可拖动；初始焦点位于可见的关闭按钮。轴只改变浏览位置，不清空搜索、不切换培养口径。

## 验收记录

- 定向覆盖排行榜、渲染隔离、种族速度缓存、原速度布局与工作台、速度查询及新导航组件。空／单档、重复种族值、键盘、滚动、窗口重排、筛选保持和中英日标题均有对应检查；相关 ESLint、语言主表 sync／check 通过。
- 桌面 1280×900 与 1920×1080：拖动、滚轮同步、全屏／还原及详情分层 Escape；同一英文配置展开前后保留 236 档，更多卡片在同屏展示。
- 国际服日文 320×740 暗色：原生触摸模拟拖动从 294 到 194，页面宽度保持 320；冗余展开按钮隐藏。
- 国服 S5 390×844：页面宽度保持 390，关闭按钮可聚焦；冥古龙四等级 99／89／79／69 的独立行保留，End 定位 69 级行，不合并相同种族值。
- 实测发现切换头像／文字后行高变化导致轴值滞后；现观察表格内容变化并同步真实可见行，214 档切换后顶部与轴均为 241。窗口几何跨订阅保存，在滚动事件先于尺寸观察器时也保持旧锚点；最终实页 209 档经全屏、还原、390px、1920px 均保持 209，相关定向回归通过。
- S5 开发服务曾保留组件创建前的 import 失败缓存；重启本轮服务后恢复，无删文件或恢复旧版本操作。未改预览配置和计算核心。
