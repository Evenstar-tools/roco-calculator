## UX35-01：随机按钮是开关

线上实际复现：第二次点击后偏好仍为 `random`；刷新序列为 S2 → S4 → S3 → S3 → S2，证明并非完全不随机，但允许连续相同，且按钮不能直接关闭。

沿用原偏好字符串键。新增独立的上次随机主题记录，在 React 提交 effect 中保存；初始化和状态更新函数不写盘，避免 StrictMode 双调用影响已显示主题。

- 关闭 → 开启：保存随机模式，立即抽取其他三季之一。
- 开启 → 关闭：固定当前显示主题，不再重抽。
- 随机模式刷新/重新进入：从上次主题之外抽取；普通重绘、输入和明暗切换不重抽。
- 下拉手动选择，包括当前抽中的同季：退出随机并保存固定主题。
- 存储拒绝访问或写入时仍允许本会话切换，不声称禁用存储后能够持久化。

真实浏览器通过：开启后序列 S1 → S2 → S3 → S1 → S4 → S3 → S4，新标签进入为 S3；关闭后刷新保持 S4，手选当前主题可退出随机。这里是自然抽取，不是固定序列或伪造截图。

实际验收还发现原按钮开启与悬停同色；已改开启实色、关闭悬停浅色，避免看起来无法关闭。手机原 42px 点击区补至 44px；320/390px 无横向溢出，亮暗均可辨。

## UX35-02：渐隐绑定图片边界

原场景宽度固定 1000px、水平定位 20%，遮罩却以整个页头宽度计算。1920/2560px 时场景到右缘仍处在遮罩实心区，露出笔直边线。只对 S1–S3 补齐相同的遮罩尺寸/定位及禁止重复，不重绘素材，不变更角色大小或位置，S4 规则保持不动。

本地真实截图范围：S1–S4 在 1920/2560/1280/929/390px 亮色；1920/929/390px 暗色。S1–S3 宽屏硬边消失且场景仍可辨；929px 角色保留，390px 沿用隐藏大角色策略。根代理和独立代理均读回受影响截图。

## UX35-03：计算界面保持经典配色

用户指出精灵选择文字、技能模式按钮、承伤入口和撤回按钮随赛季变色，要求增加勾选项，经典配色明确为 S4 基础配色。

- 开启时复用现有 S4 基础 token：亮色紫、暗色金。不是将当前赛季 ID 改为 S4，页头、场景与角色保持原选择。

- 新偏好不进入计算配置或分享协议，不改变亮暗、随机模式、技能和输入。存储失败时本会话仍可操作。
