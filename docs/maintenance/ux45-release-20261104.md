# UX45 平衡调整回顾改版发布 · 2026-11-04

## 范围与来源

用户反馈“按更新浏览”的内容展示很怪，要求着重优化平衡性调整，并加上“怎么看比较方便”的判断；确认方案后要求“改，改完更新，更新的更新规范”。2.3.5 首次发布只更新网页，随后按用户追加授权接续 Windows 桌面版，见下方桌面验收。小程序不在本次桌面发布范围。

- 国服：从 2.3.4 固定源码 `4ae300b` 接续，逐文件提交到 `59ef8c077f93bc6ab4a5dc4831b6e77da91dfc6c`，远端分支 `web-ux45-cn-20261105`。
- 国际服：pin 不变，没有这个入口。
- 发布装配从最新 `origin/main` `8747050` 建分支，只改国服 pin、版本号、更新说明和文档。

## 改了什么

线上 2.3.4 把完全相同的改动合成一行，结果种族值是“一只精灵的一项一行”（最新一批 112 行，每次只显示 24 行），学习面以技能为主语、种族值以精灵为主语混在一个列表，技能改动被复制到每只会用的精灵上，能耗降低被标成红色，“移除可学习技能”不写移除了哪个技能。

改版后按更新浏览：

- 顶部五个速览格写明各类数量，种族值和技能另写增强、削弱各几项；点一格只看这一类。
- 种族值一只一行，六维小签和总和写在一起，同家族一框，按总和排序。
- 技能一项一张卡，威力、能耗、效果改写合在一起，列出会用的精灵。
- 学习面写“+ 技能名 / − 技能名”，直接列出名单，同家族三只以上折成“家族 ×N”。
- 相同的特性、形态改动只列一次并写明适用精灵。
- 能耗、冷却降低算增强。按精灵回查复用同一套小签和颜色；两种视图的分类名统一为种族值、技能本身、特性、学习面、其他。

[同条件改前/改后](assets/ux45-before-after-20261104.png)：左边是线上 2.3.4，右边是 2.3.5 源码，两边用同一份线上运行数据，1440×900 浅色，同一批次（S5 圣龙宝藏）。

## 取舍

JS 体积门禁 512 KiB，2.3.4 已用到 511.85 KiB。新界面初版多出约 1.6 KiB，为守住门禁做了这些取舍：

- 更新内搜索不再展开逐只精灵的详情列表，改为直接筛选同一套分类视图；从更新跳到某只精灵历次调整的按钮随之去掉，改用“按精灵回查”标签。
- 方案里的学习面“按技能 / 按精灵”切换没有做；查某只精灵拿到了什么，用更新内搜索。
- 侧栏批次下不写“40 只改种族值”；学习面速览格不写“+266 −39”，每行仍写明新增或移除。
- 批次标题照抄资料名（S5 的资料名自带日期），不再另外剥掉日期。
- 分类读法提示和技能卡的“增强 / 削弱 / 改写”字样放进样式表。
- 当前版本说明压到一行，替换 2.3.4 较长的说明。
