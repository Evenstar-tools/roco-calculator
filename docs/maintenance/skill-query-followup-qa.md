## 边界

BWIKI 本次技能栏尚未列出 26 个 S4 新技能，这部分归属继续采用项目赛季快照，不能宣称来自 BWIKI 全量核验。线上尚未更新，需要后续发布。

加载验收侧重可复现的请求数与重复解析消除，不把本机测试毫秒数当成所有网络和设备的承诺。家族筛选重复计算采用页面数据对象隔离的缓存，刷新后重新加载。

改后检视还发现地鼠的两种形态有独立进化链，旧实现重复显示。现已使用源数据明确的基础名称与形态字段连接分支，不用模糊名称猜测；抓挠示例应显示 12 个家族而非旧版 13 个，回归测试覆盖两种形态及其各自进化体。
