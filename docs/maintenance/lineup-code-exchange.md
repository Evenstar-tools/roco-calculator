# 游戏／千岛阵容码交换

2026-09-10：Web 与 Windows 共用队伍面板新增“导入阵容”“导出阵容”。

## 用户流程

- 导入：粘贴裸码或带 `shareData` 的分享链接，解析后收起长码，头像预览采用桌面两列、手机单列；“修改代码”可重新编辑并清除旧预览。确认个体数值暂按 0 后，“保存并调整个体”另存为新队伍，选中首个非空成员并聚焦个体输入。原队伍不覆盖；一次写入整个队伍。
- 导入成员显示“个体待设置”，修改实际个体值后清除该成员的提示；仅修改性格、技能或血脉不会清除。提示状态随队伍保存、刷新、复制保留，不写入游戏阵容码。
- 导出：选择共鸣魔法、编队模式，复制阵容码或官方分享链接；点击复制时保存分享设置。界面只保留一个码区，剪贴板失败时切换为对应的完整代码或链接并选中，供手动复制。
- 实际个体数值、月相记忆及战斗条件不属于游戏阵容码。个体未编辑时原样保留来源字段；编辑后导出最多三项已选属性，不编码具体数值，超过三项明确拒绝。
- 目前支持含性格改写尾部的 v1 格式（`8 + 39 × N` 字符，1～6 位）。未知版本、未知映射、无法表达的性格改写及超过四个非空技能会明确报错。

## 结构

### 个体配置判定与推荐

- 官方属性列表 `https://rocom.qq.com/cp/rocom_game_manager_json/prod/sprite/individual/list.json` 于 2026-09-10 核对：1 生命、2 物攻、3 魔攻、4 物防、5 魔防、6 速度。三项均为空才是“个体未配置”；有效不重复选择按计算器 60 档恢复，预览明确显示“各 60，非原始数值”。
- 不在列表中的值或重复值标为“原码个体待确认”，不能误判为空；真实千岛夹具的三项均为 80，仍保留原码，不提供自动推荐。
- 仅缺失成员提供默认不选的“使用推荐”复选项及“缺失项全部推荐”；取消勾选即撤销。优先匹配内置同精灵、同性格预设，以四技能重叠数排序；无匹配时按性格与四技能方向提供三项 60 的参考，避开性格降低项。预设按需加载，失败则使用明确标注的参考规则。
- 推荐只写入这次导入的新队伍，不覆盖已有队伍或手动值。原码有效选择、未知字段均不受批量推荐影响。带 shareData 的完整分享链接与裸码行为相同，不以链接长度判断配置缺失；不支持不透明短链解析。
- `tests/state/lineup-ivs.test.js` 固化缺失／有效／未知三类、手动值保护、推荐与导出回归，避免再次把面板零值误写为原码无配置。

- `src/state/lineup-code.js`：纯解析／编码函数及计算器配置适配。无网络请求、无存储副作用。
- `public/data/lineup-code-map.json`：随构建携带的 ID 对照表，打开交换面板后读取本地文件，不依赖千岛／腾讯在线接口。来源与核对日期在文件内。
- `src/components/TeamExchange.jsx`：加载、预览、保存、导出与复制。
- `team-presets.js`：队伍级 `lineup` 保存魔法、模式及原位置数量；成员级 `lineupSource` 保留游戏原始字段，支持编辑后按字段重新编码；`ivsPending` 记录新导入成员的个体待设置状态。原版本队伍无需迁移。

映射生成方法：游戏精灵 ID 通过 BWIKI `Module:LineupData/Pets` 的精确 `title` 对应本地唯一 `fullName`，技能通过官方列表精确名称对应本地唯一技能名。当前包含 594 个精灵 ID、564 个技能 ID。不得改成模糊匹配；存在多个反向 ID 时，优先使用该成员导入时的原 ID，新建成员无法消歧则拒绝导出。

维护映射时先核对实际形态，尤其是同名多形态和首领。加油蟹 3743 必须对应“单只海葵的样子”。外部资料只用于事实 ID 对照；解析器是本项目独立实现，没有执行或复制外部网页脚本。

## 验证

- 真实夹具 `tests/fixtures/qiandao-lineup.json`：用户提供的 S4电鹿轮转，242 字符、6 人、24 技能、进化之力。
- 状态测试覆盖真实样本、URL／转义、错误输入、空技能及单成员、性格改写、编辑后导出、四技能上限、新队伍个体选择留空、整队原子保存、刷新／复制保持来源及存储失败。
- UI 测试覆盖个体数值确认、输入变化清除旧预览、剪贴板失败手动复制。
- 浏览器实际执行导入、命名、保存、刷新后导出、两种复制；阵容码剪贴板内容与原码一致。390 像素宽度检查队伍面板无横向溢出，窄屏工具栏使用图标。
- 导出链接已在官方分享页实际显示正确队名、六人及全部 24 技能；官方页的编队标题仍是页面固定文案，不作为模式验证依据。
- 未在游戏客户端或千岛 App 中执行回导；小程序现有队伍分析与此 Web／桌面队伍仓库不同，本次未改小程序。
