## 计算与资料

41—43级使用目标当前形态的包体物防／魔防种族，强度取 `PETBASE_CONF.stength_stage`，不取页面显示的进化阶数。

```text
基础值 = round(10 + 对应防御种族 × (等级 + 50) / 100)
性格值 = round(基础值 × 性格倍率)
有效防御 = round((性格值 + 11) × c)
c：强度1为2.76；强度2为1.955；强度3为1.38；物防魔防共用。
```

最终一步以千分整数系数相乘再除1000，避免二进制浮点将241.5或103.5错误舍下。三个 c 均落在原研究的共同可行区间内；分步取整可使相邻等级得到相同结果。系数和 +11 是实测拟合，未恢复为游戏原始常数。进化模板60%/80%/100%不等价于双防系数的倒数。

目录666项有效目标均与自身双防种族一致；28项缺资料占位继续保留。旧未来进化分支不再改变双防；26个家族的历史标识用于存档迁移。棋棋家族黑白初始形态与同色进化检索一起接通。
