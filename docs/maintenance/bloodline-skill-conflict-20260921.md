# 血脉技能标记与首领冲突提示验收

日期：2026-09-21。版本保持 2.2.2。本轮仅本地实现与验收，未提交、推送或发布。

## 实现口径

- 按当前精灵的学习来源识别必须通过血脉获得的技能，下拉列表将“可学习”改为强调色“血脉技能”。同技能存在自学、技能石等其他合法途径时，不误标为血脉限定。
- 同一队员选择“首领”血脉，或本身属于“首领”形态，同时携带上述技能时，显示冲突提示。队伍成员卡、配置区域和对应技能行均有标记；窄屏成员卡使用警告图标。
- 提示列明冲突技能，提醒更换技能或改用非首领配置；不自动删除技能、不修改血脉，不阻断原有应用操作。更换配置解除冲突后提示立即消失。
- 运行时快照保留精简的 bloodlineSkillIds，避免开发数据可识别而正式构建丢失来源。共享领域逻辑同步至小程序镜像；没有新增小程序原生界面，本轮没有小程序构建、上传或桌面安装包发布。

## 验证

- 相关单元与界面测试共 9 个文件、59 项通过，覆盖特殊标记、替代学习来源、首领形态、未选中成员、重复技能、配置不被自动修改及解除冲突。
- 全部 622 个学习表的 11,195 条血脉限定关系，在完整数据与运行时数据之间逐项一致。
- 定向 ESLint、共享核心一致性检查、正式构建、git diff --check 通过。
- 构建预算未调整：JS gzip 351.59 KiB，CSS gzip 56.78 KiB，运行数据 1.68 MiB，均在现有预算内。
- 使用隔离浏览器在正式构建预览 http://127.0.0.1:4193/ 实测。1440、390、320px 无横向溢出，深浅色可读；切换首领、恢复普通血脉、替换冲突技能均正确更新提示。没有修改用户日常浏览器中的队伍。
