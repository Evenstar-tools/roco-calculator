# 独立技能查询面板开发计划

## 目标与范围

Web 与桌面共用独立面板，从菜单进入；关闭后保留计算器配置。无需先选择对战精灵即可使用。覆盖单技能资料、完整学习面、学习途径、新赛季技能以及老精灵新增技能。保留 S3 基线，S4 数据更新后自动生成查询和对比，不改伤害计算规则。本轮不包含发布、安装包和小程序界面。

## 产品方案

1. 技能查询：名称/效果搜索，属性、种类与赛季筛选；桌面左侧列表、右侧详情，手机列表进入详情并提供返回。
2. 详情：属性、种类、能耗、威力、效果、学习面数量；按精灵名称和获取途径筛选学习面，展示精灵、获取方式与新增标记。
3. 赛季新增：比较基线与目标赛季；切换“新技能”和“老精灵新学”。新增旧技能也应出现，不能只取新技能集合。新增精灵不计入“老精灵新学”。
4. 无结果、未知威力/能耗、无学习面、加载失败均有简短且准确的状态；数字零保留为零。

## 数据边界与回退

表内基础形态与计算器进化形态不能直接按名称做集合减法。先保留表的原始学习面与途径，再通过稳定 ID 与已有分形态快照关联。赛季增量以同一身份口径的两个快照作差；表与历史快照不一致只进入复核报告，不能被误报为 S4 新获得。当前技能信息使用当前快照，选择 S3 时使用历史信息。

面板代码按需加载，查询资源单独生成。回退可撤销本功能的入口、模块与资源，上一轮手机标签及速度改动保持独立。版本号和发布记录待发布任务处理。
