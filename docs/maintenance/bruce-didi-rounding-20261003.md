# 布鲁斯对迪迪：零个体半点校准

## 配置与来源

用户确认同一实战配置：冰钻布鲁斯，固执，生命／物攻／速度个体60，其余0；配招暴风雪、力量增效、火焰冲锋、先发制人。霹雳迪迪，胆小，生命／魔攻／速度个体60，其余0；配招落雷、色散、镜像反射、放晴，总能耗8。双方初始能力等级0，冰钻自动按每能耗10%计算。

实战直接伤害：先发制人159（显示威力99），力量增效后先发制人318，未强化火焰冲锋173（显示108），暴风雪307。截图中的物防131是旧计算器，不作为游戏面板证据。

CLI数据／规则版本均为`s4-2026-09-10`，协议输入摘要为`sha256:f6f7344787601401397616f87cfe0e7469ec6f27e1e91dcd618016bdf25b62a8`。

## 定位与范围

旧基础面板规则将零个体的半点取到奇数，迪迪物防由理论半点71.5取为71，再加60得到131。只将物防改为132、其余公式不变，可同时匹配四条实战反馈。

| 情况 | 旧物防131 | 修正物防132 | 用户实战 |
| --- | ---: | ---: | ---: |
| 先发制人 | 160 | 159 | 159 |
| 力量增效后先发制人 | 320 | 318 | 318 |
| 火焰冲锋 | 174 | 173 | 173 |
| 暴风雪 | 309 | 307 | 307 |

131.5的小数防御不能同时复现未强化火焰冲锋、暴风雪；伤害分子的四舍五入也不是原因，先发制人的分子20995.2439无论四舍五入或向下取整都得到20995，除以131仍是160。

旧规则由历史提交`c2cb910`引入，其四条半点测试以第三方原站为参考，无游戏实战证据，也不足以推出通用取到奇数。修复恢复基础面板普通半点向上取整，保留原浮点容差，不硬编码精灵、种族或技能；同类半点变化依据统一模型，非新增实战确认。

等级系数37/41、未取整公式威力、伤害分子四舍五入、每击向下取整及负防御等级保留小数均未改动。小程序同步权威源码，但本轮不上传微信、不重新打包Windows、不更新Release。
