# 技能检索卡片化验收（2026-09-10）

## 范围与交互

仅 Web / 桌面共用页面；入口仍为菜单 → 技能检索。不修改小程序、数据快照、计算规则或用户配置，不推送、不发布安装包。

- 顶部常驻搜索、方向和筛选；桌面主区三列技能卡片，窄桌面两列，390 / 320px 手机单列。
- 右栏宽 320px，已选技能紧凑排列，家族头像名称整行可点击，每家族仍只显示一只。
- 点击卡片或键盘 Enter / Space 原位选择和取消，保留搜索与筛选。最多四项，第五项不会替换已有选择。
- 眼睛按钮只隐藏效果正文，不隐藏图标、名称、属性、类型、威力和能耗。隐藏后仍可搜索效果；显示偏好在本次弹窗内共享，不新增持久配置。
- 精灵页展示完整技能池、学习来源与数量；技能反查定位目标技能，返回恢复原条件与位置。精灵页和赛季新技能采用同类卡片层级。
- 具体形态先满足全部已选技能，再归并家族；家族反查优先匹配成员中的最终普通形态，不拼接不同形态技能。明确搜某个精灵时仍保留精确定位；只有幼体满足全部条件时不能伪装为终阶可学。

## 实测反馈与修复

1. 650px 高桌面选四项时，原本分割的结果滚动区只剩约 79px，无法直接浏览。已让低高度桌面右栏整体滚动，保持主技能库独立滚动，不再把结果压成小框。
2. 实际数据按幼体在前排列，原代表选择逻辑会进入幼体；改为符合条件的最高普通阶段，增加不跨形态拼技能和不优先首领的测试。
3. 手机长列表增加底部同页定位条，从技能库直达匹配结果，再返回原技能库位置，不增加抽屉或弹窗。
4. 技能卡片底部将学习来源与反查操作合并一行，减少空白；展开详情时不重复显示相同来源。
