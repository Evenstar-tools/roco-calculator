## 实际使用走查

- 首次引导选攻击方/防御方后自动进入下一步；到性格步骤后跳过，未宣称完整六步引导均复验。
- 两种界面模式的精灵搜索、自动配招及结果呈现。桌面双方并排、四技能可比较、右栏常驻，整体结构保留。
- 菜单、显示设置、技能口径、结果入口与高级天气配置；当前负面状态结算开关位置记录，但不再加一组开关。
- 桌面实际新增帕帕斯卡、修改四技能并代入攻击方；手机实际新增音速犬、调整技能顺序并代入。自动保存、代入自动关闭及配置顺序正常。
- 工具箱分组与属性查询在桌面/手机实际选择地＋冰、查看精灵与关闭返回，未发现新的操作阻碍。不代表所有工具页均已验证。

主要摩擦不是功能缺失，而是手机纵向占用、图标选项含义和结果归属。未因“整体优化”改变桌面栏位、品牌、必要说明、精灵配置或计算规则。

## 三项原方案与获批方向

1. UX33-01：具体版窄屏压紧精灵区域，选择器完整姓名保留一次，类型/阶段/特性/头像/收藏保留，交换移到旁侧。原精灵区约400px；模拟节省约100px，首屏能多看到攻方能力。技能区仍需滚动，不夸称已解决全部长页面问题。
2. UX33-02：精简版原属性控件及单/四技能按钮补短名称。普通是一个未选中/选中的普通性格选项，不冒充完整当前性格。首次模拟为普通/全60；独立评审指出状态语义疑点后，以真实非普通＋三项个体重拍当前最终图，高亮与文字含义一致。代价是配置区约增55px，首屏少显示一条技能，换取不用猜图标；无需新增教程。
3. UX33-03：手机原固定栏显示当前技能名，放在数字上方；保留双方全名、占比、承伤与撤回。首份临时模拟采用绝对定位导致叠字，读图后改为原网格中的一行，重新截图并独立复核通过；只修模拟，没有对产品写入该样式。

实施批准保留①③方向；②改为显示设置中的“显示选项名称”，默认关闭并记忆选择，不默认增加所有用户的配置区高度。以上过程描述保留方案阶段事实，当前源码与真实对照以实施验收为准。

## 已复现漏项与暂缓项

UX33-04：设置沙暴/暴风雪、收起高级选项并切精简版，结果“计算条件/调整”消失。雨天同路径正常。实页读取选中值并以正确的“当前非默认高级条件”区域定位复核；初版辅助定位名称错误已修正，以雨天作为正对照重验，不用错误定位证明故障。源码 `App.jsx` 的摘要仅映射雨天/雷鸣，待补齐两种天气；这不是伤害公式有问题的证据。

UX33-05（暂缓）：两种双向箭头分别交换整套配置和反算；未观察到误操作，不直接改图标。UX33-06（暂缓）：结算开关在显示设置内，能用，是否前移需另选方向。不为发现次数或控件数量凑改版。
