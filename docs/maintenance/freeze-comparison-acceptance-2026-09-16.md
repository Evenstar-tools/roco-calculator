# 冻结推条验收

## 问题与修复

原承伤榜将冻结传入技能条件，却仅以直接伤害与最大生命判断击倒，遗漏主结算已有的冻结斩杀阈值。现在复用共享冻结阈值规则，不启动其他回合末异常伤害。

- 最大生命仍为100%，承伤比例与范围筛选按直接伤害占比加有效冻结层数乘5%，不改名为“击倒进度”。
- 蓝色前段表示冻结覆盖，后接原伤害色段；实际伤害HP保持不变，数值拆分说明。
- 冻结击倒独立标记；详情保留原最大生命、直接伤害后的HP及向下取整的冻结斩杀线。
- 冰系免疫、取消沿用开关和无冻结回到原有口径；冻结覆盖最多100%。
- 折射两次产生4层冻结后切换追打，双向承伤榜自动沿用；重复计算不叠层、不改变对局。
- Excel与Markdown同步筛选、合计比例、冻结覆盖和冻结击倒结论。

## 七技能验收页纠正

本地验收页此前手写四技能，并非正式承伤对比截断。已改为读取内置预设的完整七技能：折射、追打、回旋风暴、气泡、超导、极寒领域、叶绿光束，不修改用户配置。

双向折射领域回归改用同一预设，断言七个选项和第七槽可选，5项测试通过。浏览器实测下拉显示七项，切换叶绿光束后正常生成60行，保持折射两次的4层冻结。后续验收特殊技能槽精灵时必须使用真实预设，并验证末槽可选，禁止固定四槽样例替代。
