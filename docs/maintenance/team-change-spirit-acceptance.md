# 队伍更换精灵入口修复

2026-09-18，本地修改，未提交或发布。

原“队伍配置”为带铅笔图标的 span 状态标签，无点击行为，却外观类似按钮。现改为“更换精灵”按钮，沿用现有外观，点击后切回成员配置、滚动定位、聚焦高亮并展开精灵选择框。临时配置仍为状态标签；能力分析草稿继续通过现有 navigate 确认逻辑保护。

27 项队伍测试、ESLint、前端构建、硬体积门禁通过；软体积警告仍在。实测 1280、390、320 三档宽度，从能力分析点击后选择框均获焦、展开且处于视口内。截图 `output/playwright/team-change-spirit-{1280,390,320}.png`；320 深色图已读回，沿用 design-craft 的操作优先与现有样式原则。未重复跑全量回归或制作安装包。

回归约束：队伍头部更换入口必须是可访问按钮；成员配置和能力分析两条路径都要验证焦点、列表展开及选择后成员标题更新，避免再次出现外观可点但没有行为的控件。对应断言已加入 `tests/ui/team-drawer.test.jsx`。
