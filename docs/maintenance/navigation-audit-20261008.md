# 本地地址与导航排查 · 2026-10-08

## 范围与结果

用户要求继续检查其他入口是否指向本地。复用当前 SEO 工作树，检查源码、已有生产构建、部署重定向及当次公网响应；不访问生产计算器执行 JavaScript，不制造验收采集流量，不替换既有 Windows 安装包。

首页、电鹿页、中英文说明页的静态跳转、搜索元信息与站点地图均无 localhost、127.0.0.1 或本地文件地址；下载、GitHub 反馈、资料、飞书手册、邮件反馈与官方队伍分享也均为明确的外部地址。`/`、`/dianlu/` 与页内目录为本应用内部路由；PWA 启动路径、资源路径、桌面 `app://calculator/` 和开发测试主机配置保留正常用途。

发现一处保留逻辑的隐患：`src/hooks/useShareFlow.js` 的“分享当前配置”直接将 `globalThis.location.href` 用于弹窗和复制。从本地预览或桌面版调用该流程生成的分享链接会保留本地来源地址，其他人无法据此打开官网。真实界面与 `WorkspaceOverlays.jsx` 复核确认当前菜单未开放此按钮，`App.jsx` 只传入未被 UI 使用的 action；现有集成测试通过捕获 action 调用，不构成用户可触达证据。不能把这处隐患描述为现用入口故障，本轮不新增或恢复按钮。

现从现有产品链接表读取官网根地址，仅在分享输出中拼接原编码 hash；当前页面仍只更新相对 hash，不导航到官网，配置导入与复制流程保持原有实现。模式、精灵、技能与配置等内容由原分享协议携带，不依赖本地路径或查询参数。不增加网页用户日志，因为未开放逻辑的维护不构成当前用户可感知的界面变化。
