# W2 技能检索筛选布局验收

日期：2026-09-09。用户确认新版 W2 后实施，适用于 Web 和同源桌面版；不改小程序、不上传、不打包。

## 实施范围

- 桌面将技能搜索、属性、种类、赛季筛选放入左侧技能列表栏，学习精灵筛选与右侧小标题同行。
- 手机进入技能详情后隐藏左侧列表与技能筛选，返回技能列表后恢复四项查询条件。
- 「老精灵新学」仍保留其原有顶部查询区。查询逻辑、学习面、图标来源、家族合并规则均未改。
- 仅调整结构和布局，不缩小精灵头像、文字或卡片。此方案替代被否决的缩小头像方案。

## 验证

- 六套亮暗主题浏览器实测通过：原尺寸、首排位置、家族搜索、展开、返回后条件恢复。
- 跨 650/651/320/1440px 断点：筛选值和家族展开状态不丢，面板及详情不横向溢出。
- 查询、赛季新技能、老精灵新学、失败重试、缓存与关闭返回行为均纳入既有回归。
- `npm run lint` 通过。
- `npm run e2e -- --workers=2 --reporter=line`：68 项全量通过。新增更严格的详情横向溢出断言后，该跨断点用例单独再次通过。
- E2E 启动时运行完整 `npm run build`，通过性能预算门禁：JS gzip 241.30 KiB / 硬上限 256 KiB；CSS gzip 37.58 KiB / 硬上限 46 KiB。未改预算。
- `npm test -- --maxWorkers=4`：103 个文件、1803 项单测全部通过。新增用例验证筛选区归属及返回后四项条件恢复；手机可见性由真实浏览器 E2E 验证。
