# 中英文说明页阅读优化 · 2026-10-08

## 目标与范围

用户要求解释 `/guide/`、`/en/` 的实现，并按项目设计改善两页观感。沿用已经确认的项目风格直接实施；本轮仅 Web，保持 2.2.4，不打包 Windows 或小程序，不修改计算、统计、云服务或收费配置。

项目及相关工作区未找到 `design.md`。实际依据为 `docs/uiux-optimization-workflow.md`、`src/styles/01-tokens.css`、`src/styles/11-ui-refresh.css` 及首次使用指引规范中的 8px 圆角、轻量布局与避免大欢迎横幅要求。没有把小程序历史 `design-qa.md` 冒充通用设计规范。

## 实现与结果

- `guide/index.html`、`en/index.html` 为真实静态 HTML，四个 Vite 构建入口中的两个；与计算器一起构建并通过同一站点部署。共同使用 `public/seo-guide.css`，不另起服务。
- 桌面增加侧栏目录与白色/深色连续阅读区；手机将目录置于正文前紧凑横排。语言切换分组、三步计算轻量分区、工具按用途与真实入口组织，FAQ 采用原生 `details`。
- 收紧标题及首屏留白，精简重复英文介绍。仍保留三步骤、六类工具、五项 FAQ、真实链接、canonical、互指语言版本及结构化数据。英文页仍是说明页；国服 S4 数据、中文计算器界面与资料、国际服未验证等限制在主按钮之前明确。
- 正文阅读、目录、FAQ 与语言切换无需 JavaScript。静态说明页依据系统明暗偏好配色；没有增加访问采集。
- 这是已有 URL 的阅读优化，不需要另建搜索索引。Google 请求抓取是可选提醒，不能保证收录或排名；本轮不重复提交站点地图或索引请求。
