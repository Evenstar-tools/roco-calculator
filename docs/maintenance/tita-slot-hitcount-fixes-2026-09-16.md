# 声波缇塔槽位与连击修复验收

## 范围

- 版本保持 2.0.2，不新增功能，不模拟传动。
- 传感器 1、3 号位为 3 连击，2、4 号位为 2 连击。
- 向心力在 1、2 号位增加 30 威力；单技能须选择位置，缺少位置时明确提示，不静默漏算。
- 单技能位置不影响四技能实际槽位；兼容控件稳定 ID 和旧字段。
- 旧预设 hitCount 保留为默认值，显式手调记录到 overrides.hitCount；恢复默认清空覆盖，切换技能记忆和小程序分享保留手调。
- 一并提交前序冻结提示修复：未达到击倒条件时显示冻结覆盖，不显示斩杀误导提示。

## 根因与回归

传感器原先缺少位置连击规则。补规则后，自动连击优先级又盖住手动输入；向心力单技能缺少位置输入，且位置的稳定 ID 与模式切换存在未覆盖边界。

先建立失败测试，再修复。主要回归入口：

- tests/domain/tita-sensor.test.js：四槽、攻防双方、单技能、稳定 ID、模式切换、显式覆盖与恢复。
- tests/ui/skill-editors.test.jsx：位置控件、特性提示、连续恢复默认。
- tests/state/calculator-session.test.js：单技能手调记忆隔离。
- miniapp/tests/skill-presentation-ui.test.jsx、share-payload.test.js：手调、恢复与分享回读。
- tests/ui/result-rail.test.jsx：冻结覆盖与实际冻结击倒提示。

## 实页验收

在独立 Playwright 会话中验证，不修改用户预设：

1. 四技能第一格传感器手填 6，离开输入框后仍为 6，伤害随之更新。
2. 单技能拆卸选择位置 1 与 3，向心力威力加成分别生效与不生效；位置控件持续可改。
3. 单技能传感器填写位置 1、手调 6，再连续两次恢复默认，连击稳定回到 3。
4. 单技能选择位置 3 后切回四技能，第一格仍按自己的位置 1 计算，不受单技能残留条件影响。
