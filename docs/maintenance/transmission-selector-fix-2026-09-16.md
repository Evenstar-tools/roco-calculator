# 精灵选择器样式及头像修复

问题：传动面板通用按钮样式覆盖共享选择器，下拉箭头与变更提示被撑高；传入原始精灵数据缺少assetUrl，且此前精简时隐藏了整个精灵卡片。

修复：复用prepareSpiritForView转换头像资源；恢复56像素紧凑头像卡片；通用按钮样式仅作用于面板自身操作，保留共享精灵/技能选择器样式。

验证：54项测试通过，新增选中精灵头像资源断言；ESLint、完整构建及性能预算通过。Playwright在1440、390、320宽度实测：变更提示18像素，下拉箭头24像素，列表头像与选中头像均成功解码，选中头像可见，无横向溢出。桌面下拉与320宽度选中态截图已读回检查。

## 后续验收清单

触发条件：弹层复用SpiritPicker或SkillPicker，或调整弹层控件样式。

- 不得用弹层下所有button的通用尺寸覆盖共享选择器；样式限定到自身操作栏。
- 精灵数据需经过现有视图转换函数；分别验证下拉列表和选中卡片头像加载。
- 在320宽度和桌面打开下拉框，检查箭头、变更提示、输入框焦点以及候选行尺寸；不能只检查下拉收起态。
- 简化界面时保留头像与技能图标，不通过隐藏整个精灵卡片解决局部排版问题。
