## 实际能力

- `searchRocoData`：按名字、关键词或 ID 查询内置国服精灵、技能、特性；可用具体精灵限定技能学习面。返回完整形态及真实技能条件控件，不承诺无关键词的完整图鉴导出。
- `calculateRocoDamage`：复用小程序现有会话、等级投影及多段/S5 结算，返回伤害、逐段分布、生命占比、剩余生命、公式步骤和实际默认假设。歧义、缺条件、不可学、状态技能和未支持规则返回明确原因。
- 普通精灵固定 60 级；已适配特殊精灵默认 99 级、允许 1–99。能力等级范围与首页一致。下注暗低血分支沿用自身 49% 联动，已有更低生命保持不变。
- 两个接口只读，不读取或改写用户存储、不执行攻击、不模拟完整队伍/回合；不新增模型密钥、网络调用、聊天界面或 GUI 卡片。
- 调用说明在 `miniapp/ai-skills/roco-calculator/SKILL.md`；机器接口定义在同目录 `mcp.json`。

## 构建与回退

正常生产入口仍为根目录 `npm run miniapp:build:prod`。Taro 构建后自动装配 `dist/skills/roco-calculator`、`app.json.agent.skills`、独立分包和上传包含目录，再执行原有压缩及发布门禁。

AI 引擎为自包含 CommonJS 包，不依赖主包 App 初始化、Taro 或 React。普通计算页面不导入 AI 分包；不支持 `wx.modelContext.registerAPI` 的宿主不会执行接口注册。

PowerShell 紧急回退只关闭 AI 接入，保留普通计算器：

```powershell
$env:MINIAPP_AI_SKILLS = '0'
npm run miniapp:build:prod
Remove-Item Env:MINIAPP_AI_SKILLS
```

回退会移除本功能拥有的分包和声明，保留其他 agent 元数据；重新启用后必须重新构建及验收，不复用旧目录产物。
