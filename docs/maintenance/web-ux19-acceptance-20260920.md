# Web UX19 实施验收

2026-09-20，版本 2.2.2，基线 4f6f365。用户在 UX19 两项效果图后明确回复“处理”，两项均纳入本次范围。仅本地实施和验收，未推送、未发布。

## 已完成

1. W19-01：主结果只在原因明确为“非伤害技能不计算伤害”时使用中性色；窄屏底栏显示“非伤害”。正常伤害百分比保留原色，缺输入和未验证规则保留原提示，不改计算。
2. W19-02：技能名、伤害与占比统一 12px，表头 11px；行高 38px、宽屏列宽、选中边线不变。底栏保持单行横排。

兼容验收发现 320px 抽屉里固定最小比例条宽度导致末列溢出；仅在原窄屏断点允许比例条收缩，伤害和占比仍保留固定列宽，没有隐藏溢出或缩小文字。

## 验证

- npm test：104 文件、1792 项通过。
- 两个结果相关组件专项文件：64 项通过，包含正常伤害、非伤害、缺输入和未验证规则，未新增测试文件。
- npm run lint 与 git diff --check 通过。
- npm run e2e：最终生产构建及 12 项通过。首轮因 JS gzip 348.01 KiB 超预算中止；精简新增状态标记后最终为 347.99 / 348 KiB，CSS 为 55.92 / 56 KiB。没有提高预算，余量仍很小。
- 曾在构建尚未结束时提前执行独立 performance:verify，因输出目录重建而缺文件；最终由完整构建内预算门禁通过为准，不把中间检查当成功。
- 1920×1080、亮暗两主题，银月狼王对布灵布灵：非伤害提示分别为 #596177／#bac7d8，正常伤害仍为原风险色；技能列表文字实测 12px，行高 38px。
- 320／390×844、两主题：底栏显示“非伤害”；结果抽屉行宽无溢出，百分比完整可见；Esc 关闭正常。
- 额外合成布局边界：超长技能名称、99999 伤害、999.9% 占比未使整行或数字溢出。此项只是 DOM 布局压力检查，不是游戏真实计算结果；检查后立即恢复原文字，不混入实测验收图。
- 真实截图和与确认方案的合图均已打开读回，没有用注入模拟冒充实现。
