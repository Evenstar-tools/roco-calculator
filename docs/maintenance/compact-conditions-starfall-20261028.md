## 星陨斩杀线

入口位于结果栏（手机在完整结果抽屉）与当前目标的星陨印记配置旁。弹窗抓取当前配置，可切换已有技能、试算层数、搜索精灵，以及选择生命/生防/纯肉培养。

- 当前对位通过 `buildCombatState`、`calculateMatchup`、`asResultRailModel` 同源计算，保留血量、减伤和实际特性；扫描 0–99 层，不假设单调，0 是有效最低值。
- 单次斩杀仅计直接伤害与冻结击倒判定，不把冻结阈值或回合末扣血伪造成伤害。未知规则或未建模存活特性显示待核验，区别于 99 层内不可斩杀。
- 三档培养均为 60 级：生命＝中立/生命60；生防＝中立/生命双防60；纯肉＝生命增益性格/生命双防60，其余个体0。榜单满血、无旧目标减伤与异常、不计防守特性。
- 当前目标优先计算，完成的行逐批显示；切技能、关闭或重新代入会取消旧请求。结果按请求身份隔离。
- “选培养”只代入目标与培养，恢复特性后保持弹窗复算；“填入最低层数”再写回。两种操作均独立记录撤回，不覆盖个人存档，不改变单/四技能模式、计算方向或所选槽位。

领域及状态 API 已列入共享清单并同步镜像；小程序 UI 不在本轮验收范围。
