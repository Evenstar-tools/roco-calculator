## 特殊机制的真实链路和边界

1. 明确规则与参数：`src/domain/trait-effects.js`。
2. 状态按方向、精灵、特性实例保存：`src/state/reducer.js`、`calculator-session.js`。
3. 合并原生/附加/吞噬/继承：`src/domain/effective-traits.js`。
4. 同一份状态投影到参数与联动：`src/domain/trait-runtime.js`。
5. 进入攻防、速度、威力等真实贡献：`src/domain/traits.js`、`skill-result/calculate-skill-result.js`。
6. 原控件、六维面板、逐技能与主结果显示：`calculator-view-model.js`、原 App/技能编辑器；不另造一套独立模拟器后宣称接入完成。

当前明确保留的边界：狼王吞噬阶段一没有自动击败监听和 5% 自损，旧通知里的临时取整/时点假设已撤回；参见 [阶段一更正](../verification/s4-moon-memory-phase-one-feishu-message.md)与[计划](s4-moon-memory-trait-plan.md)。旧玩具的旧前瞻文案已过期，以正式同步和当前规则为准。

接入风险：特性求值仍有描述推断 fallback；`description-only` 的部分守门依据位于 provenance，而 runtime 会裁掉 provenance。仅展示标签不能证明求值隔离。本轮没有证明现有正式特性因此误算；S5 新数据放行前，应保证可执行支持状态保留到运行时并在真实求值入口约束。
