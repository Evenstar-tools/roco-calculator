# 极化／钝化的适用模式与数值证据 · 2026-11-07

本轮接续用户要求“合进主干然后继续找极化钝化相关的数据证明，看看是不是pve有效”。骰子功能已按固定源码入口接入本地main，见[整合记录](s5-dice-main-integration-20261107.md)。本轮未推送或部署，也未启停采集、运行GM测试或收集PVP数据。

## 结论

1. **常规PVE适用有多层证据。** 上线公告给出适用范围；现有原包有明确的NPC极化/钝化测试场景；当前野外PVE实录下发了极化/钝化，并有与额外克制修正约1.8相容的伤害对照。
2. **不能说所有PVE子模式都生效。** 上线说明明确排除了PVP与星光对决，后者虽是PVE玩法也属于例外。公告是上线时声明，不是本轮对S5所有模式的逐一运行验收。
3. **完整数值规则尚未恢复。** 现有记录不唯一识别93/94的消费算式，尤其钝化仍与隐藏攻击、当次动态威力耦合。22500可以映射为显示225，但不能直接当最终伤害×2.25或×3.25。
4. **抵抗骰子与觉醒的组合继续保持保护门禁。** order42不是属性93/94本身，作用方向、双系处理、先后和取整仍待证；本轮不改拟合常数。

## 一、上线说明的范围证据

可公开核对的刊载：[《洛克王国：世界》上线小报特别刊](https://news.17173.com/content/03182026/104940843.shtml)，页面为“官方公告”栏目、署名洛克王国世界，日期2026-03-18。

“新增精灵觉醒”段说明了每次觉醒的本系强化15%、极化45%、钝化45%，并把PVP和星光对决排除在觉醒属性生效范围之外。文意支持日常PVE养成用途，不能据此推导服务端的乘区或上限；S5当前规则还需结合版本资料与实录。

其他社区转载只作检索线索，不充当独立验证。本文没有将一般玩家文章、其他计算器结果或同一公告的多份转载算作多条数值证据。

### PVP分流在哪里

已找到`PetUtils.IsPvp`和`CheckNeedSwitchToPvpBalancePetData`。`PetUIModule`经`ZONE_QUERY_PET_BALANCED_ATTR_REQ`向服务端请求平衡精灵数据，再按gid缓存整只`rsp.pet_data`。

已读客户端函数未显式清零93/94。由于平衡数据本身由服务端生成，不能从“客户端未清零”推导PVP有效；同样不能仅凭“有平衡路径”推导它具体移除了哪些字段。缺口在返回内容的实际变化及服务端伤害消费者。

## 三、当前实录：PVE模式与额外克制因子

只读检查现存11场：早期4场、r1七场。r1七场结束消息4908全部明确`real_pve=1 / real_pvp=0`；己方罗隐快照为觉醒5，sharpen/blunt均22500，对方觉醒0、对应值0。字段在PVE中确实下发，但字段存在不等于已证明消费公式。

本轮检查时r2会话仍无遭遇文件，不能算成新样本或零伤害。

### 同目标的中性／克制对照

r1第1场，同一42级噼啪鸟、同一60级罗隐，命中前物攻312：

| 技能 | 对目标动态威力 | 克制标志 | 原始伤害 |
| --- | ---: | ---: | ---: |
| 地刺 | 360 | 1 | 1331 |
| 火焰切割 | 100 | 0 | 205 |

定位分别为`/events/3/data/perform_cmd/perform_info/2`和`/events/5/data/perform_cmd/perform_info/2`。动态威力由命中前目标401对应项取得，不能再重复乘本系或普通属性克制。

**条件推断：** 在共同有效防御D、当前伤害骨架及没有额外未分离修正成立时，用中性招约束D，再与克制招联立，可得到额外K约`[1.7947612276,1.8048735033)`。这支持约1.8候选，不需要先固定D=137。

两击之间发生破盾揭示，且有失血、BUFF时长变化；已知状态尚未解释该比值，但未知消费者仍在，因此不能宣称K唯一来自极化，或完整原公式已经找回。

补充交叉样本为两场43级沉金兽：中性P100→110、P300→332，与另一场克制P360→718；在跨场有效防御相同前提下也与约1.8相容。它们不是同一只敌人，不写成无条件同场对照。

### 钝化为何仍未定

四次敌方命中的实录为29/37/37/32，现自动模型为19/37/39/35。敌方真实攻击及对目标动态威力未保存，静态威力/触发与隐藏攻击都有未知量。

在现攻击与技能假设下，噼啪鸟要求的统一减伤K区间约0.59748～0.60239，沉金兽要求约0.55116～0.55519，两者不相交。改成统一0.6仍解释不了全部样本；也不能靠调整攻击到某个恰好吻合的数反向证明原公式。

因此现有证据支持继续在PVE研究钝化，尚不足以独立量化其减伤规律。

## 四、验收与下一条有区分力的证据

- 现有完整实录回放仍真实返回退出码1，包含输入缺失和承伤失配。新增骰子/门禁回归通过不等于全实战公式通过。
- 下一步优先同一目标、同攻击类别、同盾/本体阶段、非暴击的中性与克制配对，保留命中前属性、双方觉醒、实际选面、BUFF和目标动态威力。
- 钝化需要同一敌人对相同我方条件的中性与抵抗命中，以及可核对的当次威力；正常遇到相应条件时记录，不要求任意控制NPC招式。
- 若比较不同觉醒，需扣除本系显示威力差异并对齐实际面板；不能比较两只不同养成精灵的裸伤害，或回退不可逆成长。
- 新数据先冻结输入、写出现模型预测，再核验；不能用同一命中反推防御后，把回放吻合当独立证明。
- PVP或其他模式不在本次采集授权内。模式适用说明与实际数值规则分别维护，不把野外PVE拟合系数带入PVP公式。
