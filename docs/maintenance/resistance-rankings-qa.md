# 独立排行榜与倍率筛选验收

日期：2026-09-11。范围：本地实现与验证；未发布、未推送，版本号保持 Web/桌面 2.0.0、小程序 1.1.14。

## 已实现

- 主菜单增加速度线排行、耐久排行独立入口；不要求先选择精灵、建队或启用队伍分析。原能力分析入口继续保留。
- 耐久榜选择的是承受的攻击属性。倍率采用带颜色的数字复选框，支持全选、半选、全部取消、任意组合；全取消明确显示空结果，不自动放宽。
- 火系勾选 ×0.25、×0.5 后，候选的最终双属性倍率都小于 1；当前默认最终形态与首领范围共 88 只。默认不限属性为 319 只。选择弱点档时，摘要直接列出所选倍率，不误称抗火。
- 属性有效耐久使用基础耐久除以最终倍率；保持原四种标准模板、三项指标、搜索不改名次规则。属性免疫独立分组，不输出无限数值。不计算特性、天气、具体技能的额外作用。
- 速度榜默认极速、满速，同速聚合，不同口径保留；没有参照时不伪造“当前速度 0”。精灵点击只读详情，不覆盖计算参数或队伍。
- Web 全局两榜状态独立，关闭重开保留会话筛选；窄屏仅保留当前指标列，表头固定，速度名称按单列完整换行。小程序更多筛选和详情替换内容区，避免压缩列表。
- 修复小程序运行数据裁剪丢失形态判定元数据的问题；两端候选、排行和速度分组通过真实运行数据对照。

## 体积门禁

用户已明确同意 JS gzip 硬上限由 256 KiB 调整为 272 KiB。只调整该项增量及对应测试，不改变警告基线或其他体积限制。

| 指标 | 实测 | 硬上限 |
| --- | --- | --- |
| JS gzip | 260.54 KiB | 272 KiB |
| JS 原始体积 | 879.54 KiB | 880 KiB |
| CSS gzip | 43.89 KiB | 46 KiB |
| 客户端资源 | 13.56 MiB | 14 MiB |
| 运行数据 | 1.40 MiB | 1.5 MiB |

所有硬门禁通过，但 JS 原始体积剩余空间很小，后续功能应优先拆分或减量，不能自动放宽其他上限。
