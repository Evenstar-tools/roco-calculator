## 指标口径与查看方法

按 Asia/Shanghai 自然日查看，采样设为 100% 后才能按完整采集口径解释。网络失败、拦截、离线都会造成漏计。

| 指标 | 口径 | RUM 查询 |
| --- | --- | --- |
| 每日访客 | 当日有上报的匿名浏览器标识 AID 去重 | 页面访问 → 统计维度选择设备数（AID）；匿名浏览器去重，不能解释为精确自然人数 |
| 浏览次数 | 首次文档加载及主计算器/电鹿路由切换各一次；刷新再计，弹层不计 | 自定义事件 page_view 次数；SDK 自带 PV 仅文档加载，不与此相加 |
| 访问会话 | 30 分钟没有点击、键盘、滚动或统计事件后再次活动开新会话 | session_start 次数；严格去重用 AID + ext2；跨午夜不主动拆分 |
| 功能使用次数 | 首次进入主计算器/电鹿及每次打开功能；自动计算和重绘不增加 | 自定义事件先筛选 feature_view，再选 ext1 分组；未筛选时会混入其他事件 |

功能编码：calculator 主计算器、deer 电鹿斩杀线、skills 技能查询、types 属性查询、transmission 传递、speed 速度排行、durability 耐久排行、rankings 其他排行、teams 队伍、desktop 下载入口。
`feature_view` 统计的是功能打开次数，不是完成计算、成功下载或保存队伍次数。以下新增口径截至 2026-09-29 仅在本地实施与验证，尚未部署，不能用它解释此前的线上数据。

### 本地新增口径（待发布）

事件名、`ext1` 功能编码、`ext2` 会话编码保持兼容；`ext3` 保留 `id`、`at`，只增加下表列出的受控枚举字段，未知字段和值丢弃。

| 事件 | 新字段 | 精确含义 |
| --- | --- | --- |
| `feature_view` | `entry_source=initial/navigate/reopen` | 文档初始化的默认页面或初始已打开面板 / 本文档内第一次主动切入或打开 / 本文档内重新进入或打开。刷新重置为 initial；浏览器前进后退按是否访问过该功能区分 navigate、reopen。initial 不代表主动选择 |
| `calculation_ready` | `result_kind=damage/status`；`ext1=calculator` | 用户配置提交（含撤回、重做）后，当前选中结果已渲染，配置完整且结果为 exact、伤害和 HP 百分比均为有限数。0 伤害有效；status 仅指内核明确结算的 statusOnly 结果。默认配置、URL 自动恢复、不支持或缺条件的结果不计 |
| `calculation_ready` | `result_kind=threshold/range_not_reached`；`ext1=deer` | 用户修改已提交，延迟结果与最新输入一致，展示行均为已知斩杀判定且伤害和比例为有限数。有可达最低层数 / 全部在范围内未达；后者也是成功完成查询。初始带入或默认对手本身不计 |
| `lineup_use` | `action=apply_member`、`side=attacker/defender`；`ext1=teams` | 队伍成员成功代入主计算器，提交状态实际匹配待应用状态之后记录。不是点击次数，不是队伍保存或能力方案预览次数 |

主计算器与电鹿每次页面功能访问最多各一条完成事件；打开浮层、重复渲染和连续修改不重置，离开该页面再进入才开始新访问，且仍须重新提交有效修改。主站切到电鹿后保持挂载但不计完成。过期结果或已被后续提交覆盖的队伍代入不计。

队伍按左右两侧分别在内存中记住最后成功代入的配置；同配置重复代入不增加，换侧或配置实际改变后成功代入可增加。离开电鹿再返回仍保留主站去重状态，刷新会重置。用于比对的配置只在本地内存中使用，不上报；不发送队伍名、搜索词、精灵配置或新增身份字段。终端继续使用既有 SDK 设备维度，没有新增 UA、设备或屏幕字段。

上报量：来源字段不新增事件；新增量上界为“主站访问次数 + 电鹿访问次数 + 去重后的成功成员代入次数”，并非全局硬上限。代表本地流程原有 11 条自定义事件，新增完成/代入 5 条，共 16 条；纯内存 mock，真实 RUM 请求为 0。事件条数不等于 SDK 批处理后的网络请求数，也不保证零费用；现有限额、保护任务、采样与开关均未调整。

验收详情：`docs/verification/usage-metrics-implementation-20260929.md`。新增统计回归已纳入常用单测配置；本地及非生产域名继续不加载真实 RUM。

## 限制与费用
不采集输入配置、队伍名、完整 URL 或查询参数。匿名 ID 存于 localStorage，网络上报仍会暴露网络层 IP/UA；上线前应同步网站实际隐私说明。换设备、清理存储会形成新访客。多标签页复用会话；同时首次开多个标签页有 localStorage 竞争，严格分析需按会话 ID 去重。
历史未采集数据不能补回；日 UV 不可直接求和得到累计人数。跨保留期长期留存需要另行安排导出，本次不启用额外数据库或调度服务。
