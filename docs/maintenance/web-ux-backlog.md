## 使用规则

主视口为 **1920×1080 横屏**（按用户“1080”理解为 1080p）；亮暗主题及精简/具体版按问题需要核对，320/390px 只做兼容检查。每轮先从本表挑最多 3 项，其他候选保留；池中还有候选时不重做全站扫描，耗尽或证据失效再补巡检。不为凑满 3 项制造改动。选中项实施前复现、实施后验收，记录状态与提交。

状态：待选 / 入选待确认 / 实施中 / 已完成 / 待复核 / 已排除。P1 为交互可靠性，P2 为主要可读性或操作反馈，P3 为次要视觉改善。重复问题复用原编号。
