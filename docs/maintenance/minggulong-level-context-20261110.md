# 冥古龙等级输入顺序修复 · 2026-11-10

用户报告：先调冥古龙当前等级，再更换对方精灵和技能，低于80级额外40%承伤没有进入技能伤害。

## 根因与修复

- 当前等级输入在两个出伤方向各有一份；App修改等级时镜像同步，再将精灵所属方向记进单技能档案。
- 更换对方精灵走applyConfiguration，重置两个方向并恢复单技能记忆，未更换侧只能恢复其出招方向，受击方向等级丢失。冥古龙界面和面板仍是79级，承伤规则却使用默认99级。
- 配置重建完成后，仅从未更换侧的当前原生等级控件读取显式值，用已有镜像入口恢复双向参数。缺失时不补默认；不保留天气、印记和对手相关条件；更换等级机制持有者时旧等级仍清除。
- 阿布、首领阿布与超能阿布同链路受影响：80级以上丢失参数会按默认60级误加承伤，此次同步修复。
