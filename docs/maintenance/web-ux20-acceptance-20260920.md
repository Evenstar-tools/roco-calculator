# Web UX20 本地验收

2026-09-20，版本 2.2.2，实施基线 `53e4556`。用户确认三项后追加“先别提交，我再改几个预设”；本轮未提交、未推送、未发布。

## 已实施

- W20-01：生命输入在失焦或 Enter 时回显实际采用值，保留编辑中草稿；不改计算公式。
- W20-02：折叠筛选时显示形态范围及承伤排序，展开后不重复显示；窄屏按空间自然换行。
- W20-03：搜索词非空时显示清空按钮，只清搜索、保留其他筛选；焦点返回输入框，窄屏点击区域 44×44px。

## 验证

- 相关组件测试：2 文件、50 项通过；全量现有测试：104 文件、1793 项通过。只扩展现有测试，不新增测试文件。
- lint 通过；生产构建产物的 E2E：12 项通过。
- 首次构建生成产物后被旧 JS 体积上限阻断，因此首次 E2E 未启动；随后用同一产物运行 `E2E_PREBUILT=1` 完成功能 E2E，不能将首次运行描述为通过。
- 用户批准本次 JS 硬上限由 348 调至 348.25 KiB，CSS 保持 56 KiB，并注明“体积再议”。修改门禁后 `npm run performance:verify` 通过：JS gzip 348.10 KiB，CSS gzip 55.96 KiB；基线超出仍保留警告，不是永久放宽授权。
- 真实浏览器：1920×1080 亮暗主题检查 HP／百分比、超上限／负数／空值、失焦／Enter、满血及撤回；验证清空按钮点击／键盘激活、焦点回归和 Esc 关闭。
- 320／390px 亮暗兼容检查：弹窗无横向溢出，清空按钮 44×44px。组件测试另验证模板、范围、排序、形态及状态选项不被清空。
