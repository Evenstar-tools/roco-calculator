# UX18 窄屏模式按钮验收

用户“完成 修复”确认采用上一轮图 2 的横排金底；仅修窄屏模式按钮，不改宽屏双按钮。基线 `6e52867`，版本仍为 2.2.2。本次本地完成，未推送。

## 原因与修复

- 原来精简模式命中 `.app-header--compact` 的竖排与 1px 外框内边距；具体模式横排、2px 内边距，且只有具体模式通过 aria-pressed 获得金底。
- 窄屏组增加独立标识，统一 2px 内边距、9px 外框圆角；单按钮显式横排，两模式共用金底深字，排除旧的未选中悬停底色。
- 单按钮使用动态可访问名称描述当前及下一模式，不再借用 pressed 状态控制颜色；宽屏双按钮继续保留原有选中态。

## 实测

- 320/390/470/620×900，亮暗两主题，精简→具体→精简连续切换：按钮均 42×38px，外框均 48×44px；文字颜色、背景、2px 内边距和相邻队伍入口间距一致，无横向溢出。
- 621×900、1920×1080、600×400 横屏恢复双按钮，精简选中／具体未选中状态正确。
- 470px 前后实测使用相同 470×64 裁剪框；原来精简标题栏为 52px、具体为 54px，现在两者均为 54px。已读回合图及亮暗模式截图。
- 26 项相关组件测试、1792 项关键单测、12 项发布 E2E 通过；新增 1 项集中覆盖模式样式、鼠标切换、键盘 Enter 切回及宽屏边界，不重复建立大批测试。
