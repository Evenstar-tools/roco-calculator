# Web UX14 横排底栏验收

2026-09-20，保持版本 2.2.2。本轮按用户裁剪后的方案实施：不采用两行布局，精灵名、伤害、百分比仍在同一行；只合并底栏背景、去掉承伤对比独立边框并增加分隔线。仅本地提交，不推送、不发布。

## 实施与验证

- WorkspaceOverlays 增加共同底栏容器，两个按钮仍为兄弟节点，各自保留原点击处理和无障碍名称，不嵌套按钮。
- 1080px 及以下使用统一背景与细分隔线；承伤对比点击区域为 88×44px，名称与数值沿用原字号。宽屏移动底栏隐藏，桌面入口不改。
- 以用户最后提供的横排截图为结构约束，原 UX14 方案只用于统一底栏背景和右侧入口样式；不采用原方案两行信息结构。design-craft 对图确认 320 / 390px 亮暗截图；底栏因统一外边框有 1px 高度差，没有增高内容行。
- `npm test`：104 文件、1791 项通过。专项 `workspace-overlays.test.jsx`：19 项通过，含新增承伤对比开关两种情况下的容器与独立点击回归。
- `npm run e2e`：11 项通过，含生产构建与性能门禁。JS gzip 347.19 KiB / 348 KiB，CSS gzip 55.48 KiB / 56 KiB，未调整预算。
- `npm run lint` 与 `git diff --check` 通过。第一次 lint 与 E2E 并行时碰到临时 trace 文件被清理；E2E 结束后重新运行通过，非产品错误。
- 生产预览 4197 实测 320、390、760、1000px 亮暗主题：信息处于同一行、数值不重叠、按钮高度达标，无横向溢出；1280px 不显示移动底栏。
- 实际点击两个入口分别打开对应弹窗，结果弹窗关闭后焦点返回原按钮。320px 具体版临时注入长名称、99999 伤害、999.9% 验证布局后立即还原；此为排版压力检查，不代表真实计算结果。

## 复用验收条件

后续调整此底栏必须保留单行横排：检查三项文字中心纵坐标相差不超过 2px、数值边界不重叠、比较按钮点击高度至少 44px。一次性浏览器检查保存在 `artifacts/web-ux14/verify-actual.js`，对比图页为 `artifacts/web-ux14/acceptance.html`。

本轮仅验收 Chromium Web；不包含小程序、桌面安装包、真实手机软键盘及设备安全区模拟。未修改计算核心。
