# 技能攻击维度审计 · 2026-11-01

## 本轮边界

按当前各服实体文案修复技能自动攻击增减；手动攻击等级继续双攻共用。国服读取 buildS5BwikiSnapshot 的当前 S5，国际服读取独立 Global S3 runtime，不把国服新技能或数值复制到国际服。

## 处理结果

- 按当期实际可用技能计，国服 S5 的 26 条、国际服 S3 的 25 条既有明确单攻技能原来写入 ownAttack/targetAttack 共用层数；现按己方/敌方、物攻/魔攻独立落账。差异为国服的仰望夜空；不计本轮新补分光，以及原本已走独立魔攻通道的技能。
- 独立落账在触发条件、连击/重复次数、萌芽加成结算之后进行，原有叠加顺序保留。
- 水泡盾、国服矿物置换原有独立魔攻通道保留，避免重复叠加。
- 明确双攻技能保留共用层数。极限撕裂补上使用后、当前生命大于 50% 时的双攻 -50%；恰好 50% 不触发。
- 国服 S5 分光必须填写队伍不同系别数；未填写不估算，填写后按 20% + 每系别 10% 只增加魔攻。
- 技能效果预览明确显示己方/敌方物攻或魔攻，不将单攻显示为双攻。
- 单项效果已接入面板、伤害、增益来源、存档和双方互换后的应用链路。旧存档中已经应用的共用层数原样保留，不追溯拆分或迁移。
- 本轮同时修正贪得无厌的攻击后增益写回：只累加物攻独立层数，不再带动魔攻。

## 区域和版本差异

| 技能 | 国服 S5 | 国际服 S3 |
|---|---|---|
| 焚毁 | 每驱散一层印记，魔攻 +20% | 每驱散一层印记，物攻 +20% |
| 暗箱操作 | 自身双攻双防 -50%；应对防御后改为敌方 -120% | 自身/应对后的敌方均为 -100% |
| 分光、矿物置换、续杯、画龙点睛 | 按本服 S5 文案纳入审计 | 不新增实体，不加入这些自动效果 |
