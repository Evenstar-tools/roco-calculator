# 配置预览包含手动收藏

2026-09-20，Web 2.2.2。用户要求勾选“仅预览配置项”后，手动收藏的精灵也显示在选择列表。本轮未提交、未推送。

## 原因与改动

原筛选只检查内置预设 spiritId，遗漏了已传入列表的 favoriteState。按 diagnose 流程先补回归用例：36 个预设加一个非预设收藏，应显示 37 个，修复前实际仍为 36；修复后通过。

仅将筛选改为“内置预设或手动收藏”，沿用图鉴排序，重合项不重复。不扩大到仅保存配置但未手动收藏的其他精灵；文字搜索仍搜索全图鉴，关闭开关后的原规则不变。悬停提示同步注明包含手动收藏，布局与样式未改。

## 验收

- 3 份相关组件测试共 31 项通过：新增收藏、取消收藏、预设重合去重、原开关持久化／搜索／读取失败重试等。
- lint 和 git diff --check 通过。
- 独立 Playwright 测试会话，1920×1080：实际点击收藏非预设精灵“火神”，列表条目增加一项；刷新后及防御方选择列表均可找到；取消收藏后恢复原列表数量。测试收藏已取消，不改用户浏览器配置。
- 实测脚本：`artifacts/web-ux20/verify-favorite-preview.js`；截图：`artifacts/web-ux20/favorite-preview-actual.png`，已读回。
- 定向 Vite 生产构建、service worker 压缩及 performance:verify 通过。JS gzip 348.11 KiB，小于本次已批准的 348.25 KiB；CSS gzip 55.96 KiB，小于 56 KiB。不是完整 npm run build 或全量 E2E 重跑。
