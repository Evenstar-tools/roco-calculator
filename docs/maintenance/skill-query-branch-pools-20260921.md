# 技能检索分支技能池修复

## 问题与修复

用户搜索“布丁”时仅看到抹茶布丁。根因是检索模型虽保留家族全部成员，结果列表却只渲染一个家族代表，隐藏了分支的独立技能池。原始技能数据没有丢失。

保留原家族关系，在每个家族内按完整技能 ID 与各技能学习途径分组；两者均相同才共用入口。每个池沿用正式名称命中优先、否则最终普通形态优先的代表选择。结果标题分别显示家族数和技能池数。技能交集与来源筛选仍先针对具体精灵计算，禁止跨分支凑技能。
