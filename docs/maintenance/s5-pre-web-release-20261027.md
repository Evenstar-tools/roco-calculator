# S5 抢先网页入口 · 2026-10-27

用户本轮明确授权将已有抢先内容发布到正式域名 `/pre`，工具箱提供入口，保持现有用户的正式页。此授权覆盖必要的网页源码提交、推送和自动部署；不包含桌面安装包或小程序发布。

## 隔离方式

- 正式页使用 `2c7f463` 的现行版本作为基线，仅增加工具箱入口、SW 绕过 `/pre` 及同版日志。
- S5 工作树独立构建：`npx vite build --config config/vite.preview.config.mjs`，配置内置 `mode: pre`、资源基址 `/pre/`，输出当前工作树 `dist/client`。
- 正式发布树 `config/preview-release.json` 固定抢先源码提交，构建脚本将其独立产物组合到正式 `dist/client/pre/`。不把开发树的 App、主题池或候选目录复制到正式页。
- 预览先安装专用 localStorage/sessionStorage 适配，再加载应用。所有原键，包括历史键和外观设置，都位于 `rock-calculator.preview.s5.` 前缀下；无自动读取/迁移正式存档。跨标签事件仅转发同一预览空间。
- 预览不注册 Service Worker、不启用正式 RUM，也不设置正式 PWA manifest。原 Service Worker 保留；新版正式 SW 对 `/pre` 与子路径直接放行。
- 电鹿进入、返回、刷新及生成分享链接保持 `/pre/`；返回正式版使用整页导航，切国际服也整页退出预览。保持现有分享协议及数据/规则校验，不新增未受支持的信封字段。
