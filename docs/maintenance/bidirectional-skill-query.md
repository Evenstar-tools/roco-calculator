# 技能检索双向查询：实现与验收

日期：2026-09-09。范围：Web 与同源桌面；不涉及小程序、数据改写、配置改写或版本号变更。

## 使用入口与行为

顶部菜单 → 技能检索 → 查询。

- 找可学精灵：搜索技能并加入条件，最多四个；匹配同一具体形态全部可学的精灵，再按家族显示一个头像。点击头像查看技能，同家族可以选择具体形态。
- 查精灵技能：复用精灵名称、图鉴号、拼音、首字母和社区别名；初始不填入示例精灵。选择后显示当前资料收录的完整学习面。
- 技能表展示原图、名称、属性与种类、能耗、威力、学习条件；可按来源、属性、种类或名称与效果筛选，点击行展开说明并反查精灵。
- 返回匹配结果保留查询条件和结果滚动位置；技能反查提供返回原精灵详情的入口，恢复筛选与展开项。
- 保留赛季新技能和老精灵新学。点新学精灵名称或技能可进入双向查询，并携带原赛季；返回赛季查询保留原筛选。
- 来源不明的记录仍在全部来源中显示，不冒充默认学习。多种学习途径归并到同一个技能，展开可读原始条件。

## 数据边界

复用已有 catalog，不新增另一套学习表；当前检索基于资料中收录的学习关系，不保证游戏内资料已经完整。

组合条件表示该具体形态逐项可学，不表示已经验证多条血脉等条件可以同时携带。计算配置、热门预设和用户保存数据不受查询操作影响。

真实 S4 回归：掠影＋月蚀交集只有银月狼王；打开后包含其他四项技能，共六项，不能只展示这两个条件。相关解锁等级仍待确认，原始依据保留在展开区。
