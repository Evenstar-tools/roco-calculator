# 预设更新最小规则

2026-09-15，网页 2.0.2 同版本更新。

- 相同跳过；本地仍等于上次导入基准的旧配置直接更新；已修改或无法识别来源的配置保留；缺失配置新增。
- 旧用户没有基准时，与仓库历史预设逐项匹配，不凭更新时间推断是否手改。已存在基准时不再回退到历史匹配。
- 基准保存在本地配置的可选 presetBaseline 字段，普通保存沿用原基准；导出不携带此内部字段，旧 schema 仍兼容。
- 确认时重新读本地配置并计算更新项，避免覆盖预览后发生的手改。单技能手动设置原样保留。
- 按钮数量仅为更新与新增之和。无变化显示“已是最新”；仅剩手改项显示“手改配置已保留”。没有新增不代表无需更新。
- 历史来源为 public/data/presets/pvp-preset-history.json；之后更新推荐预设时运行 node scripts/build-preset-history.mjs 并提交结果。历史文件不可用时保留无基准项，不冒险覆盖。

验收：tests/state/preset-update.test.js 覆盖旧预设迁移、手改保留、基准优先、再次读取保护、新增和相同、基准持久化；tests/ui/config-library-dialog.test.jsx 覆盖新增为零但需要更新的按钮。
实际浏览器验证：97 条差异中 96 条旧预设更新，1 条手改保留；完成后相同 225、不同 1、新增 0，手动生命个体 17 未被改变。

本次不重新发布桌面安装包或上传微信开发版本。

## S5 推荐配置 · 2026-10-30

- 用户指定的 14 份推荐存于 `data/presets/s5-popular-configs.json`；H/A/B/C/D/S 分别是生命/物攻/物防/魔攻/魔防/速度，指定三项各 60，其余 0。
- 冥古龙四槽依次为撞鬼、荒芜之噬、力量增效、偷袭（用户简称“力增”，“荒芜之誓”对应当前技能名“荒芜之噬”）。这只更新推荐配置，不将用户配招冒充官方学习面证据。
- 其余沿用已有默认四槽；冰钻布鲁斯、琉璃水母首领当前没有默认配招，只录性格和个体，四槽留空。
- 本分支通过 `scripts/s5-preview-presets.mjs` 合并推荐库，同一个 `/pre/data/presets/pvp-popular-configs.json` 供提醒、导入、常用浏览和队伍推荐读取；本地及预览构建均为 245 份。主发布分支的普通版也合并同一批推荐，基础 231 份文件与国际服固定源码不变。
- 后续更新仍运行历史生成器，它同时读取正式库及 S5 推荐的 Git 历史；不将新推荐自动覆盖用户存档。测试入口为 `tests/state/s5-popular-configs.test.js`。
- 普通版另由主发布分支按相同 14 份推荐追加精灵和必要技能/特性，保持旧精灵、技能与学习面不变；此分支仍负责完整 /pre/ 数据。

## 后续更新与发布

- S5 推荐以 `data/presets/s5-popular-configs.json` 为唯一录入处，同步到本分支与主发布分支；基础库和补充库避免同 ID 双重维护。预设修改提交后运行历史生成器并提交结果，正式切季继续保留旧配置基准及各次公告改动。
- 有可新增/安全更新项才显示约 2 秒提醒；用户确认预览后才应用。无变化、仅剩手改项或检查失败保持静默，更新后再次进入不提醒；同版本配招更新也按内容差异判断。
- 发布顺序是本分支提交 → 主发布分支更新 `config/preview-release.json` 固定提交 → CI/云部署 → 公开页面回查。普通版只追加有配置的新精灵及必要依赖，旧精灵公告调整留在 `/pre/`；国际服、桌面与小程序单独验收和发布。
- 验收覆盖性格/个体/技能、旧数据边界、速度/耐久候选，以及旧库有更新、应用后无更新、手改保留。技能状态修复覆盖实际受影响的单/四技能与攻/防入口，检查生效、解除及保留收益。
- 完整发布门禁以主发布分支的 [发布检查单](release-checklist.md) 为准；线上统计开关与预算保持一致，不能用提交成功代替部署与公开页面回查。
