# 预设更新最小规则

2026-09-15，网页 2.0.2 同版本更新。

- 相同跳过；本地仍等于上次导入基准的旧配置直接更新；已修改或无法识别来源的配置保留；缺失配置新增。
- 旧用户没有基准时，与仓库历史预设逐项匹配，不凭更新时间推断是否手改。已存在基准时不再回退到历史匹配。
- 基准保存在本地配置的可选 presetBaseline 字段，普通保存沿用原基准；导出不携带此内部字段，旧 schema 仍兼容。
- 确认时重新读本地配置并计算更新项，避免覆盖预览后发生的手改。单技能手动设置原样保留。
- 按钮数量仅为更新与新增之和。无变化显示“已是最新”；仅剩手改项显示“手改配置已保留”。没有新增不代表无需更新。
- 历史来源为 public/data/presets/pvp-preset-history.json；之后更新推荐预设时运行 node scripts/build-preset-history.mjs 并提交结果。历史文件不可用时保留无基准项，不冒险覆盖。

验收：tests/state/preset-update.test.js 覆盖旧预设迁移、手改保留、基准优先、再次读取保护、新增和相同、基准持久化；tests/ui/config-library-dialog.test.jsx 覆盖新增为零但需要更新的按钮。
实际浏览器验证：97 条差异中 96 条旧预设更新，1 条手改保留；完成后相同 225、不同 1、新增 0，手动生命个体 17 未被改变。

本次不重新发布桌面安装包或上传微信开发版本。
