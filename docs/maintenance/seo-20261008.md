# rococalc.top SEO 优化 · 2026-10-08

## 目的与授权

用户要求：Bing 已能搜索到网站，Google 尚未见到，执行一轮 SEO 优化。本轮改善真实页面的发现、读取与摘要，不把基础优化视作 Google 已收录或保证排名。Google Search Console 尚未验证，未获得 Google 抓取失败或未收录原因的后台证据。

沿用现有 Vite、React、EdgeOne Pages 与 2.2.4。隔离树从当前 origin/main 创建，保护主工作树已有改动；不改变伤害逻辑、游戏数据、埋点、额度、付费服务或发布桌面安装包、小程序。

## 当前事实与修复

- 公网 `/robots.txt` 与 `/sitemap.xml` 原本均为 200 HTML 首页，不能作为有效 robots/XML 使用；缺少 robots 本身不等于禁止抓取。
- 首页原始正文只有空 root，标题与说明主要是赛季信息；浏览器加载后虽有功能，未执行 JavaScript 的读取缺少产品用途和入口。
- 增加真实 robots 和只列首页、电鹿、说明页的站点地图。未为技能、队伍、属性等面板制造独立 URL。
- 首页与电鹿独立 HTML 提供对应初始说明、真实链接、标题、description、canonical、OG/Twitter 与真实 WebApplication JSON-LD；React 接管后保持正常计算界面。前进、后退、返回首页同步元信息，不让电鹿内部标题覆盖路由信息。
- 新增 `/guide/` 静态使用说明，涵盖三步计算、真实队伍与工具入口、结果范围及 5 条 FAQ。原生 details 支持不开 JavaScript 阅读和展开；底部长期可见链接使加载后的主页也能发现说明页。
- 本地 HTTP 验证发现 `/dianlu` 默认回退首页，`/dianlu/` 才返回目录文件。因此明确改用 `/dianlu/` 为规范地址，并在 edgeone.json 配置旧 `/dianlu` 301 至新地址；Router 仍识别旧新两种路径。`/guide` 同样 301 至 `/guide/`。生产规则需要上线后独立核验。
