# 优化轮：交互修复与视觉候选

日期：2026-09-19。基线 `98495eb`，Web 2.2.1、小程序 1.1.19。

## 结论与已实施项

按项目优化轮流程，先巡检小程序 H5，再巡检 Web；视觉候选只在独立浏览器页面临时注入，截图后还原，没有修改正式样式和文案。

已修复一项不改变视觉的 Web 交互缺陷：在速度轴空白处拖动后，用键盘首次激活速度节点会被旧拖动标记拦截。修复前第一次 Enter 仍显示目标 192，第二次才变为 194；修复后第一次即变为 194。拖动产生的指针点击仍然拦截，不误选节点。

修改仅涉及速度轴点击判定；未改计算公式、数据、配置保存、版本号或小程序源码。新增单测先确认失败，再完成修复；既有亮暗/尺寸浏览器用例增加拖动后的键盘操作断言。
