# 技能承伤对比

2026-09-13，本地开发交付；未提交、推送、打包或上传。

## 使用动线

承伤对比默认关闭。桌面／网页在「菜单 → 显示设置 → 承伤对比」开启；小程序在首页「设置 → 承伤对比」开启。选择保存在本机，不占用对局撤回记录；关闭后隐藏全部承伤对比入口，手机底部结果栏恢复完整宽度。

选攻守双方和技能 → 结果栏「查看全精灵承伤／承伤对比」→ 搜索、筛选或切换耐久模板 → 点行展开 →「代入防守方复算」→ 必要时撤回。

- 桌面／网页：结果栏入口，宽屏弹窗，760px 及以下全屏。手机底部结果旁可直接进入，不叠加抽屉。
- 小程序：结果区入口，原生全屏榜单。点行只展开，不改主配置；关闭保留原对局。
- 四技能模式只比较选中的一招，可在榜单内切换携带技能，保留相邻技能联动。
- 默认按伤害占满血比例升序，支持降序、名称／别名／图鉴号搜索，以及“低于50%／未击倒／可击倒”筛选。搜索保留全榜名次。
- 同一攻击来源关闭重开时保留技能、模板、搜索、筛选、排序及状态开关，按主界面最新条件重算；仅在本次页面会话记忆，不缓存伤害。换攻击来源重置，原技能被删除时回退到当前有效技能。

## 结论导出（仅 Web／桌面）

- 榜单右上角「导出」可选择 Excel（.xlsx）或 Markdown（.md），不新增小程序入口。
- 按当前搜索、筛选和排序导出完整结果，不受首屏 60 条或“继续显示”限制；保留全榜名次。计算中、无结果或计算失败时不可导出。
- 文件为“计算条件＋结论表”：攻击方性格／个体、技能、特性条件、耐久模板、星陨／冻结口径、筛选及版本时间；列表包含精灵、属性、满血、伤害、承伤比例、剩余生命、击倒结论和逐只配点。
- 文件名包含攻击方、技能、星陨／冻结层数、模板、筛选与时间。结论是导出时的静态结果，不附带计算公式或自动重算能力。
- 数据和规则版本按当前实际计算快照标注，不沿用导入旧存档中的版本；正反方向均记录实际攻击方和本次沿用的状态层数。
- Excel 为单工作表的标准 XLSX，固定表头、自动筛选，HP 和比例保存为数值；所有文本使用 inlineStr，不执行用户文本中的公式。Markdown 转义表格分隔符、换行与 HTML。
- 生成在本机完成，不上传配置。仅 XLSX 下载时加载轻量 ZIP 模块；没有使用 CDN 或引入大型表格编辑器。

## 计算口径

- 使用当前共享计算核心，固定 60 级。
- 保留当前攻击方性格、个体、特性、技能条件、血脉、天气及己方印记。
- 候选默认最终形态＋首领；可切换全部种族值完整形态。未纳入原因可展开查看。
- 三个固定模板为“生命性格满双防个体”（踏实，生命／双防各60）、“生命性格无双防个体”（踏实，仅生命60）、“中立性格生命个体”（普通无修正，仅生命60），其余个体均0，统一60级。移除承伤对比的物防／魔防性格选项，不改独立耐久排行榜。第四项“当前防守方配点”仅复用当前逻辑防守方的性格和六项个体，候选仍使用自己的种族值和属性；详情及导出按实际配点展示。
- 第五项“用户预设”在有本地配置时展示：Web 读取已收藏或已完成的本地配置，小程序读取已导入／保存的配置库；逐只匹配精灵 ID，只取性格和六项个体，不取技能、特性条件。未配置者回退生命性格／生命双防 60 个体，摘要及详情明确提示。
- 可用本地预设严格超过 200 条时优先默认“用户预设”（200 条不切换）；显式手动选择优先，按原有同攻击来源规则记忆。关闭后重新打开会读取最新本地配置；预设清空后回退生命性格，不保留失效选项。
- 不计候选原生、继承、吞噬等防守特性；默认满血、无异常／印记／能力阶段，不继承旧目标减伤、克制或目标条件覆盖。
- “沿用星陨／冻结”首次打开时按当前逻辑目标自动关联，有任一层数便勾选；没有手动选择前，重新打开读取最新状态。手动开启或取消后在同一攻击来源保留选择，换来源重新判定。开启后仅将当前目标这两项状态统一传入候选，摘要显示层数；己方层数、天气等仍回主界面编辑。不复制灼烧、中毒、带电、寄生等其他目标状态。
- 仅比较本次直接伤害，包含核心已适配的多段和联动；不含回合末异常结算，也不模拟换入过程。
- 手动锁定显示威力、听桥及依赖对手配招／出招的技能明确提示，不生成无依据榜单。
- 百分比显示保留一位小数；筛选和击倒判断使用未舍入数据。

代入时恢复该精灵特性及默认技能，保留攻击方和计算方向，应用所选耐久模板，清理旧目标条件。界面提示“结果可能与榜单不同”，一次撤回可恢复。小程序即使未开启全局快捷撤回，也提供本次代入的撤回按钮。

显式沿用时，代入同时保留星陨／冻结。非零冻结会开启主界面的负面状态处理开关，以保持技能冻结条件与榜内一致；一次撤回会恢复原开关和对局。榜单不包含灼烧、中毒等回合末伤害，但纳入冻结击倒阈值：以最大生命为100%，承伤比例、排序和范围筛选使用“直接伤害比例＋有效冻结层数×5%”（冻结最多100%，冰系免疫为0）。血条以蓝色冻结段向前推，伤害HP不变；冻结击倒显示独立结论与剩余0HP，详情保留伤害后HP。判断复用主结算的整数阈值，避免取整边界误判。折射等技能已写入状态的冻结自动沿用，不在打开榜单时重复施加。Web／小程序／导出使用同一口径。
