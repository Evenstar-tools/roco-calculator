# 桌面技能图标离线验收

## 原因与修复

旧桌面包的 553 个技能图标仍指向 BWIKI 外链，而桌面 CSP 只允许本地资源，导致这些图标退回显示属性符号。已有 26 个本地临时图标不受影响。

离线图标保存于 `data/desktop-skill-icons`；`manifest.json` 保存原始 URL 与 SHA-256。使用 `node scripts/download-desktop-skill-icons.mjs` 下载或补齐来源图标，不在常规构建时联网下载。

桌面构建在独立暂存目录复制网页资源，将运行时图标路径改成本地路径，再传给安装包构建器；不改动网页产物或小程序。桌面 CSP 保持不变。

## 防止遗漏

- `tests/desktop/skill-icons.test.js` 检查全量资源及桌面暂存行为，包括缺失、损坏和网页产物保持不变。
- `verifyDesktopSkillIcons` 在桌面暂存与打包结束后检查全部技能路径和 PNG 文件；缺少资源即阻断构建。
- 桌面离线烟雾测试实际解码全部技能图片，任意加载失败即判定失败，补上原验收只核对精灵头像的遗漏。

2026-09-08 验收：相关 36 项测试、ESLint、构建与硬门禁通过；桌面程序实际加载 579/579 张技能图，失败 0。未操作用户配置，未自动安装或远程发布。
