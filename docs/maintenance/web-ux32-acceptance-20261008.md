## 复现与最小修复

生产预览 `http://127.0.0.1:4198/`，独立浏览器测试存储，1920×1080亮色主视口、390×844亮暗兼容检查。测试数据为普通性格、个体60的圣代甜甜（樱桃巧克力口味）对寂灭骨龙，四技能首槽风吹雪，静态威力30，原结果83／19.5%。

修复前输入1.5再Tab失焦，框内变回30，仍提示“静态威力只能填整数”；手机底栏仍标“上次有效结果”。旧测试仅检查未提交和错误提示，漏查框内显示值与错误的一致性。补充真实输入值断言后在旧源码上失败，修复后通过。

`PowerDraftInput` 同步外部有效值时增加错误保护，保留非法草稿供修改；切换口径优先清错并同步当前值。既有编辑、提交、取消和恢复自动通路不变。

修复后失焦仍显示1.5并提示整数限制；10000显示范围限制。非法草稿不参与计算，结果仍为83／19.5%；修正、Esc、换口径或恢复自动后移除对应错误。
