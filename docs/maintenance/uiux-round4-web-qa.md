# 第四轮 Web 与桌面界面调整验收

日期：2026-09-09。Web/桌面共用源码；仅本地提交，没有推送、上传或制作安装包。

## 已确认并实施

- W3：速度一览的档位数字在所属分组内吸顶，长分组滚动时仍能确认速度；分组结束即随其离开。数字位于现有吸顶表头下方，不改变排序或目标选择。
- W4：矩阵容器不超过 560px 时启用表内横滑，固定成员列；单元格按钮 44×44px、数字 12px。更宽容器保持原来的紧凑表格，新增滚动区可键盘聚焦。

## 验证

- `npm test -- --maxWorkers=2`：102 个文件、1802 项通过。首次默认并发运行 1801 项通过、桌面图标读取测试超时；未修改该测试、资源或超时阈值，降低并发全量重跑通过。
- `npm run lint` 通过；最终 JSX 缩进整理后单文件 lint 再次通过。
- `npm run e2e -- --workers=2 --reporter=line`：全量 67 项通过，含本轮新增 6 项。首次默认并发 66 项通过，新手引导菜单点击超时；未改业务或放宽断言，降低并发重跑通过。
- E2E 启动执行的 `npm run build` 通过含性能预算的全部门禁。JS gzip 241.29 KiB，硬上限 256 KiB；CSS gzip 37.42 KiB，硬上限 46 KiB。存在基线警告，没有绕过门禁。
- 独立浏览器：320、390、1440 宽度 × 亮暗主题；速度数字不遮表头、不越过所属分组，末列可点开详情，成员列横坐标保持固定，整页无横向溢出。

## 视觉证据与明确差异

证据目录：`artifacts/web-ux4/implemented/`，包含 18 张实际截图与 `metrics.json`。

- W3：`w3-fidelity.png` 同时对比已确认示意与实际；沿用主题强调色，暗色也可读。
- W4：`w4-fidelity.png` 同时对比示意与实际。实际点击宽度由示意 40px 增至 44px，表格最小宽度由 864px 增至 960px，为手指操作保留空间；行高 48px，桌面保持不变。未缩小头像或字体。
- 退出速度页后的截图流程会正常接受离开未应用能力方案的确认；此前脚本默认取消对话框，因此没有切到矩阵，并非矩阵渲染缺失。
