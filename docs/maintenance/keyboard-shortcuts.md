# 网页与桌面快捷键（第一批）

范围：网页和 Windows 桌面版共用计算器界面；不修改微信小程序。

| 按键 | 行为 |
| --- | --- |
| Tab 短按 | 按下立即预览另一模式，350 毫秒内松开后保留并保存该模式。 |
| Tab 长按 | 按住至少 350 毫秒视为临时切换，可修改性格等配置；松开只还原模式，修改保留，不写入临时模式设置。期间发生点击／编辑时，即使未满 350 毫秒也按临时切换处理。 |
| Ctrl+Z | 立即撤回一步；按住 450 毫秒后，每 120 毫秒撤回一步，直到松开或历史耗尽。 |

- 撤回沿用现有计算器快照、分组及最多 50 步历史，不包含队伍编辑、收藏、主题和界面模式等未纳入历史的操作；不增加重做。
- 输入框、下拉选择、可编辑内容以及输入法组字期间不启动新快捷键，保留原生文字撤销与 Tab 移焦；在外部已按住的 Tab 除外：忽略其连发，松开仍还原模式。
- 弹窗、队伍抽屉、工具查询与引导打开时暂停新计算器快捷键，不在弹层背后切换或撤回；打开前已经持有的 Tab 仍可在松开时正常还原。
- Shift+Tab、Ctrl+Tab、Alt+Tab 等组合键不接管。在计算器非输入区域，单独 Tab 按用户约定用于模式切换，不再用于向前移焦。
- 松开 Z 或 Ctrl、窗口失焦、页面隐藏、进入输入框、鼠标按下、其他按键以及组件卸载均终止连续撤回。点击／编辑不取消 Tab 临时模式；松开 Tab、窗口失焦、页面隐藏或组件卸载才还原临时模式，修饰键 Tab 不接管。
- 忽略系统按键连发，避免不同键盘重复速率造成多次切换或双倍撤回。

实现入口：`src/hooks/useCalculatorShortcuts.js`。后续快捷键先讨论再加入，不预建自定义映射或命令语言。

自动回归：`tests/ui/calculator-shortcuts.test.jsx` 已纳入 `npm test`。

回归用例固定包含：按住 Tab → 点击并选择性格／编辑个体 → 松开回原界面 → 再次查看修改仍在 → Ctrl+Z 可撤回配置；不能只测试空页面的模式切换。
