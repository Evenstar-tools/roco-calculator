# 小程序中等宽度与参数面板修复

日期：2026-09-11。用户追加要求直接修复截图中的布局错误；本轮只修改小程序，不推送或发布，不覆盖已归档的 2.0.1 安装包。

## 问题与修复

- 780px 横向窗口仍套用 300px 结果侧栏，左侧再分成双列，六维控件只剩窄条。原先单列例外依赖竖屏方向且仅到 899px。改为 768–1023px 不分方向统一单列工作区；结果位于主内容之后，1024px 起保留宽屏侧栏。
- 个体输入控件的外框约 53px，内部 H5 input 约 21px 且偏上。统一外框 44px，使用 flex 居中并显式覆盖 `.weui-input`，兼容 Taro 编译后的元素。
- 参数弹层中六张满个体卡片不再整片染红 / 蓝；回归中性表面，阵营仍由标题表达，选中仍由上方绿色控件表达。宽屏六项改为三列两行，手机保留两列。
- 弹层快速摘要取消负边距，避免分隔线压字。共用关闭按钮补齐主题文字颜色，修复暗色下黑字。
- 用户截图中的提升箭头是现有 `status-up.png`。本轮回读源图、H5 网络图片尺寸及原生显示均正常，未重现原始加载失败，不能断言其最初原因。新增图片失败处理：不显示破图占位，仍保留绿色选中状态及 `aria-pressed`，不影响操作。

- 新增两项回归测试先失败再通过：中等宽度断点 / 输入居中约束，以及图片失败后选中状态仍可用。

- H5 320、390、780、820、1024、1440px 明暗主题：页面与弹层无横向溢出；输入框均为 44px，内外中心偏差不超过 1px，破图数为 0。另补 780×740、820×740 横向窗口检查。
- 780px 六维按钮实际宽度约 46px，820px 约 49px；精灵及技能名恢复正常横向显示。
