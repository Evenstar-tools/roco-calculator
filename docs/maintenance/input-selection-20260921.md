# 单行输入框首次点入全选

2026-09-21，版本保持 2.2.2；本地修改，未提交、推送或发布。

## 行为

- 网页及桌面共享入口统一覆盖可编辑单行文本、搜索和数值输入，包括延迟加载的弹窗与独立电鹿页面。
- 首次点入全选现有值，直接输入可替换；再次点击保留光标定位，拖选、带修饰键点击及输入法组字不被新增逻辑强制全选。键盘移入同样全选。
- 不改动输入框原有计算、校验及提交时机。多行文本、只读与禁用输入框、复选框、下拉框、滑条等保持原行为；现有精灵／技能选择器专用行为保留。
- 使用文档事件委托，避免逐个输入框重复实现；热更新时移除监听。特殊单行控件可用 data-auto-select="false" 排除。
- 无样式、版本、小程序改动；未制作或发布桌面安装包。
