# 特性反向联动

特性选择器固定提供8项：向心力、翼轴、贪心算法、盲拧、机械变式、风速仪、正位宝剑、宝剑王牌。隐藏无关的选择追加、变招和替换类特性；未选时仅显示不可选的占位文字。

选择特性后按当前快照traitIds反查精灵，默认选择最高进化阶段，依次对应声波缇塔、帕帕斯卡、贝古斯、立方人、权杖-V、测风蝉、圣剑-X、圣剑骑士。当前精灵已经匹配时保留该形态及四技能；否则带出匹配精灵、头像、默认四技能及可学技能列表。切换会重置旧推演。

精灵到特性的原有联动保留；普通精灵无上述特性时显示“无相关特性”，不会向列表插入无关选项。本轮只调整配置联动，不改变传动及行动结算规则。

验证：55项相关测试和ESLint通过，覆盖全部8项反查、头像和切换后回合清空；完整构建及性能门禁通过。浏览器实测从特性切换精灵及默认技能，在320像素宽度回读头像。
