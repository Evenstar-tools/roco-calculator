# 传动功能支持状态门禁

用户指出：盲拧可以选，但开始后要求手填实战顺序，不符合自动计算预期。本轮移除界面手动录入路径，改为计算前检查与禁用。

## 当前边界

- 盲拧：显示“不支持”并禁用选项。直接搜索对应精灵或载入配置仍在开始前阻断，显示原因；不能绕过。
- 机械变式、风速仪：标记“仅顺序”，能耗递减和印记累计明确不支持。
- 正位宝剑、宝剑王牌：补齐1号位、1/3号位行动限制，界面禁用非法槽位，引擎也拒绝。
- 随机变招等影响回合开始的技能：配置后即显示不支持，禁用开始。
- 轮班额外传动：分支选项标记不支持且禁用；其他身份替换、全队移动及固定槽冲突行动提前禁用。轮班加威仅做顺序结算，不宣称输出威力。
- 普通精灵搜索或导入配置时，仍检查其原生特性，不能因精简的特性列表省略了该项而绕过规则限制。

## 验证

60项传动引擎与界面测试通过，ESLint通过。真实浏览器验证盲拧选项禁用、直接选立方人阻断、无手动录入框、部分支持标记、圣剑合法行动槽，以及切回向心力后正常推进。320像素截图已读回。

完整构建通过；共享工作树CSS/JS体积超过基线但低于阻断阈值，为警告通过。未提交或发布。

## 后续准入规则

新增可选特性或行动前必须检查：能否自动给出结果、是否只支持部分效果、能否经精灵搜索/导入绕过限制。未实现的标记并禁用；部分实现显示具体范围；禁止把要求用户手算/手填当作已支持。测试必须覆盖正常路径、所有入口的阻断及切换回受支持配置的恢复。
