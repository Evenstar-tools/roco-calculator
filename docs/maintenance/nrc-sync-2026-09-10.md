## 不扩大的边界

降雨、午夜爆音未在新站技能模块出现；保留内部 ID 兼容旧配置，但不加入正式当前学习池或技能查询。非攻击技能缺省威力沿用应用的 0 表示，不把格式差异误报为改动。

来源事实完整不等于模拟了所有回合机制。月相的过量治疗、中毒联动以及正模标本等整队/多回合事件仍属说明，不新增自动回合结算。秋收的草系环境由玩家明确选择条件，不把天气或草血脉自动等同于环境。

S3 历史快照不改。新站当前学习表不合并旧 S3 补充关系；血脉等级不会误匹配默认学习。已有精灵/技能 ID 不重建，因此不迁移或清空玩家配置。

1. `npm run data:check-updates -- --json`：当前快照自动检查新站 6 个模块，不再仅监控旧站两个筛选页。
2. `node scripts/bwiki/nrc-source.mjs`：缓存公开原始模块，遇到限流/缺失即停止，不把不完整结果写成当前数据。

4. `node scripts/bwiki/apply-nrc-current.mjs`、`node scripts/bwiki/sync-nrc-assets.mjs`、`node scripts/bwiki/sync-nrc-form-roles.mjs`、`node scripts/bwiki/build-form-role-manifest.mjs --write --from-catalog`。
5. 更新随包预设的数据/规则版本（先验证其技能合法性），运行 `npm run miniapp:sync-core`、`npm run data:runtime`、`node scripts/miniapp/build-bundled-runtime.mjs`。
6. 跑测试、构建、头像绑定和窄屏实际操作，再按用户授权提交或发布。旧公告/前瞻/截图导入器遇到正式新站快照不会覆盖它。
