## 失效点与修正

旧实现把普通盾血除以2当作唯一的破盾本体生命，默认回血 `ceil(H×0.9)` 并精确匹配一个数字。这个零天分、精确10%的组合解释不了犀角鸟149。

新实现使用独立本体候选值，按0星天分0至10的包络计算：

```text
B = R(10 + L + S×(2L+50)/100 + t×(L+25)/100)
H = R(B×n) + 22
t ∈ {0,…,10}; n ∈ {0.9,1,1.1}; R(x)=floor(x+0.5)
```

这是与现有实战相容的有界模型，不是从客户端恢复出的服务器野怪生成函数。0至10覆盖未知0星个体，不赋予概率、不声称每个数都由服务器实际生成。客户端包体的通用 `talent_random_maximum=50` 未找到对应S5消费者，不能据此当作0星野怪上限。天分项的等级系数来自客户端 `ATTR_GLOBAL_CONFIG`；本体尾项22沿用已实测的生命基线。官方随机玩法说明确认初始资质10及无资质条的情况，但不公开S5破盾生成算法。

普通／异色只改变盾池；换血不乘2或3。保留旧 `targetBodyHpByLevel` 作为零天分基线兼容字段，实际判读与三档显示使用 `targetBodyHpCandidatesByLevel`。野怪有生命上限骰子时仍拒绝用普通本体模型判断。

血条整数不代表精确比例。包体UI在(0,99]向上取整，99以上向下取整，满血才显示100。显示p（1至98）对应的整数现有HP为：

```text
floor((p−1)×H/100)+1 ≤ C ≤ floor(p×H/100)
绿色回血 G = H − C                 （我方满血）
```

99单独覆盖大于98%且未满血的整数HP；0与100分别对应0与H。程序枚举天分所得的离散H，逐一检查合法C区间，再去重等级/性格组合。只要多档都能解释，就全部保留；不在三档最小最大之间跨空洞做宽松匹配。

条件默认「游戏血条（整数）」，另保留显式「精确比例」口径（两位小数，旧记录手填的非默认比例，包括整数，自动沿用此口径）。后者仍使用 `ceil(H×(1−p))`，但H同样有天分范围。更换目标、清空整场、恢复默认会恢复血条10%；关闭第五行仍暂停该条证据。
