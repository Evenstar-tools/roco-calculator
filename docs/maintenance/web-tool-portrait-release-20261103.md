# 工具加载与榜单头像网页补丁 · 2026-11-03

用户已授权提交、上传当前已完成优化并回查正式网页；本地模拟弱网首次进站约 20 秒的进一步优化明确留到后续。本批沿用 2.3.0，只发布网页，保持安装包、小程序以及地区数据规则不变。

## 改动与取舍

- 工具分包准备完成即显示，保留失败恢复；工具箱只按使用意图准备技能目录。
- 同次访问复用已验证的地区资料；电鹿扫描减少重复准备，相同参数重开复用有限结果，计算取整不变。
- 耐久榜分批渲染、搜索仍查全表；速度榜头像在滚动容器附近才请求，等图时显示精灵名字，保留原图像素与透明度。
- Service Worker 合并同类在途图片请求，限制后台回填并发，前台直接取图；刷新发布缓存，沿用图片版本协议。
- 未浏览头像的离线覆盖减少，浏览器原生查找仅覆盖已渲染耐久行；慢 CPU 速度榜重开存在少量额外开销，未宣称所有操作均提速。

## 发布前体验依据

两服共享实现与地区边界已验证。以下时长是国服本机生产产物、单组配对结果，不作为公网或手机速度承诺。

每工具独立新浏览器，清空 HTTP 与站点缓存、阻止 SW 并禁用 HTTP 缓存，普通 CPU 点击至内容显示两帧：属性 328→47 ms、技能 340→97 ms、传动 330→44 ms、速度榜 404→87 ms、耐久榜 405→57 ms、电鹿 567→217 ms。同页重开电鹿约 42 ms 另属内存复用场景。

清缓存后直接首次访问，页面及 SW 分别模拟 150 ms 延迟、200,000 B/s 下载：固定首屏 42 张头像加载完成 4.780→3.562 s；同次访问 End 后固定底部 22 张 5.210→3.863 s；完整观察含 SW 接管回填的头像正文 10.228→3.460 MB。页面首次工具箱入口可见 19.884→19.980 s，未改善。首屏最少观察 4 秒，首屏完成到 End 的间隔不同，快跳样本不能精确归因到单一机制。

此前 30.36→7.45 s 快跳数据是在 SW 已接管后重载的场景，保留为独立条件，不与首次访问混称。原始证据保留于发布工作区 `output/playwright/experience-review-20261103/` 及其中 `cold-cache/`，未纳入公开源码。
