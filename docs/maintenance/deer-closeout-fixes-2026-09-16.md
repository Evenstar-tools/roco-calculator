# 电鹿斩杀线收尾修复验收

## 当前结论

2026-09-16：已完成用户确认的四项功能修复与三项界面收敛。本地版本仍为 2.0.2，未提交、推送或发布。本记录替代早期本地验收及收尾评估中的待修状态和测试数字；历史文档保留作过程记录。

## 功能修复

1. 保命特性：火羽「不死鸟」、化蝶「化茧」以及银月狼王获得的这些特性，启用时明确显示“保命效果未计入 · 斩杀待确认”。保留理论伤害，停止确定的单招、补刀斩杀推荐，禁用一键填层数，逐层表不再误报击倒。关闭防守特性后恢复按普通伤害计算。此项是防止误导的最小修复，**并未实现保命剩余次数和多次免疫的完整模拟**。
2. 四种耐久模板只改性格、个体，保留当前特性参数与战斗条件；完整已存预设仍按明确提供的字段覆盖。松鼠能量5逐一切换四模板后仍为5。
3. 数值输入复用草稿控件，支持逐字输入负数、删除重填和空值失焦恢复；层数按整数提交。真实浏览器键盘输入 -2 通过。
4. 查询层数只覆盖对应层数，不再将自定义每层效果改回默认40%/30%；方向覆盖值优先级保留。更换敌方不再清空攻击方特性方向参数。非星陨印记保持，主动设置星陨时才替换。

回归用例位于 `tests/domain/deer.test.js`、`tests/ui/deer-page.test.jsx`；既有入口隔离和返回测试仍通过。以上问题已有可重复的检查，后续修改不能仅凭截图或文案判断特性已适配。

## 界面与对比

按 design-craft 的层级与参考对比流程落实已确认的①②③，不增加装饰：

- 配置卡间距收紧，移除防御方重复特性文字；特性名称、描述和参数保持直接可见。
- 折叠战斗条件显示当前非默认值，例如自身HP49%、冻结4层；伤害条旁增加冻结百分比图例。
- 320/390px 逐层详情为三列，文字不逐字竖排；手机主结果补回“当前X层伤害”。

保留鹿影、真实技能图标、原计算器色彩与控件、深浅主题及既有速度提示。速度提示仅在同先制度下比较当前有效速度，不宣称推演对手技能先制。

对比证据：`artifacts/web-ux-deer-closeout/compare-w1.png`、`compare-w2.png`、`compare-w3.png`。参考为用户确认的 `mock-w*-after.png`，实现为 `actual-w*.png`。配置间距、层级、图标与三列布局一致；以下差异是有意的：

- 模板现在有正确的选中态，且不会清空能量。
- 条件摘要只显示非默认值，不追加“其余默认”；冻结百分比放在实际血条旁，避免重复挤占折叠栏。
- 逐层伤害不照抄旧模拟图数字；当前截图保留松鼠能量5，数值随修复后的真实条件重算。对比图用于检查布局，不作为新旧伤害相等的证明。

## 后续修订：仅显示防守相关特性

防守特性区域依据内核防守规则显示双防、减伤、承伤修正相关特性，保留银月狼王获得特性的入口以及不死鸟／化茧保命未支持警示。满月砣「月相」、电鹿自身的纯进攻特性等不再占用防守配置区域。按 design-craft 收敛无关信息，不新增空框或占位说明；仅隐藏展示，不修改原特性启用状态与战斗输入。

判断基于特性能力而非当前效果数值，因此零层、条件未触发以及手动关闭时仍保留需要的控件，避免无法重新开启。

秩序鱿墨「绝对秩序」沿用共享内核既有规则，保留开关及可调减伤比例：电鹿电系技能不减伤，非电系技能默认减伤50%。八个候选及后续先发的减伤回归通过，界面修改比例、关闭和恢复均已验证，不新增独立伤害公式。

## 后续修订：展开详情起点与留白

用户截图指出说明文字及逐层卡片贴住左边缘。实测详情跨列单元格被末列箭头样式误命中，左内边距为0、右侧12px。将末列规则限定到非跨列单元格，并为桌面详情统一设置左右20px留白；手机保留左右12px，文字、层数网格和计算过程入口共用同一左对齐线。按 design-craft 同状态对比截图验收，仅改两处CSS，不改文字、字体、配色、数据或计算逻辑。

浏览器1112px、320px检查通电及光刃展开详情，测量左右边距均符合20px／12px，文字和卡片左缘偏差小于1px，无横向溢出。深浅主题截图已读回，对比图 `output/playwright/deer-detail-spacing-comparison.png`。后续修改表格或详情样式时，在已有对手的电鹿页面执行 `playwright-cli -s=deer run-code --filename scripts/qa/deer-detail-spacing.cjs`，自动检查边距、对齐及溢出，防止跨列单元格再次被末列样式覆盖。本次未重新构建、提交或发布。
