## 第3强度阶位通式及拟合依据

`R`取现有家族映射的对应双防种族值，`L`为显示等级，`n`取0.9、1、1.1。`round`为正数四舍五入。

```text
B = round(10 + R × (L + 50) / 100)
D = round((round(B × n) + 11) × c)

候选 c = 1.38
```

这里D是能解释实测的有效伤害分母，尚无原始战斗属性字段证明它等于怪物原生面板。

逐条按 `N/(实测伤害+1) < D ≤ N/实测伤害` 反推，再求整数D与c的共同区间，没有引入伤害容差。

只用中性技能、不依赖极化K的记录，包括深蓝鲸41—43级、噼啪鸟43级盾前火切223、锤头鹳43级先发77，得到：

```text
1.3791946308724832 ≤ c < 1.380794701986755
```

1.38在共同区间内。加入已标明K1.8及破盾条件的其他记录，区间不变。部分防御性格档位由伤害反推，仍保留此条件，不能将整个交集说成独立捕获确认。

## 为什么第1、2阶保留独立规则

在相同的“基础、性格、最终分步取整＋尾项11”结构下，下列每个阶位内部都没有共同乘数：

| 强度阶位 | 中性技能记录 | c可行区间 |
|---:|---|---|
|1|41级可爱猿，103/113|[1.798013245, 1.811258278)|
|1|43级沉金兽，首发未破盾火切110|[1.823741007, 1.838129496)|
|2|42级小翼龙，冷静，684/540/99|[1.633333333, 1.642857143)|
|2|41级伊雷龙，物防不变解释，364/111|[1.648809524, 1.660714286)|

这些冲突不依赖极化。它们排除的是当前输入条件下这个固定结构的“同阶单c”，仍需检查种族映射、成长尾项及各场状态，尚不足以断言物种一定各有系数。单独给式子增加截距能拟合少数点，但跨等级、性格记录不能稳定通过，暂不写进产品。

尤其是第2阶伊雷龙：41/42级若基础先round，两级都得73，加物防后都得80，后续必同D。因此这两级不同实测不能只靠调整同一个c解决。
