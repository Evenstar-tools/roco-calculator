# 同族形态与三三状态保留：本地验收

日期：2026-09-19。基线 `e3393f5`；版本保持 Web 2.2.1 / 小程序 1.1.19。本轮实现并提供本地验收，不提交、不发布。

## 验收入口

[本地验收页](http://127.0.0.1:4191/artifacts/sansan-morph-20260919/preview.html)提供两个真实计算场景：三三初始形态、切换成气球猫后。不是静态交互稿。

1. 点击“打开三三初始场景”。首次使用出现新手引导时可跳过；切到具体版可直接看全部参数。
2. 攻击方已经填入鼓气 3 层、飞吻手填威力 100、攻击能力 +2。
3. 再次打开攻击方精灵框，选择气球猫、逗逗或奇梦咪：输入不变，种族值、面板及伤害重新计算。
4. 撤回可恢复上一步形态；“重新载入当前形态预设”退出临时形态并正常载入目标精灵。

## 已实现

- 首次搜索正常载入；再次打开优先展示“同族形态 · 保留本场配置”。键盘、鼠标均可选择，取消或重复选当前项不改状态。
- 原配置身份与本场形态分开保存。性格、个体、配招、技能顺序、单/四技能模式、能力、威力、印记、异常及双方参数保持。
- 三三的鼓气 / 三鼓作气直接继承同一组层数，只算一次，不添加永久开关。
- 非等价特性保留原效果及输入范围，显示“特性沿用”。覆盖波普鹿超级电池、蒸汽革命 25 层、棋绮后分支渗透继承等回归。
- 保留分支锚点，降到共享低阶后不能借此跨到另一分支。
- 百分比生命保持输入比例；显式 HP 只在超过新上限时约束；默认满血跟随新上限。
- 支持撤回及计算分享往返，小程序记忆功能按原有设置保存本场形态。
- 形态切换及后续临时调整不自动写个人预设。存入队伍时明确要求先重新载入预设，避免看到低阶形态却静默保存成原精灵。
- 主计算器显式启用；队伍编辑、技能查询、电鹿、传动等选择器不被全局改变。

按 design-craft 复用现有选择框、头像、行布局和亮暗主题；只增加同族分组、临时形态和特性来源提示，不新建大面板。
