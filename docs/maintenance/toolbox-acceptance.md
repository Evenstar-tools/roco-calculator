# 标题栏工具箱验收

2026-09-18，本地开发，未提交、未发布、未制作安装包。

## 范围

标题栏顺序为界面模式、队伍、工具箱、主题、菜单。工具箱复用已有图标库与菜单/主题样式，按 design-craft 保持轻量双列分组；窄屏隐藏工具箱文字，保留图标、提示和无障碍名称。

- 查询：属性查询、技能检索。
- 计算：电鹿斩杀线、传动计算器。
- 排行：速度线排行、耐久排行。

工具从原设置菜单迁出；配置、显示设置、帮助、关于保留。工具箱点击切换、外部点击和 Esc 可关闭，Tab / Shift+Tab 循环焦点。选择工具先收起面板，关闭工具返回触发按钮；不写入主计算器撤回历史。面板具备当前工具高亮状态。

电鹿保留精灵旁原入口，新增工具箱固定入口：无电鹿攻击方时构造独立电鹿输入，保留已选防御方；缺防御方时补默认配置，不修改主页双方配置。返回主页不自动展开工具箱。

- 五个弹窗工具逐一验证打开、收起工具箱、Esc 关闭和焦点返回；电鹿验证跳转和返回。
- 额外验证银月狼王攻击/水灵防守进入电鹿后保留水灵，返回主页攻击方仍为银月狼王。
- 117 项定向组件/集成测试通过；全量 Vitest 158 文件、2521 项通过，之后追加的电鹿输入隔离测试单项通过。

- 前端构建、ESLint、diff 检查与硬体积预算通过；原有软预算警告仍在，未调整预算。
- 实页截图：`output/playwright/toolbox-<宽度>-<精简版或具体版>-<light或dark>.png`。320 亮色与 1280 深色已读回检查。
