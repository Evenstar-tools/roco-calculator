## 实施

- UX33-04：`App.jsx` 的非默认条件摘要补齐沙暴、暴风雪，沿用雨天／雷鸣的“计算条件／调整”。无天气且无其他条件时不显示空摘要；调整沿用原动作进入具体版高级设置，保留天气。
- UX34-01：手机承伤榜取消无标题的独立倍率列，将倍率放在类型旁，伤害HP独立一行。弱点红、抵抗绿、正常中性；保留明确×倍率，免疫单独写“免疫 ×0”，非有限／缺失值不冒充0或1。桌面保留原列，配色语义一致；颜色用现有主题变量适配亮暗。姓名、头像、无预设、排名、类型、比例、剩余HP与分段条均保留；冻结摘要按“伤害47.3%”“＋冻结15%”整段换行，不省略或删除。
