## 真实页面验收

本次生产构建在 `http://127.0.0.1:4198/` 复核，独立Playwright会话，不清用户存储或操作其他服务。

- 320/390px，具体/精简，精简名称开启/关闭，亮暗主题：页面宽度与滚动宽度一致，无横向溢出或短名称裁切。1920宽屏亮暗复核通过。390具体版身份区本例400→298px，同配风吹雪仍83／19.5%；非普通＋三项个体场景风吹雪仍96／22.6%。
- 原精灵选择列表位置在屏内；收藏切换并恢复，完整交换两次恢复双方配置。显示设置的完成/关闭可用，名称开关开启、关闭及重载记忆通过；伤害、精灵/技能、性格/个体和存档配置保持一致。
- 四技能不同槽位及攻防方向的名称随当前结果变化：冰晶坠179、反向诡刺80、正向风吹雪96；抽屉反算后底栏与结果栏一致。单技能名称与当前选择一致。
- 纯状态霜降未使用时显示非伤害；实际使用后冻结占比30.0%，底栏与结果抽屉一致。关闭结算并返回四技能后，非法威力草稿1.5失焦仍保留，伤害96不变、名称仍风吹雪，Esc恢复合法值。
- 独立视觉复核指出宽屏名称开启后的模式按钮过宽，已收回184px并重新构建、截图；手机仍双列。等正常收藏提示消失后重拍，最终图无提示遮挡。主代理与独立评审已读回最终真实截图及合图。
