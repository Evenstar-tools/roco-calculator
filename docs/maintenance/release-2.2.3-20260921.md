# 2.2.3 Web 发布验收

用户授权：完成本轮改动后升至 2.2.3、推送并回查 Web。仅部署 Web，不创建桌面安装包、不上传或发布小程序。

## 范围

- 技能检索保留同族各分支的独立技能池。
- 血脉技能特殊标记，与首领血脉／首领形态冲突时只提示、不修改队伍。
- 可编辑单行输入框首次点入全选，保留后续光标定位、拖选及原有提交行为。
- 精灵选择栏增加高阶、旁支与地区形态关联；跨分支载入目标预设，萌化合法路径不放宽。
- 同步根版本、锁文件、Service Worker、用户更新日志及 230 套预设来源版本；配招内容和小程序独立版本不变。
