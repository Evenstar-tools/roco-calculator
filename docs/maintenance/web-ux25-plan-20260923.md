## 实施验收口径

1. 地＋冰首屏能看到獠牙猪；地＋武能看到 8 个最终形态且可访问全部名称。
2. 单属性不显示精灵区；切换属性后结果同步更新；倍率来源点击仍可用。
3. 1920/1280/390/320px、亮暗主题无页面级横向溢出，弹窗内部滚动正常；头像无加载失败。
4. Web 全量测试、lint、E2E、构建及真实截图读回通过；用户确认实施后再提交。
