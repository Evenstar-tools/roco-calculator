# UX23 性格阶梯选择方案

状态：W23-01 性格阶梯菜单、W23-02 按住 Tab 编辑已本地实施。用户随后确认“增益性格加颜色这个也做”，W23-03 六维卡片增益绿图标也已独立实施，未提交或发布。

## 目标与范围

网页和 Windows 桌面版，用两级同栏缩进菜单替代完整性格原生长下拉。主目标是直接定位速度增益，无需滚轮翻找；小程序不改。基线为 `2e4b1c4` 加当前未提交快捷键改动。

示意数据：音速犬对水灵，攻击方胆小（+速度 -物攻），具体版，1920×1080，亮／暗主题。完整性格控件宽 654px；截图同框 674×570px。

## W23-01 交互约定

1. 点开先显示 7 行：普通（无修正），以及生命、物攻、魔攻、速度、物防、魔防六个增益分组，顺序沿用当前产品。
2. 鼠标停留分组约 150ms 或点击分组，在该行下方缩进展开 5 个具体性格；一次只展开一组，总计最多 1+6+5=12 行。
3. 分组展开后保留，不因指针移出分组标题而关闭；允许移进子项选择。进入另一组才替换，不累积展开；点击已展开组不造成列表闪收。
4. 悬停和点击分组都不修改配置；点击具体性格才走既有 onChange、即时计算、保存及撤回通路并关闭菜单。普通行可直接选中，无二级列表。
5. 分组标注增益 +20%，子项显示名称、减益属性及 10%；当前性格有背景和“已选”标记。重新打开仍从 7 行起步，触发栏保留完整当前性格。
   用户追加修订：六个增益分组名称字号从 13px 增至 14px，移除分组前的展开箭头，避免暗示必须点击；保留悬停和点击两种展开方式。子项、百分比和行高不变，顶部选择框的下拉箭头不在移除范围。已随本次确认实施。
   第二次修订：在六行 +20% 的左侧加入对应六维属性图标，复用现有 StatIcon 图片，大小 18px、与百分比间距 8px；不放回左侧展开箭头，不给图标单独点击行为。已实施。
6. 键盘支持方向键导航／展开／收起、Enter 或空格确认、Escape 关闭并返回触发器；不让性格菜单按键穿透到全局快捷键。
7. 菜单浮层不撑开属性卡，优先朝有空间的方向展开，必要时在视口内限位。标准桌面窗口 12 行无需内部滚动；320/390px 及短窗口单独测边界，不以裁掉行或缩小全站字号解决空间问题。

## 实施计划与验收

1. 将 `src/components/NatureSelect.jsx` 改为受控阶梯菜单，继续读取 `NATURES`、`STAT_LABELS` 和 `normalizeNatureId`，不复制 31 项性格映射、不改计算倍率。
2. 沿用现有调用处：主计算双方、队伍成员、能力分析手动微调。精简版 `QuickNaturePicker` 快捷预设规则与按钮本轮不改。亮暗样式写入既有样式分层。
3. 补齐焦点返回、点击外部关闭、悬停延迟清理、浮层定位，以及选择后完整字段与撤回状态。主计算与队伍的不同保存路径分别验证，不把全局计算器撤回说成支持队伍撤回。
4. 测试覆盖：7 行初始态；六组各 5 项且任意时刻只有一组；31 项可达；悬停不提交；选择／取消／普通无修正；鼠标、键盘、亮暗及窄屏；前后计算结果一致。
5. 用户确认后实施，拍真实验收截图，与方案区分保存；按项目门禁运行测试、lint、E2E／构建，发布须另有授权。

## W23-02 Tab 临时编辑已实施

用户确认：按住 Tab → 修改性格等配置 → 松开返回原界面，修改保留。本次仅实施此项，不视为确认 W23-01 阶梯菜单。

已拆分“停止 Ctrl+Z 连撤”和“结束 Tab 临时模式”：鼠标点击、输入框聚焦和编辑不再提前结束 Tab；松开仅还原模式，不回滚配置。捕获已持有 Tab 的连发与松键，避免输入控件移焦或弹层阻止还原；窗口失焦／页面隐藏仍兜底恢复。期间发生编辑时，即使未满 350ms 也不把临时切换提交为长期模式。

验收使用当前真实原生性格控件：精简 → 按住 Tab → 原生下拉选开朗 → 松 Tab → 回精简且性格保留；再次切具体验证一致，Ctrl+Z 能撤回性格修改。另测个体输入修改、弹层期间松键、短按切换、快速编辑、反向临时切换、失焦及连续撤回停止。实测脚本与截图在 `output/playwright/shortcuts/`，具体结果见 `tab-edit-acceptance.md`。
