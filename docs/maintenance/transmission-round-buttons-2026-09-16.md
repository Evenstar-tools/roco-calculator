# 回合按钮简化

移除回合下拉和计算按钮，改为开始、下一回合、撤回图标。开始直接结算第1回合，进入推演后禁用；下一回合逐次结算。撤回恢复进入本回合之前的完整状态，包括槽位、行动、冷却和记录；第1回合再撤回到初始编辑态。重置或更换配置清空撤回栈。
