## 改动

- W17-03：分配区内容宽度至少 714px 为六列，354–713px 为三列，更窄保留两列；不缩字体。
- W17-04：成员配置和能力分析在 1023px 及以下共用三列两行紧凑导航，六个成员一次看全；每卡攻防按钮隐藏，沿用当前成员操作折叠入口。取消成员区 38dvh 限高和独立滚动。
- 宽屏仍是完整成员侧栏，不启用旧的能力页紧凑模式；当前成员操作入口仅窄屏显示。

## 证据与验证

- 320×720、390×1080：成员区均为 183px，两页一致，无成员区内部滚动，六个选择入口可见；390 实际选择第六名武斗酷猫并设为攻击方成功。
- 768×1024：成员区 229px，包含队伍名称输入，无内部滚动。
- 1440/1920×1080：两页侧栏均为 280px，保留 12 个每卡攻防按钮，窄屏折叠操作隐藏。
- 容器宽度 240/353/354/713/714/900px 对应 2/2/3/3/6/6 列，未出现水平溢出；测试宽度覆盖已恢复。
- 已读回 320/390 亮色、390 暗色、个体值实际截图。暗色截图等待主题过渡结束，避免把过渡帧当最终画面。
- 1792 项关键单测、30 项队伍组件测试、11 项发布 E2E 通过；既有能力分析 E2E 补充成员区高度、可见操作、切页稳定、个体值列数检查后，复用同一生产构建定向 2 项通过。
- E2E 已含生产构建与预算检查：JS gzip 347.93 KiB / 348 KiB，CSS gzip 55.81 KiB / 56 KiB；没有提高预算。
