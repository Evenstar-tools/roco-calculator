# 海外新访客自动分流 · 2026-10-29

## 本轮授权与范围

用户询问“海外自动分流目前仍未启用…这个要怎么做，能开启吗”，本轮接通既有自动分服方案。基于最新 origin/main `8beca7e` 实施，保留同日整合发布及固定国际服源码 `efa2b0ddb285f428c516197d6da11f18a37d8478`。只更新网页根入口，不新增页面、导航、介绍、SEO内容、统计事件或定时任务；不发布桌面安装包或小程序。

## 实际行为

- `/cn/`、`/dianlu/`、`/en/`、`/jp/` 等明确地址优先，分享、手动选择及后退记录沿用既有优先级。
- 有国服队伍、收藏、精灵配置或计算草稿者保持国服；同时识别旧命名空间与现有分服键，不迁移或改写数据。
- 仅无上述目标的新访客根入口查询同域 `/api/location`。大陆 `CN` 默认国服，其他有效国家/地区默认国际服；国际服沿浏览器语言优先序选择日文、中文或英文。
- 800毫秒内未取得有效地区时按语言回退：中文国服，其余国际服。自动决定不写手动偏好；之后仍使用已有切服、语言入口。
- 先完成分流再挂载应用。国际服通过完整文档跳转加载独立构建，参数和分享片段保留，不提前初始化国服存档或国服埋点。
- `/api/location` 只读取托管平台提供的国家代码，返回 `private, no-store`；不返回或记录IP及精确位置，SW已有 `/api/` 缓存绕过继续生效。桌面 `app:` 保持国服。

## 来源与验收

地区字段按 [EdgeOne Request 文档](https://cloud.tencent.com/document/product/1552/81902) 的 `request.eo.geo.countryCodeAlpha2`，函数路由按 [Pages Edge Functions 文档](https://pages.edgeone.ai/document/edge-functions)，未使用第三方定位服务或调整付费套餐。

- 本地构建及发布级单元/交互测试通过；新增启动前分流回归涵盖失败、超时、迟到响应、明确目标和真实国服存档保护。
- 本地组装产物浏览器验证通过：模拟JP+日语、US+英语分别进入实际 `/jp/`、`/en/`；CN+英语保留国服；查询失败+日语进入日文；已有国服存档和明确 `/cn/` 不请求定位。国际服跳转前未加载国服运行数据、未产生国服存储键或手动偏好。
- 新增根入口后续分享变更回归，避免首次传入路由结果后丢失后续国际服硬跳转。
- 各国家模拟仅验证逻辑，不作为不同国家真实网络验收证据。线上部署与当前网络回查结果归档到当前任务 `outputs/rococalc-auto-routing/20261029/`，以发布后证据为准。

## 回退
