本轮依据用户“增加enjp的打点分析下en/ jp 分网址的指标”接通既有匿名服务。仅修改固定 Global 源码的 analytics 与启动接线，再更新正式发布 pin；国服、预览、小程序和桌面实现不变。不新增可见内容、SEO配置或定时任务。

## 网址与口径

- `/en/`、`/jp/`、`/global/zh-CN/`分别归组；旧`/global/ja/`归日文`/jp/`。仅保留固定 canonical，不上报查询参数、分享 hash、来源页或业务输入。
- 设备沿用既有匿名浏览器ID，各网址独立日去重。同设备可出现在多个网址，不能相加作为全站去重设备。
- 浏览采用业务`page_view`，初次打开及同页语言切换各一次，同网址重复调用不计数。SDK PV用于AID识别，不能与业务浏览数混用。
- 会话沿用30分钟无活动重启；切换语言不强制重启。分网址`session_start`表示在该页开始的会话，不代表所有经过该页的会话。
- 功能打开沿用`feature_view/ext1`及入口来源字段，完成事件沿用`calculation_ready/lineup_use/download_click`。当前访问内首次完成的采集逻辑不变，不能据此计算严格分网址转化率。
- 单核心共享设备与会话，每个固定网址独立SDK队列；事件创建时保存canonical，批量延迟发送保持原网址。性能、错误、资源接口明细与指纹采集继续关闭。
