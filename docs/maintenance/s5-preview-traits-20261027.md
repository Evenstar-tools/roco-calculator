## 已实现的边界

- `data/candidates/s5-preview-new-spirits.json` 保存逐条视频定位、未知项和素材来源。`src/features/s5-preview/catalog.js` 将候选仅叠加到 Web / Windows 原精灵列表，不写正式快照，也不修改 S4 数据/规则版本。
- 复用原搜索、选择、卡片和收藏入口；搜索 `S5` 可列出 17 个占位。特性全文继续用原 TraitHint，补足触摸点击后的保持和失焦关闭；未知六维时不显示伤害、面板或自定义六维/对比开关。
- 首领身份与普通精灵独立，种族值为 null、属性为空、学习面为空，不继承基底数值，也不补默认个体/性格/技能。
- `src/features/s5-preview/mechanics.js` 提供隔离的事件处理与效果适配函数，全部返回 `calculationEnabled:false`；本轮没有接入正式运行时伤害引擎。已实现等级99/80阈值、20能耗阈值的固定速度增益、印记乘2、固定星陨/寄生层数、每局一次、下一草技减费消费、事件去重和梦境速度交换合同。
- 未确认口径要求调用方显式提供核验依据：不默定3费取基础还是实际消耗、不默定总能耗来源、不把10层冻结自行累加、不猜中毒印记所属方、不假定非草技保留减费。
- 未知持续时间、上限、随机分布、骰子点数效果和首领升级额外效果保持 blocked / unknown。梦境只处理经确认的速度值交换，保留先制度；不在此推断回合结算顺序。
