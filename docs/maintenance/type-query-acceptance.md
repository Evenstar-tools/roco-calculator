# 属性查询开发验收

2026-09-18；基于 `91e1254` / v2.1.2 工作树。功能已接入网页共用前端，未提交、未发布、未制作新的 Windows 安装包。

## 功能与边界

- 入口：标题栏队伍后方的工具箱 → 查询 → 属性查询，位于技能检索之前（后续工具箱改动已迁出原菜单）。
- 18 种属性宽屏单排，中屏两行、手机三行，不横向滚动；最多选择两项，重复点击取消，选满提示先取消再更换。
- 防守调用现有 `getTypeMultiplier`；双重弱点为 3×，双重抗性为 0.25×。
- 进攻分别计算所选属性对 18 种单属性目标的倍率，取较优值，不相乘。
- 支持倍率来源、折叠常规承伤、清空、会话内关闭重开保留选择；刷新不保留。
- 不计威力、本系加成、特性、天气、血脉及面板，不修改主计算器配置或撤回历史。
- 复用真实 ElementIcon、属性矩阵与主题变量；惰性加载，无新增依赖或持久化字段。

## 窄屏与倍率文案修订

用户验收后取消原方案的手机横向滚动，改为宽度不足换行：1280 单行、900/600 两行、390/320 三行。五个宽度实测均无横向溢出，320 宽下最小按钮宽度为 44px。结果区在窄屏上下排列，标题、提示和倍率说明允许换行。

倍率来源拆为三行：先说明攻击属性、防御目标与结果，再分别列出每项倍率，最后说明组合规则。防守示例为“草系攻击水＋地系防守：承受 3 倍伤害”，不再用“2× × 2×”表述。攻击说明明确取较高倍率而非相乘。

本次修订 179 项相关测试通过，前端生产构建通过；未重复运行上轮完整单元/E2E 套件。实际截图为 `output/playwright/type-query-wrap-{1280,900,600,390,320}.png`、`type-query-source-320.png`、`type-query-source-320-dark.png`，亮暗截图已读回。以上取代原手机横滚验收结论；4190 的旧示意页不作为本轮验收载体，正式功能在 4191 首页菜单内。

后续修改属性选择区的验收清单：必须检查 320/390/600/900/1280 五档宽度，18 项完整可见、最多三行、无横滚、按钮至少 44px；检查下方结果及倍率来源不会溢出。修改倍率文案时必须通过攻防方向、单项倍率与组合规则的 UI 断言。
