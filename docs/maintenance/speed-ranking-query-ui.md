# 速度榜交互验收 · 2026-09-11

## 约束

- 数字默认查询实际速度；种族速度严格匹配；名称 / 图鉴保留原入口，不将三种口径混用。
- 同速汇总以配置计数，不冒充精灵数量；没有同速项时只插入基准标记。
- 去字模式保留口径和特殊条件标记，点击头像查看完整配置。
- 头像与眼睛图标的 H5 内部 img 不得叠加 Taro aspectFit 的位移；定位仅滚动榜单，不滚动整个页面。
