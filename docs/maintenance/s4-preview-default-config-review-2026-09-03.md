## 本轮采用的分配规则

1. 速度种族值达到 120 时，优先极限速度；个体选择生命、速度和较高的攻击项。
2. 只有一项攻击达到 120 时，优先考虑极限该攻击；个体选择生命、速度和该攻击。
3. 明确受向时，优先极限生命；个体选择生命、物防和魔防。
4. 生命个体默认保留；定位存在冲突时，角色定位优先于机械比较种族值。
5. 当前结论仅供 S4 前瞻试算，正式版仍需结合正式技能参数、实战定位与 BWIKI 数据复核。
