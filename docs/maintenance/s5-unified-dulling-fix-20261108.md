# S5公共钝化修正统一

2026-11-08，用户指出其他场景仍显示0.72并要求全部修正。本次接续上一批有限场景校准，统一当前国服工具采用的经验公式；不把推广应用表述为已恢复游戏原始公式。

## 当前计算

`K = clamp((100 + 攻方极化百分比) / (100 + 守方钝化百分比), 0.60, 1.80)`。

- 原属性关系为0或1时K=1；野怪极化、钝化为0，入伤使用我方钝化。
- 5–10星入伤K依次为1、100/145、0.60、0.60、0.60、0.60。6星只在显示时四舍五入，伤害使用完整精度。
- 删除42级深蓝鲸对10星罗隐的物种、等级、技能限定覆盖。自动威力、手填显示威力、单双段和骰子共用公共函数；手填最终威力保持不再修正。
- 出伤极化上限1.8、中性／免疫、奇遇生命、野怪攻防和41级加物防鲸203校准点保留。

## 实测与回归

- 42级加魔攻鲸→魔防137罗隐，7–10星采用同一修正：气泡222、激流266、天洪333。确认实测来自10星，其他星级是公共公式推算。
- 42级气泡随5–10星模型输出370、255、222、222、222、222。验证升星不反向增加来伤，以及刷新后仍用同一公式。
- 各精灵、41/42/43级、物理／魔法、单双段、骰子路径均检查公共函数一致性；精确匹配仍不容许±1。
- 鲸→迪莫作者表30条、伊雷龙660、抵抗实录29/37/37/32、显式最终威力龙爪及已核对的地刺249/193、火焰切割124回归保留。
- 早期“气泡266、无威力加成”与后续同场气泡222分开保留，前者仍未闭合，不将其改名为激流或删除。43级天洪430保持退出校准。
