## 已确认方案

精灵栏恢复原样。四技能模式中，铭记于月亮位于狼王所属技能侧的标题下方、技能表头上方；单技能模式在技能上方保留带攻防方与精灵名的编辑区。

桌面五项标签采用三列两行；手机采用两列三行，保留名称与“仅展示”等状态，不为强凑两行缩小点击区域。默认收起长说明，点标签一次只展开一项；再次点击或点击“条件与效果”可以收起。收起仅改变界面，不派发条件变更。满五项隐藏搜索，删除后恢复。
