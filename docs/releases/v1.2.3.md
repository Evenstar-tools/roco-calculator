# 洛克计算器 v1.2.3

本次发布是首个公开源码版本。

## 主要内容

- 精简版与具体版双模式，适合回合内快速决策和完整参数核验。
- 四技能双向伤害对比，支持动态威力、触发条件、层数与手动覆盖。
- 精灵配置自动记忆，切换精灵时恢复专属性格、个体、技能和技能状态。
- 内置 592 个精灵形态、553 个技能与本地素材，支持离线使用。
- 修复桌面端精灵头像加载，并更新应用与快捷方式图标。

## 安装

下载 `Rock-Calculator-v1.2.3.exe` 并运行。应用安装后仍显示为“洛克计算器”。覆盖安装会保留本机配置；重要队伍仍建议先复制分享链接备份。
