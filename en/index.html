Roco Kingdom damage calculator guide

Compare PvP damage, plan teams and check type matchups.

The calculator UI and Jini data are Chinese (China-server S4 data). International-server stats and rules have not been verified.

Open calculator (Chinese) → Download for Windows

Calculate damage in three steps

  1. 01

    Select both sides

    Choose the attacking and defending Jinies in the main calculator. Search uses the Chinese names and supports partial matches. Selecting a Jini brings in its skills, traits and base stats.

  2. 02

    Adjust skills and conditions

    Use compact mode, 精简版, for a quick setup. Detailed mode, 具体版, lets you adjust personality, individual stat values, skill power, hit count and battle conditions. Choose a single skill or a four-skill setup.

  3. 03

    Read and compare results

    Check damage, its share of HP and remaining HP. Changing the setup recalculates the result. Expand advanced options, 高级选项, to review the formulas and conditions.

Results apply to the inputs you selected. Check any warnings about unconfirmed base stats, unsupported effects or unresolved conditions before treating a theoretical result as a confirmed battle outcome.

Choose a tool for your question

Open 队伍 (teams) at the top of the main calculator. Find the other tools in 工具箱 (toolbox).

Save and compare teams 队伍

Manage multiple six-member teams, configure each Jini and its four skills, then load a member into either side of the calculator. Team analysis shows type weaknesses, skill coverage and matchups.

Location: main calculator → 队伍

Look up skills and learners 技能检索

Search Chinese skill names or effect descriptions, then filter by type, category and season. Review which Jini families can learn a skill, along with the season's skill and learning updates recorded in the data.

Location: 工具箱 → 技能检索

Check type matchups 属性查询

Select one or two types to check defensive resistances and weaknesses, and offensive coverage. This tool compares type relationships only; it does not include skill power, traits, weather or other conditions needed for a complete damage calculation.

Location: 工具箱 → 属性查询

Compare speed and durability 速度线排行／耐久排行

Speed rankings show configured speed values and base-speed references. Durability rankings compare templates, incoming attack types and selected metrics. Check the stated assumptions, then calculate a specific matchup with the relevant conditions.

Location: 工具箱 → 速度线排行 / 耐久排行

Simulate skill-slot order 传动计算器

Select a Jini, a trait and four starting skills, then review the order changes turn by turn. You can also load skills already configured in the main calculator. This slot-order tool is not a complete battle simulator.

Location: 工具箱 → 传动计算器

KO threshold tool 电鹿斩杀线

Set both sides, trait stacks and target HP to compare current skill damage and the minimum stacks needed for a single-skill knockout. An optional follow-up calculation is also available. The page flags unresolved conditions and survival effects that are not included.

Frequently asked questions

Should I use compact or detailed mode?

Use compact mode, 精简版, to compare Jinies and skills quickly. Switch to detailed mode, 具体版, to adjust personality, individual stat values and more conditions. Before reading the result, check that both sides and the skill conditions match the battle you want to calculate.

Why might a skill deal different damage in a battle?

Check both Jinies, their personality and individual stat values, skill power, traits and battle conditions. Review the formulas in advanced options. Type lookup and rankings use their own stated assumptions and cannot replace a complete damage calculation. Unconfirmed data and unsupported effects can also affect the conclusion. RocoCalc covers the Chinese version of Roco Kingdom, 洛克王国：世界, also referred to as Roco Kingdom: World. It uses China-server S4 data; international-server stats and rules have not been verified.

Where are my configurations saved?

Jini configurations are saved locally and restored for that Jini when you switch selections. They are not synced through an account. Do not expect them to appear automatically on another device or after clearing site storage. The team panel supports lineup import and export; check its notices for exactly which settings are included.

Can I use it on a phone or computer?

You can use the web calculator on either. Windows users can also download the latest installer from the project's GitHub Releases. Use the links at the top of this page and check the version actually offered on the release page. This English guide does not translate the calculator's Chinese interface or data.

How do I report a data or calculation issue?

Include the Jinies, skills, both configurations, enabled conditions and the result you expected in a GitHub issue. For the calculation assumptions, see the project's calculation rules (Chinese).
