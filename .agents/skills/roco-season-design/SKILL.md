# 洛克赛季主题设计

以此文件所在目录向上三级为项目根目录，不使用另一个检出的旧版本覆盖当前工作区。

1. 先读项目 [AGENTS.md](../../../AGENTS.md)，再读唯一流程正文 [design.md](../../../design.md)。按用户已指定的平台和改动范围执行，保留现有 UI/UX 与未提交改动。
2. 来源、选图、生成背景、角色摆放、配色、代码入口与验收按 design.md；历史素材从其中链接的来源说明和提示词按需查。需要位图时使用环境的内置 imagegen，角色原图不生成式重绘。
3. 做新赛季时先区分官方实景、宣传封面与自制装饰，并展示用到的原图和派生图。缺少某项来源时说明缺口，不借用其它赛季或自行命名场景。已确认的方向继续实施，未明确的可逆细节依现有规范处理。
4. 交付以真实运行页面、主题选择与保存操作为准；不把说明文案删除当作解除计算限制。默认只做本地开发验证；提交、推送、部署和跨平台发布遵循本次授权。

直接调用示例：`使用 $roco-season-design，按 design.md 做 S5 主题；参考图如下，沿用原版 UI，先本地验证。`
