## 能做什么

- 同时配置攻防双方的精灵、性格、个体和技能。
- 即时查看技能伤害、生命占比和剩余生命。
- 支持队伍预设、四技能对比和常见条件触发。
- 配置只保存在你的设备上，不会上传个人队伍数据。
